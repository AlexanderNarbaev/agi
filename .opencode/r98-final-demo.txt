## System Architecture (cumulative across RUN 8-9.8)

```
Distillation:       Qwen2.5-0.5B → Boolean Chain (24 layers × 915 neurons)
Chain storage:      21,960 boolean neurons (k=14 each)
Native eval:        libtruthy.so via Project Panama FFM (JEP 424)
QA retrieval:       Inverted index, IDF-weighted scoring (8,607 Q&A pairs)
Multi-turn memory:  Per-conversation-id bounded ring buffer (32 turns)
Async training:     Single-thread executor, job queue + status tracking
Chain reload:       Atomic layer list swap (volatile + synchronized)
Prompt-specific:    No wordish bias; pure chain-scored token selection
```

## Honest Remaining Limitations

1. **Chain-driven text generation is garbled** — multi-language BPE tokens.
   Fix requires a learned LM-head projection (RUN 10 architectural work).
2. **Training effect on /v1/generate is sometimes invisible** — depends on
   whether the trained neurons participate in scoring the picked tokens.
3. **AutoTrainer can saturate CPU** at startup. Disable via
   `MATRIX_AUTO_TRAIN_ENABLED=false` env var.
4. **Job cancellation is not yet implemented** for /v1/train/async.
