# ADR-002. BIR как единое каноническое представление артефактов

- **Статус:** accepted (базовое решение; зафиксировано здесь пост-фактум как эталон формата ADR)
- **Дата:** волна 6 документации
- **Связи:** SPEC-002 (keystone), DESIGN-01/02, C4 (компоненты BIR-ядра), FR-02, NFR-02/04/05/12

## Контекст

Системе нужна одна форма, в которой рождаются, передаются, исполняются, верифицируются и забываются все вычислительные артефакты (единицы, сети, правила, guardrail'ы). Альтернативы: (а) разные форматы у разных подсистем с конвертерами; (б) единый формат высокого уровня (деревья выражений/графы) с интерпретатором; (в) единое булево промежуточное представление с несколькими каноническими формами.

Ключевые требования: энергетический паритет против LLM (G-A), исполнение без GPU (G-B), машинная верифицируемость каждого артефакта (G-C), детерминизм и аудируемость (NFR-04/05), субстратная переносимость JVM→native→FPGA (NFR-12).

## Решение

Все артефакты — **BIR (Boolean Intermediate Representation)**: заголовок (provenance, fidelity, Φ, хэш конфигурации) + одна из трёх форм:

- **TT** — плотная таблица истинности, k≤20, long[]-LUT; каноническая семантика; прямой маппинг на FPGA LUT.
- **CLAUSESET** — набор конъюнктивных клауз (Tsetlin-DNF); первичная форма обучения; каноническая идентичность по изотропии (нормализация порядка клауз/литералов).
- **BDD** — решающая диаграмма с фиксированным порядком переменных; канонична → проверка эквивалентности за O(1) по ссылке.

Компилятор форм — упорядоченные подстановки (нормальные алгоритмы Маркова) с локальными правилами (одна конструкция — один инвариант, дисциплина Генцена); артефакт без валидного заголовка не исполняется нигде в контуре.

## Основания (атлас)

- Бит как элементарный тип и структурная дисциплина — Цузе (§33); конечные функции исчерпываются алгеброй — санкция TT от Мойсила (§26).
- Каноничность ≡ автоустойчивость (§8); изотропия ≡ каноническая идентичность CLAUSESET — Пирс (§31); разложение Буля ≡ рекурсия BDD (§29).
- Компилятор как нормальный алгоритм — ленинградская линия (§6); локальность правил и бюджетируемое пространство поиска — Генцен (§33).
- Вывод только по форме, минимальный Kern примитивов — Фреге (§33); малое аудируемое ядро — Вирт (§35).
- Сигнатурная/субстратная независимость — институции Бёрстолла–Гогена (§29, NFR-12).

## Последствия

**Положительные:**
- Энергометрия становится честной: битовые ops × нДж вместо оценок FLOP (H-009 accepted в своих границах).
- Верификация встроена в формат: эквивалентность, provenance и Φ проверяются механически на каждой границе контейнера (C4: «все стрелки в core проходят верификатор»).
- Один артефакт исполняется на всех эдж-профилях (FR-12) и переносится по субстратной лестнице (L10).

**Отрицательные / цена:**
- Потолок выразительности: k≤20 для TT; всё большее — композиция BirNet, а не рост единицы.
- Числовые/медиа-домены требуют кодировщиков в биты (DESIGN-06) с явной потерей, фиксируемой в fidelity заголовка.
- CLAUSESET может экспоненциально раздуваться на «плохих» функциях; компилятор обязан деградировать к TT/BDD по бюджету, а не молча расти.

## Отвергнутые альтернативы

- **Разные форматы у подсистем:** конвертеры становятся неучтённым источником рассогласования и энергии; аудит цепочки превращается в аудит конвертеров.
- **Высокоуровневый IR с интерпретатором:** интерпретатор — скрытый субстратный слой вне верификации; противоречит G-C и NFR-12.
- **Плавающая/нейросетевая форма как носитель:** теряется детерминизм (NFR-04) и энергетическое преимущество (G-A); LLM остаётся опциональным бэкендом сигналов, не носителем знаний (ADR-001).

## Проверяемость

- Любой артефакт в репозитории/рантайме парсится SPEC-002 заголовком; CI-тест: сериализация→десериализация сохраняет хэш.
- BDD-эквивалентность двух форм одной функции (k≤16) — обязательный тест компилятора (SPEC-002 AT-форм).
- Откат решения возможен только новым ADR с экспериментом, показывающим нарушение G-A/G-C на BIR.
