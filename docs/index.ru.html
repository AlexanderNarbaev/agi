Три принципа

🔍 Детерминизм

Каждое решение — проверяемая булева цепочка. Идентичное состояние и вход всегда дают идентичный выход. Никаких LLM в рантайме.

Три формы вычислений

Каждая булева функция хранится в одной из трёх эквивалентных форм:

  • TT (Truth Table) — исчерпывающая таблица 2^k для k ≤ 20 (K_MAX)
  • CLAUSESET — DNF с автоматами Цетлина для разреженных больших k
  • BDD — редуцированная упорядоченная бинарная решающая диаграмма для компактного представления

Формы взаимно компилируемы; эквивалентность проверяется механически.
