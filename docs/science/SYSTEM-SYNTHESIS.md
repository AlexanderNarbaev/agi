# SYSTEM-SYNTHESIS. Единая система

Этот документ — сшивка трёх томов исследования (SUBSTRATE-MODELS §1–§10,
ALGORITHM-ATLAS §1–§23) в **один стек механизмов** с полной трассировкой:
каждый перенесённый результат школы → конкретный механизм → дизайн-документ →
функциональные/нефункциональные требования → гипотеза. Назначение: автономный
агент, читающий репозиторий, должен увидеть систему целиком — что уже решено,
что является экспериментальной ставкой (H-001…H-018) и где проходят честные
границы.

## 5. Честные границы системы (сводные)

1. **Квант:** никаких экспоненциальных ускорений для поиска/вывода; потолок
   OR — Θ(√n), симметричные функции — ~n/2 (AA §3). QuantumBackend — опция,
   не обещание.
2. **Неполнота:** ядро сознательно ограничено разрешимыми фрагментами; всё,
   что за пределом — внешняя верификация и объяснимый отказ, а не попытка
   «дожать» (AA §6, §8, §20). Это не баг, а конституционное решение (Статья VI).
3. **Противоречия:** не взрывают систему (изоляция, AA §11), но и не
   «разрешаются» молча — два сорта знания разведены структурно.
4. **Fuzzy:** никаких градаций истины в ядре; мягкость — только в интерфейсе
   читаемости (AA §22). Задокументированный отказ, а не пробел.
5. **Резервуар и декодер** — эмпирические ставки (H-015/H-016): при провале
   фиксируется отрицательный результат и fork-альтернатива, а не подгонка.
6. **Энергия:** числа 10⁴×–10⁶× — из прототипной энергометрии ops×нДж
   (H-009 accepted в своих границах); перенос на другие домены — только через
   новые пререгистрированные эксперименты (NFR-06).
