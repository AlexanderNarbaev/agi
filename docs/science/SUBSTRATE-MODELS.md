## 1. Конечные автоматы — за пределами автоматов Цетлина

### 1.1. FSM как BIR-артефакт с памятью
Конечный автомат (Мили/Мура) с k входами, s состояниями, m выходами — пара булевых функций: `δ: {0,1}ᵏ × {0,1}^⌈log₂s⌉ → {0,1}^⌈log₂s⌉` (переходы) и `λ: {0,1}^⌈log₂s⌉ × {0,1}ᵏ → {0,1}ᵐ` (выход).
- **Перенос:** любой FSM представим как BirNet из двух BirUnit (δ и λ), где регистр состояния живёт вне сети — в рабочей памяти M0 и подаётся на вход следующего такта (DESIGN-02 §2.1: рекуррентность только через память). Это закрывает класс «последовательностных» политик (план крафта, протоколы SCADA-переходов, диалоговые автоматы Persona) без нарушения DAG-инварианта.
- **Верификация:** эквивалентность двух FSM — через BDD-композицию (проверка δ/λ покомпонентно) + проверка достижимости состояний BFS по образу δ; недостижимые состояния — отчёт «мёртвый код автомата». Линт FSM-политик — обязательный шаг Φ-гейта для последовательностных Capability.
- **Метрика:** доля FSM-Capability с полностью достижимым пространством состояний; размер BDD-композиции δ∘λ (сторож 10⁶ узлов, DESIGN-01 §4.2).

### 1.2. Минимизация и факторизация
Классическая минимизация FSM (разбиение по эквивалентности состояний) и факторизация на последовательную/параллельную композицию меньших автоматов (теорема Крона–Родса: любой автомат раскладывается в каскад простых) — готовый инструмент MDL-рачета: минимизированный автомат имеет меньшую длину описания при той же функции.
- **Перенос:** офлайн-процедура `fsm_minimize` в конвейере консолидации (DESIGN-05 §4): кандидат на promote обязан быть минимальным автоматом; избыточные состояния = штраф Φ автоматически.

## 2. Свёрточные схемы — от CNN к свёрточной TM и весовым сетям без весов

### 2.1. Convolutional Tsetlin Machine
Свёрточная TM (Granmo et al.): одна и та же команда клауз применяется к окнам входа с разделяемыми автоматами; пространственная иерархия как у CNN, но с булевой интерпретируемостью; семейство TM поддерживает классификацию, свёртку, регрессию, обучение с подкреплением, автоэнкодеры и композиты [^208^].
- **Перенос:** BirNet с **разделяемой единицей** (одна CLAUSESET-единица, применённая к W окнам; shared-unit — уже поддержан «свёрткой изоморфных подсетей», DESIGN-02 §2.4). Схема ioSchema: окно, шаг, паддинг; голосование окон агрегируется TT-единицей.
- **Граница честности:** качество на сырых изображениях ниже CNN-фронтира (ANALYSIS §2, G-D); ниша — доменные «перцепты» (сетка мира, телеметрия), не фотографии.

### 2.2. Weightless Neural Networks (WiSARD → Bloom WiSARD → BTHOWeN → ULEEN)
WNN вычисляют **таблицами поиска**: базовый элемент — RAM-узел, n-входовая LUT с 2ⁿ однобитовыми ячейками; каждая перестановка содержимого LUT — уникальная булева функция, всего 2^(2ⁿ) функций на узел [^207^]. Обучение классически однопроходовое: при предъявлении адреса ячейка устанавливается в 1 — до 10⁴× быстрее DNN/SVM по времени обучения [^207^]. ULEEN (ACM TACO 2023) добавляет многопроходное обучение с обратной связью, ансамбли субмоделей и прунинг; FPGA-ускоритель: 0,21–0,94 мкс latency, 0,19–3,14 мкДж/инференс, превосходство над BNN-платформой FINN по энергии до 8,9× при сопоставимой точности [^207^].
- **Ключевое наблюдение:** RAM-узел WNN **в точности равен TT-форме BirUnit** (та же ёмкость 2^(2ⁿ), та же память 2ⁿ бит, тот же маппинг на FPGA LUT 1:1). Архитектурный выбор SPEC-002 §1 получает независимое индустриальное подтверждение с измеренными FPGA-числами — внешний ориентир для целей G2 (SPEC-002 FR-D2).
- **Перенос:** новый producer **`WnnTrainer`** (однопроходовый записывающий): ансамбль TT-единиц (k≤20, разреженная случайная связность по схеме с фиксированным seed) + bleaching/порогование для обобщения. Применение: (а) мгновенное предобучение домена на малом корпусе (один проход!), как стартовая точка до refine автоматами Цетлина (DESIGN-04 §2); (б) «мозжечковый слой» §5. Гипотеза H-010.
- **Связь с Bloom WiSARD:** счётные фильтры Блума как сжатое хранилище ячеек LUT — кандидатная техника для CLAUSESET-кэша M1 (помечено, не принято: вероятностная структура конфликтует с детерминизмом; решение — через EXP, не через дизайн).

## 3. Комбинаторика памяти — Sparse Distributed Memory (Канерва)

SDM (Kanerva 1988): адресное пространство {0,1}ⁿ огромно; физически существуют лишь разреженные «жёсткие локации»; запись идёт во **все** локации внутри радиуса Хэмминга r от адреса; чтение — голосование (по счётчикам, не битам) всех локаций радиуса; сходные адреса активируют пересекающиеся множества локаций → встроенное обобщение по сходству; ёмкость и радиус имеют точные оценки (радиус чтения оптимален вблизи 0,382·n для плотности 2⁻n/…, зависит от числа локаций).
- **Перенос:** M1-эпизодическая память (DESIGN-05 §3) уже использует Хэмминг-recall; SDM даёт ему строгую математику: (а) **счётчики вместо булевых свёрток** — агрегат эпизода хранит вектор целых (записи суммируются, чтение — порог), что алгебраически замыкает «забывание через затухание счётчиков» (полураспад счётчика = политика забывания с точной временной константой, не эвристикой); (б) **радиус как конфиг домена** (`memory.hamming-radius`, дефолт по формуле Канерва от n схемы); (в) **разреженные адреса**: схемы битов домена проектируются с контролируемой плотностью (0,1–0,3 единиц), что увеличивает различимость адресов — требование к PERCEPTION-кодировщикам (INV-P4, DESIGN-03).
- **Метрика (H-011):** precision@5 recall при SDM-чтении (счётчики+порог) vs плоский top-K Хэмминга на одном корпусе эпизодов; конфиг радиуса публикуется.

## 4. Числовая классификация знаний

### 4.1. Формальный анализ понятий (FCA, Гантер–Вилле)
Булев контекст (G, M, I): объекты G, атрибуты M, инциденция I. Замыкание Галуа порождает **решётку понятий**: каждое понятие = максимальная пара (объём ⊆ G, содержание ⊆ M); частичный порядок = иерархия обобщения; решётка строится точно (алгоритмы NextClosure и т.п.), без обучения.
- **Перенос:** реестр BIR-артефактов — уже булев контекст: объекты = артефакты/факты/эпизоды, атрибуты = биты ioSchema/witness/теги домена. Решётка понятий даёт: (а) **формальную иерархию доменов и компетенций** (поддомен = понятие-потомок) — основа классификатора доменов Медиатора (DESIGN-02 §6) и генерации Persona-структуры из данных, а не ручной конфигурации; (б) **импликации атрибутов** («witness-бит 7 всегда с битом 12») = кандидаты в FROZEN-инварианты домена и в клаузы CLAUSESET — точное, проверяемое извлечение правил; (в) редукцию контекста (удаление выводимых атрибутов) = MDL-сжатие схем памяти.
- **Связь со SPEC-003:** FCA-решётка — дискретный скелет графа знаний; Ricci-анализ работает на взвешенном графе, FCA — на точном контексте; несовпадение «понятийной» и «статистической» кластеризации = сигнал шумных рёбер (дополнительный канал детекции пробелов к FR-7 TDA).

### 4.2. Векторно-символические архитектуры (VSA/HDC) — разреженные направленные векторы
HDC/VSA (обзор: ACM CSUR 2022 [^212^]): сущности — векторы высокой размерности D (тысячи бит); операции: **bind** (у BSC — покомпонентный XOR; самообратен), **bundle** (мажоритарная сумма — суперпозиция множества), **перестановка** (кодирование порядка и ролей); сходство — расстояние Хэмминга; чтение структуры — unbind + clean-up по словарю [^207b^][^212^]. Разреженные варианты (SBDR, коды Куссула–Рачковского) с Context-Dependent Thinning сохраняют подмножество единичных компонент — «разреженные направленные коды» со структурной схожестью [^212^].
- **Перенос:** слой **составной семантики поверх битовых векторов проекта**. Все три операции — тривиальные BirNet: XOR-биндинг = поразрядная TT-единица k=2 (или одна инструкция); majority-bundle = TT/попсумм; перестановка = проводка, нулевая стоимость. Применения:
  1. **role-filler представление запроса**: «кто/что/кому/где» = bind(roleᵢ, fillerᵢ) → bundle — один D-битовый вектор, по которому memory_recall (§3) находит структурно похожие эпизоды, а не только лексически близкие;
  2. **направленные связи знаний**: bind(subject, predicate, object) с перестановкой ролей — числовое хранение направленных фактов в M2, декодируемое unbind'ом; направленность = порядок ролей (permutation), что и есть «направленные векторы»;
  3. **функциональные графы**: последовательность шагов BRC как bundle(ρⁱ·stepᵢ) — сжатая подпись цепочки для сходства трасс (детект «такой ошибки уже была» без полного сравнения цепочек).
- **Бюджет:** D = 8192 бит (1 КБ на вектор), словарь атомарных векторов версионируется как артефакт (детерминизм: генерация из seed в конфиге).
- **Честная граница:** VSA — представление и поиск по сходству, не рассуждение; логические гарантии остаются за BIR/BDD, VSA не подменяет верификацию (тот же статус, что у embed-hash в DESIGN-03).

## 5. Мозжечковый слой — быстрые преобразователи входа/выхода

### 5.1. Модель Марра–Албуса как адаптивный фильтр
Микросхема мозжечка (обзор Dean et al. 2010 [^210^]): вход (мшистые волокна) **расширительно перекодируется** в большой слой гранулярных клеток (expansion recoding в разреженное представление); выход — взвешенная сумма (клетки Пуркинье); обучение — по **учительскому сигналу ошибки** (восходящие волокна), ковариационное правило, теоретически минимизирующее среднеквадратичную ошибку (LMS); одна и та же схема работает для сенсорных и моторных задач — функция определяется внешними подключениями [^204^][^210^].
- **Перенос:** архитектурный слой **`ReflexLayer` (мозжечковый слой)** между PERCEPTION и DELIBERATION: быстрые, дёшево обучаемые преобразователи, которые (а) расширяют сырой сенсорный вектор в разреженный код большей размерности (повышает линейную/клауз-разделимость — гранулярный слой), (б) дают **рефлекторный ответ за микросекунды** для критичных контуров (SCADA: CONTINUE/WAIT/SHUTDOWN — прямой путь, минуя многошаговую делиберацию), (в) обучаются **офлайн по сигналу ошибки** — источник сигнала: расхождение предсказания и исхода в журнале событий (коррекции учителя DESIGN-04 §4 — прямой аналог climbing fiber).
- **Реализация:** CMAC (§5.2) или WNN-ансамбль (§2.2); форма артефакта — TT/CLAUSESET; статус после гейта — ACTIVE, для safety-рефлексов — FROZEN после сертификации (фазы MA, ARCHITECTURE §4).

### 5.2. CMAC (Albus 1975) — табличная аппроксимация функций
CMAC: вход отображается в перекрывающиеся рецептивные поля (ассоциативные ячейки); выход — сумма весов активных ячеек (табличный lookup); локальность отображения ускоряет обучение на порядки против глобальных сетей; две интерпретации — биологическая (модель мозжечка) и инженерная (table-referencing для real-time управления) [^201^][^211^].
- **Перенос:** producer **`CmacTrainer`**: весовая таблица по хэш-разложению входа на G перекрывающих решёток (G — конфиг обобщения); выход quantize'ится в m бит (пороги — артефакт). Свойства: локальное обучение (изменение затрагивает G ячеек — быстрая сходимость на потоке), детерминизм при фиксированном seed, полная читаемость таблицы (аудит). Роль: непрерывно-значные сенсорные предикторы и предиктор последствий действия (world model лёгкого класса: «состояние+действие → ожидаемое следующее состояние», вход MCTS, ARCHITECTURE §3.2).
- **Граница:** CMAC хранит вещественные веса → в BIR не входит как есть; публикуется как внешний офлайн-артефакт, а в рантайм BIR попадает после квантования в CLAUSESET/TT с измеренной fidelity (INV-3 компилятора DESIGN-01 §5). Либо вариант: бинарный CMAC поверх термометрического кода — тогда таблица сразу булева (WNN-эквивалент), fidelity 1,0.

## 6. Скопления нейронов для агентского взаимодействия

Комбинируемость кластеров (пользовательский запрос «скопления нейронов, которые можно комбинировать друг с другом для агентского взаимодействия») покрывается существующей иерархией DESIGN-02 §1 и уточняется здесь правилами композиции:

1. **Функциональная композиция** (BirNet∘BirNet): корректна iff схемы портов совпадают (контрактный тест); результат — Capability более высокого уровня; проверка — BDD-эквивалентность сплющивания для K≤20, иначе композиционная (DESIGN-02 §2.4).
2. **Суперпозиция** (bundle по §4.2): объединение эпизодического опыта нескольких кластеров в один вектор для cross-доменного recall; не создаёт новой логики — только поисковую структуру.
3. **Агентская композиция** (Persona ↔ Persona): взаимодействие только через контрактные вызовы (MCP/прокси, DESIGN-03 §5) с бюджетами и Guardrail на стыке; **запрещено** прямое слияние весов/таблиц двух обученных артефактов (семантика не определена — ловится ArchUnit); «комбинация знаний» двух агентов = импорт артефакта через pipeline M4 (подпись → Guardrail-аудит → CANDIDATE → гейты, DESIGN-05 §7).
4. **Ансамблевая композиция** (Viewpoint, DESIGN-02 §4): кластеры-эксперты одного домена с калиброванными весами; конфликт — детерминированная лестница.

### Новые гипотезы (регистрация в HYPOTHESES.md)

- **H-010:** однопроходовый WNN-producer (WiSARD-стиль, ансамбль TT-единиц) достигает точности в пределах 2 п.п. от TsetlinTrainer на структурированных доменных задачах при ≥10× меньшем wall-clock обучения — кандидат на роль «первого ответа» домена до refine (EXP-010).
- **H-011:** SDM-чтение M1 (счётчики + порог + радиус Канерва) даёт precision@5 recall выше плоского top-K Хэмминга при том же бюджете памяти на корпусе эпизодов владельца (EXP-011).

### Новые открытые вопросы (в OP-реестр не вносятся — инженерные)
- Плотность схем битов доменов: проектирование кодировщиков с целевой плотностью 0,1–0,3 (SDM/SBDR) — включить в приёмку PERCEPTION (INV-P4).
- Бинарный vs вещественный CMAC для world model: решение — через EXP-010/пилот, не через дизайн.

## 8. Советская школа алгоритмов — самоорганизация, потенциальные функции, алгебраический подход, алгебра автоматов

Проект уже стоит на автомате М. Л. Цетлина (SPEC-002, DESIGN-04). Этот раздел фиксирует остальные ветви советской школы распознавания и автоматов — они дают готовую теоретическую базу для новых механизмов DESIGN-07 (Cauldron, Viewpoint, композиция), изобретённых на полтора–два десятилетия раньше западных аналогов.

### 8.1. МГУА Ивахненко (ИК АН УССР, Киев) — предтеча Cauldron
Метод группового учёта аргументов (Ивахненко, с 1960-х): модель строится **самоорганизацией** — генерируются ряды функций нарастающей сложности (в базовом варианте — полиномы от пар признаков), из каждого ряда отбираются лучшие по **внешнему критерию** (точность на отложенной выборке, регулярность, баланс), отобранные становятся входами следующего ряда; рост прекращается, когда критерий перестаёт улучшаться [^220^][^221^]. Алгоритмы семейства: COMBI (полный перебор на малом числе аргументов), MULTI (многослойный итеративный), MIA/RIA (мультипликативно-итеративный).
- **Перенос (прямой):** это ровно конвейер Cauldron (DESIGN-07 §2): ряды нарастающей сложности → селекция внешним критерием Φ → рождение новых элементов → lineage. Внешний критерий Ивахненко ≡ Φ-гейт: оба требуют оценки кандидата на данных, **не участвовавших в его построении**. Отличие MATRIX: вместо полиномов — булевы конструкции (BirNet), вместо отложенной выборки одного вида — составной Φ (качество + энергия + MDL + refusal-поведение).
- **Заимствование в спецификацию:** правило остановки Cauldron формулируется как теорема внешнего критерия: «если лучший кандидат ряда r+1 не превосходит лучший кандидат ряда r по Φ — рост останавливается» (детерминированно, воспроизводимо, фиксируется в lineage).
- **Граница честности:** МГУА доказанно эффективен на малых выборках и интерпретируемых моделях, но на высокоразмерных задачах уступает современным градиентным методам; наша ниша — булевы домены малых/средних размерностей, где это преимущество, а не ограничение.

### 8.2. Метод потенциальных функций (Айзерман, Браверман, Розоноэр, ИПУ АН СССР, 1964–1970)
Рекуррентное обучение распознаванию: оценочная функция строится как сумма «потенциалов» от показанных объектов `K(x, xᵢ)` с рекуррентным обновлением при каждом новом предъявлении; по сути — первое системное изложение того, что позже стало ядерными методами (kernel trick) и онлайн-обучением [^222^][^223^]. Монография 1970 г. охватывает детерминированные и вероятностные постановки, сходимость, выбор потенциала.
- **Перенос:** (а) **онлайн-обучение без хранения корпуса** — рекуррентная схема обновления естественно ложится на протокол постоянного обучения (DESIGN-07 §5, фоновая активность): каждый новый эпизод M1 — один шаг рекуррентного обновления кандидата, без переобучения с нуля; (б) **ядровый взгляд на WNN:** отклик ансамбля RAM-узлов (H-010) алгебраически эквивалентен сумме потенциалов от предъявленных адресов — bleaching есть выбор функции потенциала. Это даёт теорию сходимости для однопроходового producer.
- **Граница:** сходимость доказана для классических условий (робастность к шуму потребует отдельного EXP).

### 8.3. Алгебраический подход Журавлёва и АВО (ВЦ АН СССР → ВЦ РАН; школа Хумсана, Ташкент/АН УзССР)
Алгоритмы вычисления оценок (Журавлёв, 1970-е): классификатор строится как **голосование ансамбля** «опорных» подфункций (по подмножествам признаков); поверх — корректирующая операция из заданного семейства. Алгебраический подход: задача — найти в алгебраическом замыкании семейства алгоритмов **экстремальный** (безошибочный на данном классе) алгоритм; доказана теорема о существовании корректного алгоритма в замыкании для любой корректной задачи. Развитая теория локальных алгоритмов — вычисление свойств объекта по локальной информации с границами сложности. Школа распространялась через семинары Хумсана в Ташкенте (АН УзССР, научная школа Кабулова) [^224^][^225^].
- **Перенос (прямой):** АВО ≡ механизм **Viewpoint** (иерархия DESIGN-02): ансамбль независимых оценщиков + корректирующая операция голосования — ровно то, чем Viewpoint собирает кластеры. Теорема об экстремальном алгоритме задаёт целевую функцию для Φ-оптимизации Cauldron: поиск корректного алгоритма = поиск экстремальной точки в алгебраическом замыкании базовых BirNet-операций. Локальные алгоритмы ≡ принцип доменной декомпозиции (каждая Capability вычисляется по локальному срезу битов).
- **Заимствование:** корректирующие операции АВО (взвешенные кворумы, пороги значимости) — кандидатные политики агрегации Viewpoint, подлежат сравнению через EXP при внедрении.

### 8.4. Алгебра автоматов Глушкова (ИК АН УССР, Киев)
«Синтез цифровых автоматов» (Глушков, 1961): систематические методы синтеза автоматов из абстрактной спецификации; затем — алгебра регулярных событий (система алгоритмических алгебр): автоматы и их композиции (последовательная, параллельная, обратная связь) образуют алгебру с операциями, допускающую эквивалентные преобразования и доказательство эквивалентности выражений [^226^][^227^][^228^].
- **Перенос (прямой):** это теоретический фундамент правил композиции кластеров (§6): четыре правила композиции BirNet — операции алгебры Глушкова над булевыми схемами; проверка эквивалентности через BDD — механизация его доказательственной техники. Перспектива: эквивалентные преобразования BirNet-выражений (перестановка/факторизация композиций) как легальные оптимизации, сохраняющие функцию — инструмент энергетической минимизации (NFR-01) без изменения поведения.

|---|---|---|
| МГУА Ивахненко | Cauldron (DESIGN-07 §2) | ряды сложности + внешний критерий ≡ Φ-гейт + правило остановки |
| Потенциальные функции (ИПУ) | постоянное онлайн-обучение (DESIGN-07 §5), WNN | рекуррентное обновление; теория сходимости bleaching |
| АВО Журавлёва / школа Хумсана | Viewpoint, Φ-оптимизация | голосование + корректирующие операции; экстремальные алгоритмы; локальные алгоритмы |
| Алгебра автоматов Глушкова | композиция кластеров (§6) | алгебраические эквивалентные преобразования композиций; синтез из спецификации |
