# Baseline-протокол: Дуальность и рационализаторское зерно

**Статус: living** · Preregistered baseline protocol для H-023…H-026 (EXP-019).
**Дата:** 2026-08-10
**Назначение:** Зафиксировать baseline-модели ДО запуска эксперимента. Без baseline результаты не интерпретируемы (CONSTITUTION VI.3).

---

## Принципы

1. **Без ML-моделей.** Все baseline — детерминированные статистические процедуры (CONSTITUTION VII.1: Python lab-only; анализ — за пределами рантайма).
2. **Воспроизводимость.** Каждый baseline имеет фиксированный seed и детерминирован.
3. **Прогрессивная сложность.** Baseline-линейка: Random → Majority → Single-Attribute → (опционально) Linear.

---

## B1: Random Baseline

**Описание:** Случайный предсказатель. Для каждой метрики генерирует равномерное случайное значение в допустимом диапазоне.

**Метрики:**

| Метрика | Random Baseline | Смысл |
|---|---|---|
| Δ-confidence (D-axis) | 0 ± noise | Случайный классификатор не различает D-полюса |
| ROC-AUC | 0.50 (95% CI: [0.47, 0.53] при n≥200) | Случайная догадка |
| RAT-индекс (mean) | 0 | Нет систематического сдвига уверенности |
| Spearman ρ(RAT, conformity) | 0 | Нет связи |
| Spearman ρ(RAT, essentialism) | 0 | Нет связи |
| Conformity (mean) | Зависит от распределения ответов | Ожидаемое значение при случайных ответах = 0.20 (равномерное распределение по 5-point Likert) |

**Реализация (псевдокод):**
```python
# Фиксированный seed для воспроизводимости
seed = 42
rng = random.Random(seed)

def random_baseline_auc(n_judgments):
    # Генерируем случайные confidence и случайные D-метки
    y_true = [rng.randint(0, 1) for _ in range(n_judgments)]
    y_score = [rng.random() for _ in range(n_judgments)]
    return roc_auc_score(y_true, y_score)
    # Ожидаемое значение: ~0.50
```

**Критерий превосходства над baseline:** Экспериментальный AUC должен быть значимо выше 0.50 (permutation test, p < 0.05).

## B2: Majority Baseline

**Описание:** Всегда предсказывает наиболее частый класс (по D-axis: 0 или 1). Использует prior-распределение ответов для каждого statement.

**Метрики:**

| Метрика | Majority Baseline | Смысл |
|---|---|---|
| ROC-AUC | 0.50 (не различает классы) | Majority не даёт информации о D-полюсе |
| Δ-confidence | 0 (одинаковая уверенность для всех) | Нет дифференциации по D-оси |
| Conformity prediction | Всегда мода | Верхняя граница конформности |
| RAT prediction | 0 (нет сдвига уверенности) | Нет рационализации |

**Примечание:** Majority baseline полезен как верхняя граница для conformity-метрики: conformity реальных респондентов не может быть ВЫШЕ, чем majority (по определению conformity как близости к majority).

**Реализация:**
```python
def majority_baseline_conformity(responses):
    # responses: list of int (1-5 Likert)
    from collections import Counter
    mode = Counter(responses).most_common(1)[0][0]
    return mean([1 - abs(r - mode) / 4 for r in responses])
```

## B3: Single-Attribute Baseline

**Описание:** Предсказывает D-полюс суждения, используя ТОЛЬКО один D-атрибут (без учёта confidence). Проверяет, не объясняется ли асимметрия простым знанием ground truth одного атрибута.

**Метрики:**

| Метрика | Single-Attribute Baseline | Смысл |
|---|---|---|
| ROC-AUC (per D_i) | AUC = 1.0 для D_i, ~0.50 для остальных | Если реальный AUC ≈ 1.0, асимметрия тривиальна |
| Δ-confidence (D_i) | Должен коррелировать с другими D_j? | Проверка избыточности D-атрибутов |

**Процедура:**
1. Для каждого D-атрибута D_i (i ∈ {1,2,3,4}):
   - Взять ground truth D_i как предсказание
   - Оценить AUC для различения D_j (j ≠ i) по confidence
   - Если D_i предсказывает D_j с AUC > 0.50 → атрибуты не независимы

**Preregistered ожидание:** D-атрибуты должны быть слабо коррелированы (ρ < 0.3 между D_i и D_j для i ≠ j). При нарушении — reduction через PCA или удаление избыточного атрибута до анализа H-023.

---

## B4: Линейный baseline (опциональный, необязательный)

**Описание:** Линейная регрессия confidence по D-атрибутам (без взаимодействий). Проверяет, не является ли асимметрия простым линейным эффектом.

```
C_pre ~ D1 + D2 + D3 + D4
```

**Метрика:** R² линейной модели. Если R² < 0.05 → D-атрибуты не объясняют confidence линейно → асимметрия (если есть) нелинейна.

| Baseline | AUC ожидаемый | Δ-confidence ожидаемый | RAT ожидаемый | Использование |
|---|---|---|---|---|
| B1: Random | 0.50 | 0 | 0 | Нижняя граница: любой результат должен быть значимо лучше |
| B2: Majority | 0.50 | 0 | 0 | Верхняя граница conformity |
| B3: Single-Attribute | ~1.0 (на своём атрибуте) | — | — | Проверка независимости D-атрибутов |

## Процедура оценки (preregistered)

1. **До вскрытия ground truth:**
   - Запустить все baseline (B1–B3, опционально B4)
   - Зафиксировать baseline-значения метрик
   - Сохранить seed'ы и хеши конфигураций

2. **После сбора данных (не ранее):**
   - Сравнить экспериментальные метрики с baseline
   - Для H-023: экспериментальный AUC vs B1 random (permutation test)
   - Для H-024: экспериментальный RAT vs B1 random (one-sample bootstrap)
   - Для H-025: I² гетерогенности между корпусами

3. **Правило принятия:**
   - Экспериментальная метрика должна быть значимо (p < 0.05, FDR-скорректированное) лучше baseline
   - Если не лучше — гипотеза НЕ подтверждена (неубедительность = опровержение, CONSTITUTION VI.3)
