## EXP-009C 2026-08-26 — GPU-нога (RTX 5070 Ti Laptop, torch 2.12.1+cu130, fp32)

Та же функция учителя (веса из teacher.onnx), N=2000:

| Инференс | Время |
|---|---|
| GPU батч 2000 (200 повторов) | **0.0200 мс** |
| GPU per-call одиночный | **17.25 µs** |
| MATRIX BIR CPU батч 2000 | 0.125 мс (~62 нс/eval) |
| ORT CPU батч 2000 | 18.68 мс |

**Честный вывод:** GPU выигрывает крупнобатчевый throughput (×6.25 против BIR); **MATRIX BIR выигрывает per-call латентность ~×276** (17.25 µs против ~62 нс) — на малых скомпилированных артефактах накладные расходы ядра CUDA доминируют. Это и есть тезис проекта: компилированная булева функция ≈ бесплатный инференс для точечных решений.
