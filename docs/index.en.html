The BIR Paradigm

BIR (Boolean Intermediate Representation) is the central concept of MATRIX. Every Boolean function in the system is stored in one of three equivalent forms, which are mutually compilable and mechanically verifiable:

BirUnit = (id, k, m, form, payload, header) — DESIGN-01

TT — Truth Table

f: {0,1}^k → {0,1}

Exhaustive truth table. Stores 2k bits — all possible input combinations.

Capacity: 22k functions. At k=20 (K_MAX): 128 KB per unit, 1.05M functions.

Best for: k ≤ 20, guaranteed correctness, BDD/CLAUSESET equivalence.

CLAUSESET — DNF with Tsetlin automata

f = ⋁i=1..C Li

Disjunctive Normal Form. Learning via Tsetlin automata (interact & reward).

Complexity: ≤(3k+1)C DNF; PAC bound n ≳ (Ck·ln3 + ln(1/δ))/ε².

Best for: sparse rules, large k (784 for MNIST), data-driven learning.

BDD — Reduced Ordered BDD

ROBDD (Bryant, 1986)

Canonical compact form. Equivalence verified mechanically: enumeration of 2k inputs.

Ceiling: Parity of k variables needs 2k-1 clauses → for large k use TT or XOR network.

Best for: compact storage, formal verification, Model Checking.

Three forms compile into each other (BirCompiler, SPEC-002), and equivalence is verified by a single command.

Key Principles

🔍 Determinism

Every decision is a verifiable Boolean chain. Identical state and input always produce identical output. No LLM in runtime (CONSTITUTION, Article III).

🛡️ FROZEN Layer FROZEN

Ethical and domain constraints are immutable at the FROZEN layer. 6 axioms, structurally unchangeable, formally verifiable. Any modification attempt is rejected automatically.

⚡ Energy Efficiency

BIR: 0.64 ns per TT evaluation (k=10). Neuron: 197M ops/s. 4-5 orders more efficient than LLMs. Runs on laptop and FPGA.

🧬 Interpretability

Every decision is a tree of logical rules. No "black boxes". MonotoneDecoder explains any circuit via maximal upper zero (DESIGN-09).

🌐 Decentralization

Anyone can run an instance. Knowledge synchronizes via Noosphere (CRDT + Kafka + WebSocket). Mesh Federation guarantees BFT consensus.

📚 Ethics by Design

Three prohibitions (don't kill, don't torture, don't enslave) are in FROZEN layer. EthicalFilter rejects command before execution. Guardrail FPR 0% / TPR 100% (H-006).

Implemented Algorithms

RUN

BIR-classifier (H-009)

Binary classifier on BIR. Parity with LLM ≤3B (±3 p.p. balanced accuracy) at ≥10⁴× less energy on laptop.

RUN

WNN/WiSARD (H-010)

Single-pass ensemble of TT-units. WiSARD-style: address-RAM. Accuracy ±2 p.p. vs TsetlinTrainer at ≥10× faster training.

RUN

SDM/Kanerva (H-011)

Sparse Distributed Memory: counters + threshold + radius. Precision@5 ≥+5 p.p. vs flat top-K Hamming at same budget.

RUN

intESN / Binary Reservoir (H-015)

VSA-state + permutation recurrence + TT/WNN-readout. Fixed seed. Accuracy ±3 p.p. vs float-ESN at ≥10× less energy.

RUN

MonotoneDecoder (H-016)

Identification of monotone Boolean functions by maximal upper zero circuit. ≥5× less corpus vs TsetlinTrainer on monotone domains.

RUN

LTL Model Checker (H-017)

Formalization of DESIGN-07/08 in LTL + bounded model checking. Detects violations not covered by AT-* acceptance tests. Pnueli school.

RUN

GUHA + Levin (H-018, H-019)

Systematic candidate generator (Hájek–Havránek) + optimal budget scheduler 2-l. Coverage per joule ≥+15% vs uniform schedule.

RUN

LearnedMinecraftPilot (H-005)

Minecraft pilot learning through evolutionary Developmental Loop. −30% time vs random at not worse accuracy.

RUN

MeshFederation (M4)

CRDT + QuorumChecker (3/5 BFT) + Kafka + WebSocket. Distributed FNL sync without central server.

DONE

Guardrail FPR/TPR (H-006)

FPR 0%, TPR 100%, P99 latency 0 ms. Targets (≤5%, ≥95%, ≤50ms) achieved.

Quick Start

git clone https://github.com/AlexanderNarbaev/agi.git
cd agi
./gradlew build
./gradlew test                          # all 1055+ tests
./gradlew :matrix-core:jacocoTestReport # coverage report
./gradlew :matrix-core:quarkusBuild -Dquarkus.package.jar.type=uber-jar
java -jar matrix-core/build/*-runner.jar demo

Run GridWorld simulation (BIR-agent evolution):

Distill HuggingFace weights → BIR:
