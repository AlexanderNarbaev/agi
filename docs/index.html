Парадигма BIR

BIR (Boolean Intermediate Representation) — это центральная концепция MATRIX. Каждая булева функция в системе хранится в одной из трёх эквивалентных форм, которые взаимно компилируемы и механически верифицируемы:

BirUnit = (id, k, m, form, payload, header) — DESIGN-01

TT — Truth Table

f: {0,1}^k → {0,1}

Исчерпывающая таблица истинности. Хранит 2k бит — все возможные входные комбинации.

Ёмкость: 22k функций. При k=20 (K_MAX): 128 КБ на единицу, 1.05M функций.

Лучше для: k ≤ 20, гарантированная корректность, эквивалентность BDD/CLAUSESET.

CLAUSESET — DNF с автоматами Цетлина

f = ⋁i=1..C Li

Дизъюнктивная нормальная форма. Обучение автоматами Цетлина (interact & reward).

Сложность: ≤(3k+1)C DNF; PAC-оценка n ≳ (Ck·ln3 + ln(1/δ))/ε².

Лучше для: разреженные правила, большое k (784 для MNIST), обучение на данных.

BDD — Reduced Ordered BDD

ROBDD (Bryant, 1986)

Каноническая компактная форма. Эквивалентность проверяется механически: перечислением 2k входов.

Потолок: Паритет k переменных требует 2k-1 клауз → для больших k используется TT или сеть XOR.

Лучше для: компактное хранение, формальная верификация, Model Checking.

Три формы компилируются друг в друга (BirCompiler, SPEC-002), и эквивалентность проверяется одной командой.

Ключевые принципы

🔍 Детерминизм

Каждое решение — проверяемая булева цепочка. Идентичное состояние и вход всегда дают идентичный выход. Никаких LLM в рантайме (CONSTITUTION, Статья III).

🛡️ FROZEN-слой FROZEN

Этические и доменные ограничения иммутабельны на уровне FROZEN-слоя. 6 аксиом, структурно неизменяемые, формально верифицируемые. Любая попытка модификации отклоняется автоматически.

⚡ Энергоэффективность

BIR: 0.64 нс на оценку TT (k=10). Neuron: 197M ops/s. На 4-5 порядков экономичнее LLM. Работает на ноутбуке и в FPGA.

🧬 Интерпретируемость

Каждое решение — дерево логических правил. Никаких «чёрных ящиков». MonotoneDecoder объясняет любую схему максимальным верхним нулём (DESIGN-09).

🌐 Децентрализация

Любой может запустить инстанс. Знания синхронизируются через Noosphere (CRDT + Kafka + WebSocket). Mesh Federation гарантирует консенсус при BFT.

📚 Этика по конструкции

Три запрета (не убий, не пытай, не порабощай) — в FROZEN-слое. EthicalFilter отклоняет команду до выполнения. Guardrail FPR 0% / TPR 100% (H-006).

Реализованные алгоритмы

RUN

BIR-classifier (H-009)

Бинарный классификатор на BIR. Паритет с LLM ≤3B (±3 п.п. balanced accuracy) при ≥10⁴× меньшей энергии на ноутбуке.

RUN

WNN/WiSARD (H-010)

Однопроходовый ансамбль TT-единиц. WiSARD-стиль: RAM по адресу. Точность ±2 п.п. от TsetlinTrainer при ≥10× быстрее обучения.

RUN

SDM/Kanerva (H-011)

Sparse Distributed Memory: счётчики + порог + радиус. Precision@5 ≥+5 п.п. vs плоский top-K Hamming при том же бюджете.

RUN

intESN / Binary Reservoir (H-015)

VSA-состояние + перестановочная рекуррентность + TT/WNN-readout. Fixed seed. Accuracy ±3 п.п. от float-ESN при ≥10× меньшей энергии.

RUN

MonotoneDecoder (H-016)

Идентификация монотонных булевых функций по схеме максимального верхнего нуля. ≥5× меньше корпуса vs TsetlinTrainer на монотонных доменах.

RUN

LTL Model Checker (H-017)

Формализация DESIGN-07/08 в LTL + bounded model checking. Обнаруживает нарушения, не покрытые приёмочными тестами AT-*. Школа Пнуэли.

RUN

GUHA + Levin (H-018, H-019)

Систематический генератор кандидатов (Hájek–Havránek) + оптимальный планировщик бюджетов 2-l. Покрытие на джоуль ≥+15% vs равномерное расписание.

RUN

LearnedMinecraftPilot (H-005)

Обучение пилота Minecraft через эволюционный цикл Developmental Loop. −30% времени vs random при нехудшей точности.

RUN

MeshFederation (M4)

CRDT + QuorumChecker (3/5 BFT) + Kafka + WebSocket. Распределённая синхронизация FNL без центрального сервера.

DONE

Guardrail FPR/TPR (H-006)

FPR 0%, TPR 100%, P99 latency 0 мс. Цели (≤5%, ≥95%, ≤50ms) достигнуты.

Быстрый старт

git clone https://github.com/AlexanderNarbaev/agi.git
cd agi
./gradlew build
./gradlew test                          # все 1055+ тестов
./gradlew :matrix-core:jacocoTestReport # отчёт покрытия
./gradlew :matrix-core:quarkusBuild -Dquarkus.package.jar.type=uber-jar
java -jar matrix-core/build/*-runner.jar demo

python scripts/pretrain_neurons.py --architecture llama --layers 6
