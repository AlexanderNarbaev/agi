# DESIGN-10 — Бинарный резервуар (intESN)

**Статус: normative** · пересмотр 2026-08-26 (v2 rebuild).

## Что

Нетренируемое бинарное рекуррентное ядро для рефлекторного слоя M0. Гипервектора D=8192, сдвиг по времени. Readout (TT/WNN) обучается за один проход.

## Реализация

`tsetlin/IntEsNetwork` (K-9 статус H-015 running). Bundle+циклический сдвиг + упакованное хранение, всё в `long[]`.

## Метрики / гейты

Не измерено (H-015 running); отложено до EXP-015.
