# DESIGN-NN — Core Knowledge (Spelke / Spitz-Sokolov) (R-D neuroscience)

> TRUE-W11 research-engine iteration #6.
> Domain: early-learning neuroscience.
> Source: Spelke, E. (1990) "Principles of object perception"
>         Spitz-Sokolov, Y. (1948) "Восприятие и его роль в развитии..."

## Goal

Implement a tiny **core-knowledge base** with three innate primitives
that Spelke identifies as universal across human infants:
1. **Object permanence** — objects persist through time
2. **Continuity** — objects move on continuous paths  
3. **Contact** — objects act on each other only through contact

These can guard the mind from generating physically-incoherent
responses (e.g. "the ball flew away without being touched").
