
## Sync Issue: gitverse Shallow Clone

When trying to push to `gitverse` remote for the first time, encountered:
```
! [remote rejected]   main -> main (shallow update not allowed)
```

This is a server-side constraint on the gitverse repo (created as shallow clone).
Cannot be resolved locally. Owner action required from gitverse web UI:

1. Go to https://gitverse.ru/AlexandrNarbaev/agi/settings
2. Navigate to Repository settings
3. Look for "Shallow clone" or "History depth" option
4. Disable it / set depth to 0 (full history)
5. Save settings

After this, the next wave commit will push to both remotes successfully.
