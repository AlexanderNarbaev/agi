## File: `docs-v2/tla/FederationConsensus.tla`

### Constants

- `L0` through `L7` — capability levels
- `Weight` — function mapping level → voting weight
- `STANDARD_THRESHOLD` — approval threshold (0.67)

### Variables

- `votes` — set of votes cast
- `status` — current consensus status (PENDING/APPROVED/REJECTED/VETOED)

### Safety Properties (Theorems)

1. **VetoInvariance**: `HasVeto => status = "VETOED"`
   — L7 VETO always produces VETOED status

2. **ApprovalThreshold**: `status = "APPROVED" => YesRatio >= STANDARD_THRESHOLD`
   — APPROVED requires ≥ 67% weighted YES

3. **WeightMonotonic**: `TotalWeight = TotalYesWeight + TotalNoWeight`
   — Total weight = sum of YES + NO weights

4. **VetoOverridesApproval**: `~((status = "VETOED") /\ (status = "APPROVED"))`
   — VETO and APPROVED are mutually exclusive

### State Machine

```
Init → CastVote(v) → Evaluate → {APPROVED | REJECTED | VETOED | PENDING}
```

### Invariants Verified

- TypeOK — votes are well-formed Vote tuples
- VetoInvariance — VETO always wins
- ApprovalThreshold — APPROVED requires sufficient YES weight
- WeightMonotonic — total weight is consistent
- VetoOverridesApproval — VETO and APPROVED never coexist
