## Features Added

### `loadPriorHistory(sessionId, history)`
- Scans `data/conversations/<sessionId>.ndjson`
- Parses role + content from each line
- Appends user/assistant messages to existing history
- Skips malformed lines (graceful)

### `listRecentSessions(max)`
- Lists NDJSON files in `data/conversations/` sorted by mtime
- Filters out hidden files (start with `.`)
- Default: returns top 10

### `--list-sessions` CLI flag
- `java io.matrix.cli.RealConversationCli --list-sessions 5`

### JSON Parser
- Hand-written `extractJsonField(json, fieldName)` 
- Handles escaped quotes, newlines, backslashes
- Avoids dependency on full JSON library
