## Objective
Create `BiochemicalMediator` class that reads modulator definitions from
the federation runtime and exposes them as typed value maps for cognitive
layers (attention, arousal, plasticity, etc).

## Class: `io.matrix.federation.integration.BiochemicalMediator`

### Snapshot Record

```java
public record MediatorSnapshot(
    Map<String, Float> hormoneLevels,
    Map<String, Float> neurotransmitterLevels,
    Map<String, Float> signalLevels,
    long timestampNs,
    int totalModulators
) {}
```

### Methods

- `refreshFromRegistry()` — re-read all modulators
- `getValue(String id)` — Optional<Float> for one modulator
- `setLocalValue(String id, float value)` — local override (caller responsible for proposing)
- `snapshot()` — MediatorSnapshot categorized by type
- `getAllValues()` — flat map of all values
- `getCategoryCounts()` — count per ModulatorType
- `getUpdateCount()`, `getRuntime()`, `getRng()`

### CONSTITUTION Compliance

- **Article I v3:** Seeded Random exposed via `getRng()`
- **Article II:** No voting logic here — read-only bridge
- **Article IV:** Reads FROZEN modulators but does not allow mutation
- **Article VI:** Pure value map, no subjective state
