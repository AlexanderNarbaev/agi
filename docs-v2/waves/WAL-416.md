## Features

- **Terminal-styled** dark theme (black + green)
- **Session continuity** via localStorage
- **Multi-turn conversation** with chat bubbles
- **Loading states** with disabled button
- **Message history** loaded from local session
- **No external dependencies** — pure HTML/CSS/JS
