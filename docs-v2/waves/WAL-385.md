### FAIL-8: BiochemicalMediator.snapshot totalModulators misleading

- **Issue:** `totalModulators = activeValues.size()` included local-only overrides
  from `setLocalValue` for IDs not in the registry
- **Fix:** Use `runtime.getRegistryStore().size()` instead
- **Test:** Added `testTotalModulatorsReflectsRegistryNotLocalOverrides`

### FAIL-9: Random rng fields documentation
- **Files:** 5 classes with `private final Random rng`
- **Issue:** Fields allocated but never used internally; only exposed via `getRng()`
- **Fix:** Added Javadoc explaining purpose: "Deterministic RNG (seeded).
  Reserved for tie-breaking and downstream stochastic sampling. Exposed via
  getRng() for callers that need it."
- **Note:** Fields kept (removing would be breaking API change)
