## Class: `io.matrix.brain.BrainServer`

### Verified WORKING
```
$ curl http://localhost:9200/health
{"status":"ok","service":"brain-server"}

$ curl http://localhost:9200/info
{"kb_size":4,"model":"qwen2.5-0.5b"}

$ curl -X POST -d '{"message":"What is the capital of France?"}' http://localhost:9200/chat
{"message":"What is the capital of France?","reply":"The capital of France is Paris...", "confidence":0.718}
```

### Endpoints
- `GET /health` - health check
- `GET /info` - KB size + model info
- `POST /chat` - real Qwen response with RAG

### Usage
```bash
java io.matrix.brain.BrainServer [port] [model-path]
Default port: 9100
```
