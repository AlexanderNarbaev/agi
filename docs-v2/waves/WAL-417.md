## New HTTP endpoint

### `GET /history?sessionId=X&limit=N`

Returns the last N turns of a session as JSON.

### Verified
```
$ curl -s "http://localhost:9096/history?sessionId=w403-test&limit=10"
{
  "sessionId":"w403-test",
  "turns":[
    {"conversationId":"w403-test","role":"user","content":"What is your name?",...},
    {"conversationId":"w403-test","role":"assistant","content":"I am not a person...",...},
    {"conversationId":"w403-test","role":"user","content":"And who created you?",...},
    {"conversationId":"w403-test","role":"assistant","content":"I am an artificial intelligence...",...}
  ]
}
```
