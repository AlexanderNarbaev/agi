### Usage
```
java io.matrix.cli.ConversationSummarize <session-id> [model-path]
```

### Features
- Loads Qwen2.5-0.5B model
- Sends session content with "Summarize this conversation" prompt
- Returns 1-2 sentence summary
- Custom model path support

### Implementation
- Extracts user/assistant turns from NDJSON
- Builds conversation transcript
- Sends as single prompt to Qwen
- Outputs AI-generated summary
