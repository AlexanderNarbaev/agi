## Objective
Expose the real conversation CLI over HTTP for integration with
other tools (browsers, bots, agents).

## Class: `io.matrix.cli.RealConversationServer`

### Endpoints
- `GET /health` → `{"status":"ok","service":"real-conv"}`
- `GET /sessions` → JSON list of recent sessions
- `POST /chat` → `{"sessionId":"...", "reply":"...", "priorTurns":N}`

### Tech
- Uses Java's built-in `com.sun.net.httpserver.HttpServer`
- No Quarkus, no framework — pure JDK
- 4-thread executor
- Shutdown hook for graceful close

### Verified Working

```
$ curl http://localhost:9093/health
{"status":"ok","service":"real-conv"}

$ curl http://localhost:9093/sessions
{"sessions":["cli-1789817338693","cli-1789817200648","2026-09-04","2026-08-31","2026-08-30","2026-08-28","2026-07-20"]}

$ curl -X POST -H "Content-Type: application/json" \
    -d '{"message":"What is 2+2?","sessionId":"http-w394"}' \
    http://localhost:9093/chat
{"sessionId":"http-w394","reply":"2+2 is equal to 4.","priorTurns":0}
```

### Performance
- First request: ~1.9s (model warmup)
- Subsequent requests: ~2-3s (CPU inference)
