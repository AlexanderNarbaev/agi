### Features
- Styled HTML (dark theme matching web UI)
- Per-turn color coding (user=blue, assistant=green)
- Bookmark display (golden boxes)
- Summary section with turn counts and timestamps
- Self-contained (no external CSS/JS)

### Usage
