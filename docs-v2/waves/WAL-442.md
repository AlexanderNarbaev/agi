### Features
- HTTP server on port 9094 (configurable)
- `/` — serves streaming chat UI (HTML + JS)
- `/chat` — standard JSON response
- `/stream` — SSE with token-by-token delivery
- Records all turns to NDJSON

### Endpoints

- `GET /` — Streaming chat page (HTML)
- `POST /chat` — Standard chat (`{"message":"...","sessionId":"..."}`)
- `GET|POST /stream?msg=...` — SSE with events `chunk` and `done`
