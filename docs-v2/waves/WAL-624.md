## Alert Rules

```yaml
# Prometheus alert rules
groups:
  - name: matrix_alerts
    rules:
      - alert: HighErrorRate
        expr: rate(http_requests_total{status=~"5.."}[5m]) > 0.1
        for: 5m
        labels:
          severity: critical
        annotations:
          summary: "High error rate detected"

      - alert: HighLatency
        expr: histogram_quantile(0.99, rate(http_request_duration_seconds_bucket[5m])) > 1
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "High latency detected"

      - alert: NodeDown
        expr: up{job="matrix-node"} == 0
        for: 1m
        labels:
          severity: critical
        annotations:
          summary: "Node is down"
```
