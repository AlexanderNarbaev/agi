## Bug Found & Fixed

`LocalConsensusEngine.evaluate()` was using `boolean vetoed = false` and
returning early after first VETO. **Fixed**: now counts all vetoes with
`int vetoCount = 0`, incremented per VOTE_VETO vote.

Updated `LocalConsensusEngineTest` and `FederationPropertyTest` still pass
with the new behavior.
