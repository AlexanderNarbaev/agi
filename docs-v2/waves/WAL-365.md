1. **vetoAlwaysOverrides** — L7 VETO always → VETOED status
2. **emptyVotesIsPending** — no votes → PENDING
3. **allYesIsApproved** — all YES with weight → APPROVED
4. **allNoIsRejected** — all NO → REJECTED
5. **weightMonotonic** — total = YES + NO weight sums
6. **approvalRatioInBounds** — ratio ∈ [0, 1]
7. **l0L1VotesAreIgnored** — zero-weight votes don't contribute
8. **vetoOverridesAllCounts** — any YES + VETO → VETOED
9. **seedDeterministicSameResult** — same seed → same Random
10. **voteCountMatchesAdded** — vote count = votes added
