## Class: `io.matrix.cli.ConversationName`

### Verified
```
$ java io.matrix.cli.ConversationName w403-test "philosophy discussion"
Set name for w403-test: philosophy discussion

$ java io.matrix.cli.ConversationName --read w403-test
philosophy discussion

$ java io.matrix.cli.ConversationName --remove w403-test
Removed name from: w403-test
```

### Usage
```
java io.matrix.cli.ConversationName <session> <new-name>  # Set
java io.matrix.cli.ConversationName --read <session>      # Read
java io.matrix.cli.ConversationName --remove <session>    # Remove
```

### Implementation
- Names stored in first line of NDJSON as `# META name: <name>`
- Comment lines are ignored by other conversation readers
