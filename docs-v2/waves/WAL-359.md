## Class: `io.matrix.federation.consensus.LocalConsensusEngine`

### Voting Weights (per DESIGN-67)

| Level | Weight |
|-------|--------|
| L0_INFANT | 0.0 (no vote) |
| L1_LEARNER | 0.0 (no vote) |
| L2_ADULT | 1.0 |
| L3_SPECIALIST | 1.5 |
| L4_EXPERT | 2.0 |
| L5_MASTER | 3.0 |
| L6_ARCHITECT | 5.0 |
| L7_GUARDIAN | 10.0 + VETO |

### Thresholds

- Standard: 67% weighted approval
- Critical (safety): 80%
- Emergency: 50% + 2× L7 confirmation

### Methods

- `addVote(ConsensusVote)` — record a vote
- `evaluate(ConsensusProposal)` — compute ConsensusResult
- `createVote(proposalId, decision, level, confidence)` — helper to build a vote
- `getVotingWeight(CapabilityLevel)` — static lookup
- `getVoteCount()`, `getL7ConfirmationCount()` — counters
- `reset()` — clear votes for new proposal

### Veto Semantics

- L7 VETO always wins (overrides any YES majority)
- Counts separately from weighted votes
- Returns CONSENSUS_VETOED status

### CONSTITUTION Compliance

- **Article I v3 (Stratified Stochasticity):** Uses seeded Random for any tie-breaking
- **Article II (Consensus):** Voting weights are formal and encoded in code
- **Article VI (no consciousness claim):** Pure algorithm, no subjective state
