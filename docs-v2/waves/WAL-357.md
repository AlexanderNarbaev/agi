## Approach

**Problem:** `com.google.protobuf` gradle plugin (v0.9.4) is incompatible with
`org.graalvm.buildtools.native` (v1.1.10) — fails with "Configuration with name
'native-testCompileOnly' not found".

**Solution:** Manual code generation:
1. Download `protoc` 25.5 binary from GitHub
2. Run `protoc --java_out` against `proto/matrix_federation_v1.proto`
3. Move generated files to `matrix-core/src/generated/java/io/matrix/federation/proto/`
4. Add `protobuf-java:3.25.5` dependency to `matrix-core/build.gradle`
5. Add `srcDir 'src/generated/java'` to sourceSets
