## Class: `io.matrix.chat.MatrixChatClient`

### Usage (in your own Java app)

```java
MatrixChatClient client = MatrixChatClient.builder()
    .modelPath("models/onnx/qwen05b")
    .dataDir("data/conversations")
    .build();

String reply = client.chat("user-123", "Hello!");

List<Turn> history = client.getHistory("user-123");
client.deleteSession("user-123");
client.close();
```

### Features
- Builder pattern for configuration
- Session continuity (loads prior turns)
- NDJSON persistence (no Quarkus needed)
- getHistory() to retrieve past turns
- deleteSession() for cleanup
- Builder options: modelPath, dataDir, useGpu, maxNewTokens

### API Methods

| Method | Purpose |
|--------|---------|
| `chat(sessionId, message)` | Send message, get response |
| `getHistory(sessionId)` | Get all turns for session |
| `deleteSession(sessionId)` | Remove session file |
| `close()` | Release model resources |
