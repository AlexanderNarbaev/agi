## Class: `io.matrix.cli.ConversationBenchmark`

### Usage
```
java io.matrix.cli.ConversationBenchmark [iterations] [model-path]
```

### Features
- 5 test prompts, configurable iterations
- Measures total time, avg time, throughput
- Shows tokens/second
- Reports min/max latency
