### TelemetrySnapshot Record

```java
public record TelemetrySnapshot(
    int totalEvents,
    Map<String, Integer> eventCountsByType,
    Map<String, Integer> proposalCountsByStatus,
    Map<String, Integer> voteCountsByDecision,
    int registryMutations,
    long snapshotTimestampNs
) {}
```

### Methods

- `recordProposal(String status)` — count proposals by status
- `recordVote(String decision)` — count votes by decision
- `recordMutation()` — count registry add/update/remove
- `buildEvent(String type, String nodeId, String value)` — ProtoBuf TelemetryEvent
- `snapshot()` — TelemetrySnapshot aggregated
- `reset()` — clear all counters
- `getTotalEventCount()`, `getRng()`

### Thread Safety

- `AtomicInteger` for totalEvents + registryMutations
- `ConcurrentHashMap` for all event/proposal/vote counters

### CONSTITUTION Compliance

- **Article I v3:** Seeded Random exposed via `getRng()`
- **Article VI:** Telemetry is numerical observation, no subjective state
