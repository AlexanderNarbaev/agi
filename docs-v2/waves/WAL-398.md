## File: `matrix-core/src/main/scripts/matrix-conv.sh`

Convenient wrapper that locates all gradle-cached jars and dispatches:

```bash
./matrix-conv.sh cli                       # Interactive CLI
./matrix-conv.sh server [port]            # HTTP server (default 9093)
./matrix-conv.sh replay <session-id>      # Replay conversation
./matrix-conv.sh list                     # List sessions
```
