## Objective
Enable learning from recorded conversations by converting NDJSON session logs
to (input, output) training pair format.

## Class: `io.matrix.cli.NdjsonToTraining`

### Usage
```bash
java io.matrix.cli.NdjsonToTraining <output.jsonl> [input-dir]
```

### Verified
```
$ java io.matrix.cli.NdjsonToTraining /tmp/training.jsonl
Wrote 104 training pairs to /tmp/training.jsonl
Read 6 session files
```

Output format (JSONL):
```json
{"input":"my favorite color is blue","output":"I understand...","source":"conversation"}
{"input":"hello","output":"I understand...","source":"conversation"}
```

## Implementation

- Walks `data/conversations/*.ndjson`
- Pairs consecutive user/assistant messages
- Outputs as JSONL compatible with `MatrixTrainingEngine`
- Standalone (no Quarkus)

- **Article V:** Spec-driven (uses existing training format)
- **Article VI:** Training data is measurement substrate
