# WAL-622: Cloud Infrastructure Setup

**Date:** 2026-09-20
**Checkpoint:** 226fbc8e

## Summary

Cloud infrastructure setup for production deployment.

## Infrastructure Components

### 1. Compute
- **Instance Type:** t3.large (2 vCPU, 8GB RAM)
- **Instances:** 3 (for federation)
- **Auto-scaling:** CPU > 70% → scale to 5 instances
- **Load Balancer:** Application Load Balancer (ALB)

### 2. Database
- **Primary:** PostgreSQL 15 (db.t3.medium)
- **Read Replica:** 1 replica for read-heavy queries
- **Backup:** Daily snapshots, 7-day retention
- **Storage:** 100GB gp3

### 3. Cache
- **Redis:** cache.t3.micro (for session storage)
- **ElastiCache:** Managed Redis cluster
- **TTL:** 1 hour for session data

### 4. Storage
- **S3 Bucket:** For static assets, logs, backups
- **Lifecycle Policy:** Move to Glacier after 30 days
- **Versioning:** Enabled

### 5. Networking
- **VPC:** Custom VPC with public/private subnets
- **Security Groups:** Restrict access to necessary ports
- **NAT Gateway:** For private subnet internet access

## Terraform Configuration

```hcl
# Main configuration
provider "aws" {
  region = "us-east-1"
}

# VPC
resource "aws_vpc" "matrix_vpc" {
  cidr_block = "10.0.0.0/16"
}

# EC2 Instances
resource "aws_instance" "matrix_node" {
  count         = 3
  ami           = "ami-0c55b159cbfafe1f0"
  instance_type = "t3.large"
}

# RDS PostgreSQL
resource "aws_db_instance" "matrix_db" {
  engine         = "postgres"
  instance_class = "db.t3.medium"
  allocated_storage = 100
}

# ElastiCache Redis
resource "aws_elasticache_cluster" "matrix_cache" {
  cluster_id      = "matrix-cache"
  engine          = "redis"
  node_type       = "cache.t3.micro"
}
```
