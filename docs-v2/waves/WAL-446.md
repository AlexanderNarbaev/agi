### Features
- Add bookmark to any turn in any session
- List all bookmarks in a session
- Remove bookmarks by turn number
- Stored as # META bookmark turn=N note="..." comments

### Usage
```
java io.matrix.cli.ConversationBookmark <session> <turn> <note>     # Add
java io.matrix.cli.ConversationBookmark <session> --list          # List
java io.matrix.cli.ConversationBookmark <session> --remove <turn>  # Remove
```
