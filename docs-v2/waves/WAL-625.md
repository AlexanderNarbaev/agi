# WAL-625: CI/CD Pipeline Setup

**Date:** 2026-09-20
**Checkpoint:** 8abf75a3

## Summary

CI/CD pipeline setup for production deployment.

## Pipeline Components

### 1. GitHub Actions Workflow
- **Trigger:** Push to main, pull requests
- **Stages:** Build, Test, Deploy
- **Environment:** Production, Staging

### 2. Build Stage
- **Tool:** Gradle
- **Tasks:** Compile, package, native image
- **Artifacts:** Docker image, JAR file

### 3. Test Stage
- **Unit Tests:** JUnit 5
- **Integration Tests:** Testcontainers
- **Performance Tests:** JMeter
- **Security Tests:** OWASP ZAP

### 4. Deploy Stage
- **Strategy:** Blue-green deployment
- **Tool:** Kubernetes rolling update
- **Rollback:** Automatic on failure
- **Verification:** Health checks, smoke tests

## GitHub Actions Workflow

```yaml
name: CI/CD Pipeline

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Set up JDK 25
        uses: actions/setup-java@v3
        with:
          java-version: '25'
          distribution: 'graalvm'
      - name: Build with Gradle
        run: ./gradlew build
      - name: Build native image
        run: ./gradlew nativeCompile

  test:
    needs: build
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Run unit tests
        run: ./gradlew test
      - name: Run integration tests
        run: ./gradlew integrationTest
      - name: Run security tests
        run: ./gradlew securityTest

  deploy:
    needs: test
    runs-on: ubuntu-latest
    if: github.ref == 'refs/heads/main'
    steps:
      - uses: actions/checkout@v3
      - name: Deploy to Kubernetes
        run: |
          kubectl apply -f k8s/
          kubectl rollout status deployment/matrix
```

## Deployment Strategies

### Blue-Green Deployment
1. Deploy new version to green environment
2. Run smoke tests
3. Switch traffic from blue to green
4. Keep blue as rollback target

### Canary Deployment
1. Deploy new version to 10% of traffic
2. Monitor metrics for 15 minutes
3. Gradually increase to 100%
4. Rollback if metrics degrade

## Rollback Procedures

### Automatic Rollback
- Health check failure → rollback
- Error rate > 5% → rollback
- Latency p99 > 2s → rollback

### Manual Rollback
```bash
# Rollback to previous version
kubectl rollout undo deployment/matrix

# Check rollback status
kubectl rollout status deployment/matrix
```
