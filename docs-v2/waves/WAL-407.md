### Formats

| Format | Description |
|--------|-------------|
| `json` | Pretty-printed JSON with full conversation structure |
| `csv`  | One row per turn: session_id,role,content,timestamp |
| `txt`  | Plain text transcript with [USER]/[ASSISTANT] headers |

### Usage
```
java io.matrix.cli.ConversationExport <session-id> <format> [output-file]
java io.matrix.cli.ConversationExport --all <format> [output-file]
```
