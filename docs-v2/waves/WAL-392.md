## Class: `io.matrix.cli.RealConversationCli`

### Features
- Loads Qwen2.5-0.5B ONNX model from `models/onnx/qwen05b/`
- CPU mode (portability)
- Multi-turn conversation with history trimming (last 10 turns)
- Special commands: `quit`, `reset`, `info`
- Records every turn to NDJSON in `data/conversations/<session>.ndjson`
- Standalone (no Quarkus/HTTP dependency)

### Usage
```bash
java -cp <classpath> io.matrix.cli.RealConversationCli [model-path] [session-id]
```
