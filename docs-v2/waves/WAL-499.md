## Class: `io.matrix.brain.BrainHttpServer`

### Endpoints
- `GET /health` → `{"status":"ok","version":"1.0"}`
- `POST /chat` → real Qwen response with RAG
- `POST /learn` → learn from recorded conversations
- `GET /stats` → KB size + model info
- `GET /knowledge?q=query` → search knowledge base
- `GET /` → web UI with chat form

### Verified
```
$ curl http://localhost:9220/health
{"status":"ok","version":"1.0"}

$ curl -X POST -d '{"message":"What is the capital of Japan?"}' http://localhost:9220/chat
{"reply":"The capital of Japan is Tokyo...","confidence":0.5554}

$ curl -X POST http://localhost:9220/learn
{"learned":120,"kb_size":124}
```

### Architecture
- Uses LlmBrainLoopRag (RAG + LLM)
- Uses ConversationLearner for /learn
- Uses SimpleKnowledgeBase for /knowledge
- Java built-in HttpServer (no framework)
