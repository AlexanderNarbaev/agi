### Methods

- `backup(ModulatorRegistryStore, Path)` — writes ProtoBuf snapshot to file
- `restore(Path, seed)` — reads file, creates new store
- `verify(Path)` — checks if file is valid backup
- `BACKUP_EXTENSION = ".regpb"`

### BackupResult Record

- `path` — file location
- `modulatorCount` — number of modulators
- `timestampNs` — creation time
- `fileSizeBytes` — file size
