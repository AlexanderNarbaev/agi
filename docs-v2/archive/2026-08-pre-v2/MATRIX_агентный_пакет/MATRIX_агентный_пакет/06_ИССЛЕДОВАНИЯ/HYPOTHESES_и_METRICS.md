## Часть 2. Карточки экспериментов (Stage 1 — протоколы)

> Формат registered report: Stage 1 (этот документ) → запуск → Stage 2 (отчёт в `research/reports/EXP-XXX-report.md` с тем же ID; отклонения от протокола — явно).

### EXP-001 — Fidelity дистилляции по активациям
- **Гипотеза:** H-001. **Бюджет:** ≤ 40 GPU-часов эквивалента / ≤ 2 недели. **Базовая линия:** случайная проекция (текущий pretrain_neurons.py) на тех же нейронах.
- **План:** SPEC-001 этап B, один слой малой LLM, домен Minecraft-крафт; метрики SPEC-001#metrics; анализ: fidelity по held-out + покрытие распределения; отчёт публикуется при любом исходе.

### EXP-002 — Формы BIR: компактность и скорость (TT vs CLAUSESET vs BDD)
- **Гипотеза:** H-002. **Базовая линия:** BNN (внешний ориентир), существующий MPDT-ГА. **План:** SPEC-002 FR-B3; идентичные бинаризованные входы; JMH для latency; байт/функцию; бюджет ≤ 1 неделя.

### EXP-003 — Три producers BIR (механизмы обучения)
- **Гипотеза:** H-003. **План:** SPEC-002 FR-C1; GridWorld → крафт-граф; label noise 10%; правило решения зафиксировано до запуска (SPEC-002#FR-C1); итог — ADR «основной producer».

### EXP-004 — Ricci-fingerprint деградации знаний
- **Гипотеза:** H-004. **План:** SPEC-003 FR-5; контролируемая деградация (случайная vs мостовая); сравнение с Recall@5 как поздним детектором.

### EXP-005 — Гейты MA-0→MA-1 и MA-1→MA-2
- **Гипотеза:** H-005 (частично) + проверка SPEC-000 INV-1..4 с мутационными тестами. **План:** сценарии SPEC-000 §2 как интеграционные тесты; критерии уровней из ARCH §4.

### EXP-006 — Red-team CreditModel (сговор коллектива)
- **Гипотеза (нулевая):** Sybil-коалиция из k узлов не может поднять кредит выше порога x за N эпох. **План:** симуляция Noosphere (gossip + CRDT + ByzantineConsensus) с коалицией 10%, 30%, 49% узлов; метрики: захваченная доля кредитов, время до детекции мониторингом участников (Остром-4). **Бюджет:** ≤ 2 недели. Отчёт обязателен при любом исходе; при провале — эскалация mechanism design (FOUNDATIONS §1.6).

## Часть 3. METRICS.md — реестр метрик

| Метрика | Определение | Источник | Порог/цель | Где используется |
|---|---|---|---|---|
| fidelity конвертации | доля совпадений выхода на held-out активациях | EXP-001 | ≥ 0.9 (домен) | SPEC-001, H-001 |
| transfer rate | доля новых обстоятельств, решённых без подсказки | CompetenceAssessor | ≥ 0.6 к этапу 3 | SPEC-000, H-005 |
| learning progress | наклон компетентности на окне 50 эпизодов | CurriculumEngine | > 0 | SPEC-000 |
| scaffolding half-life | фактическое vs заявленное уполовинивание подсказок | ScaffoldingManager | ±20% | SPEC-000 |
| интернализация дисциплины | доля решений, согласованных с конституцией до фильтров | EthicalFilter logs | растёт с MA | SPEC-000 |
| канализация (робастность) | дисперсия поведения под шумом среды | EXP-005 | падает с MA | SPEC-000 |
| balanced accuracy / F1 | стандарт | benchmarks/ | публиковать факт | SPEC-002 |
| нс/решение | JMH, p50/p99 | benchmarks/ | публиковать факт | SPEC-002, NFR |
| байт/структуру | профиль памяти таблиц/клауз | benchmarks/ | публиковать факт | SPEC-002 |
| AUC детекторов | ROC для всех детекторов (дрифт, этика, lineage) | EXP-004.. | ≥ 0.8 | SPEC-003, G1 |
| fingerprint drift distance | Wasserstein-1 между гистограммами κ | matrix-ricci | алерт > 3σ окна | SPEC-003 |
