# Агентный пакет MATRIX — README

**Версия:** 1.0 · **Дата:** 2026-07-31 · **Назначение:** положить в репозиторий и запустить доступных ИИ-агентов на реализацию.

---

## Что это

Этот пакет — дистиллят пяти итераций аудита и исследования (стратегический аудит, биомотивированная траектория, теоретическая база, Tsetlin/наследие школ, педагогика/топология/среда разработки). Он **заменяет** все предыдущие исследовательские документы как рабочую основу: противоречия устранены, избыточное удалено, каждое требование снабжено метрикой и критерием приёмки. Прежние документы (`MATRIX_стратегический_аудит_и_план.md`, `MATRIX_реформа_документации_и_harness.md`) остаются как исследовательский архив — агентам их читать **не нужно**.

## Куда положить

## Порядок запуска агентов

| Шаг | Агенту даётся | Результат |
|---|---|---|
| 1 | CONSTITUTION.md + AGENTS.md + vision/ARCHITECTURE.md | Агент подтверждает рамку, читает инварианты |
| 2 | spec/SPEC-001 (конвертация весов) | Этап 1 роадмапа — критический блок |
| 3 | spec/SPEC-002 (Tsetlin-базовая линия) | Параллельно с SPEC-001, та же неделя бенчмарков |
| 4 | spec/SPEC-000 (Developmental Loop) | После стабилизации этапа 1 |
| 5 | spec/SPEC-003 (топология знаний) | После поднятия Knowledge Stack |

**Правило:** один агент — один SPEC за сессию; сессия заканчивается milestone-коммитом и обновлением WAL.md (формат в AGENTS.md).

## Статусы документов (конвенция)

`CONSTITUTION.md` — **FROZEN-документ**: меняется только через RFC владельца. `spec/*` — **normative**: меняются через acceptance-driven итерацию с changelog в шапке. `research/*` — **living**: обновляются каждым экспериментом. `WAL.md` — **ephemeral**: переписывается каждой сессией.

## Главные инварианты (кратко — полные в CONSTITUTION.md)

1. Рантайм исполняет только BIR-артефакты (TT k≤20 / CLAUSESET / BDD); FROZEN-нейроны неизменяемы; детерминизм рантайма.
2. Четыре запрета: Не убий / Не пытай / Не порабощай / Не размножайся без ведома.
3. Каждый обучающий цикл имеет объявленный монотонный функционал качества.
4. Переход уровня зрелости MA — только через принятую карточку эксперимента.
5. Ни одного непроверяемого утверждения в публичных документах.
6. Продакшн-код — Java (JVM); Python допустим только в `research/` как одноразовая лаборатория.
