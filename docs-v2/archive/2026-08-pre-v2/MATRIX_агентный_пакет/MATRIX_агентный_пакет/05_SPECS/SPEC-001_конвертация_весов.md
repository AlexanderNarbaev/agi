# SPEC-001: Верифицируемая конвертация весов (карантин → дистилляция по активациям)

**Статус: normative · v1.0 (2026-07-31)** · Критический блок этапа 1. Предыстория: `scripts/pretrain_neurons.py` выполняет случайную выборку k≤20 весов из d_model с порогом 0.0 — деструктивная проекция (GIGO), верифицировано построчно.

## 1. Цель

Заменить случайную проекцию на измеримую дистилляцию поведения: MPDT-структура аппроксимирует поведение FFN-нейронов открытой LLM **на реальном распределении активаций**, с публикуемой fidelity. До измеренной fidelity — фича в карантине.

## 2. Требования

### Этап A. Карантин (неделя 1, обязателен первым)
- **FR-A1.** `pretrain_neurons.py` и весь путь «pretrained neurons» помечается experimental; исключается из `/v1/models` (модель «unified neural system (pretrained neurons merged)» удаляется из листинга).
- **FR-A2.** Из README и документов удаляются claims, зависящие от этой фичи (Конституция, Статья VI).
- **Критерий A:** ни один endpoint и ни один документ не выдаёт конвертированные нейроны как семантически значимые.

### Этап B. Дистилляция по активациям
- **FR-B1.** Teacher: открытая LLM (дефолт — малая модель семейства SmolLM2/Qwen) запускается **из JVM** через DJL + ONNX Runtime (см. engineering/JAVA_STACK.md); Python не выходит за `research/`.
- **FR-B2.** Калибровочный корпус прогоняется через teacher; снимаются пары (вход FFN-нейрона, выход) с реального распределения (слой выбирается конфигом; начать с одного слоя).
- **FR-B3.** Бинаризация входов — по изученным порогам (квантили распределения активаций), не по нулю; пороги сохраняются в metadata Avro вместе с индексами выбранных входов (индексы уже сериализуются — сохранить).
- **FR-B4.** Выбор k≤20 входов — по важности (|w| · статистика активаций) или greedy по вкладу в ошибку аппроксимации; `rng.choice` запрещён.
- **FR-B5.** Обучение таблицы/дерева на парах FR-B2 (rule extraction / TREPAN-подход): цель — fidelity к поведению нейрона на held-out активациях.
- **FR-B6.** Метрика публикуется в metadata каждого нейрона: fidelity, k, метод выбора входов, хэш корпуса, версия teacher. Модель с fidelity ниже порога **не выпускается** (порог по умолчанию 0.9 для домена Minecraft-крафт; пересмотр — через changelog).
- **FR-B7.** Φ цикла: fidelity на held-out, монотонно по итерациям обучения; ухудшение — откат к лучшему чекпойнту (Статья III).

## 3. Инварианты

- INV-1: teacher живёт вне рантайм-контура решений (Статья II.2): дистилляция — офлайн-процедура, рантайм остаётся детерминированным.
- INV-2: provenance: каждый дистиллированный нейрон несёт lineage (teacher, корпус, параметры) — связь с genesis/lineage ledger (ARCHITECTURE §5).
- INV-3: воспроизводимость: фиксированные seed'ы; один и тот же корпус + версия teacher → идентичная таблица.

## 4. Метрики

| Метрика | Порог |
|---|---|
| fidelity (точность совпадения выхода на held-out активациях) | ≥ 0.9 (домен-специфично; публиковать фактическое) |
| покрытие распределения (доля реальных активаций, попадающих в обученные входные паттерны) | ≥ 0.95 |
| стоимость: токены/часы teacher на нейрон | регистрировать в METRICS.md (бюджет эксперимента) |

## 5. Критерии приёмки

1. Этап A слит отдельным PR с тестом «endpoint не возвращает pretrained-модель».
2. EXP-001 (preregistered): дистилляция одного слоя одной малой LLM; отчёт с fidelity, включая **отрицательный результат, если fidelity < порога** (протокол: публикуем как есть — это решение о судьбе линии «конвертер LLM», риск из аудита §9).
3. Решение владельца по результату EXP-001: шкала B (продолжить) или честное закрытие линии с фиксацией в OPEN_PROBLEMS.md.
