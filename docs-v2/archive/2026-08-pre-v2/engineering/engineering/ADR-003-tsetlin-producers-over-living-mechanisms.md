# ADR-003. Автоматы Цетлина как базовые producers BIR; «живые» механизмы — только через эксперимент

- **Статус:** proposed (решение подтверждается EXP-002/EXP-003; до результата — рабочая ставка)
- **Дата:** волна 6 документации
- **Связи:** DESIGN-04, SPEC-002 FR-C1, HYPOTHESES H-002/H-003/H-010, C4 (контейнер «Офлайн-обучение»), FR-05, NFR-04/13

## Контекст

Офлайн-обучению нужен базовый механизм порождения CLAUSESET-артефактов из корпусов. Кандидаты: (а) автоматы Цетлина (коллективы автоматов с линейной тактикой); (б) генетические алгоритмы (существующий MPDT-ГА); (в) трёхфакторные «живые» правила (hebbian-like); (г) однопроходовые WNN-producer'ы (WiSARD-стиль).

Требования: интерпретируемость результата (клаузы читаются человеком, NFR-13), детерминизм по seed (NFR-04), скорость до порога точности, совместимость с witness-линией (каждый кандидат рождается с обоснованием).

## Решение

Базовый producer — **TsetlinTrainer** (автоматы Цетлина): обучение — конечноавтоматное поощрение/штраф литералов; результат — CLAUSESET, напрямую читаемый и верифицируемый. WNN-producer — допустимый быстрый однопроходовый вариант (H-010). ГА и трёхфакторные правила **исключаются из ядра** и возвращаются только при экспериментальном превосходстве по зафиксированному правилу SPEC-002 FR-C1 (скорость, качество, байт/структуру — при ≤2× сложности).

## Основания (атлас)

- Прямая родословная: LAD (Хаммер–Крама–Ибараки, §25) — паттерн ≡ клауза, теория ≡ CLAUSESET, обоснование ≡ witness; автоматы Цетлина — SM §1.
- Гейт приёма клауз — трайрупья Дхармакирти (§30): поддержка в классе, полное отсутствие вне класса, достоверность установления — это ровно семантика поощрения/штрафа автоматов.
- Принцип детерминизма Мойсила (§26) → фиксированные seed'ы, побитовая повторяемость (NFR-04).
- Потенциальные функции советской школы (SM §8) — исторический предок Φ-гейта, в который встроен producer.

## Последствия

**Положительные:**
- Каждый артефакт обучения интерпретируем: клауза + таблица сопряжённости = читаемое правило с witness (FR-03, NFR-13).
- Обучение дешево и локально: никаких градиентов, битовые операции, ноутбучный профиль (G-A, G-B, G-E).
- Дубликаты кандидатов отсеиваются канонизацией BDD (EXP-018/020).

**Отрицательные / цена:**
- На «плохих» доменах (высокая арность взаимодействий) CLAUSESET раздувается; митигируется композицией BirNet и генераторами средней арности (H-020).
- Наивная реализация TM в прототипе не сошлась с эталоном (prototype/RESULTS §5) — обязательный предэтап EXP-002: воспроизведение эталонных чисел Granmo 2018 до доменных выводов.

## Отвергнутые альтернативы

- **ГА как базовый producer:** существующий MPDT-ГА сохраняется как baseline EXP-002, но по текущим данным проигрывает по (точность × байт/структуру) и скорости; возврат — только через H-003-опровержение.
- **Трёхфакторные правила:** неинтерпретируемое состояние, сложность без измеренного выигрыша (H-003).
- **Градиентное обучение в ядре:** несовместимо с G-B и детерминизмом; допустимо только снаружи — как источник дистилляции через карантин (SPEC-001, ADR-001).

## Проверяемость

- EXP-002: эталон MUX/noisy-XOR до доменов; иначе доменные результаты недействительны.
- EXP-003: правило решения FR-C1 зафиксировано до запуска; отрицательный результат публикуется (FR-15).
- Пересмотр ADR — только по accepted-результату H-002/H-003/H-010.
