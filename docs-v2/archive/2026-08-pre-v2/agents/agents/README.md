# Спецификации для агентов — карта

**Статус: normative** · Корневой `AGENTS.md` — общие правила проекта. Этот каталог — специализированные протоколы, обязательные при работе в соответствующей зоне. Правило области действия: специализированный файл **дополняет** корневой, не отменяет его; при конфликте побеждает CONSTITUTION.md, затем корневой AGENTS.md.

| Файл | Область действия | Когда обязателен к прочтению |
|---|---|---|
| [AGENTS-MODULES.md](AGENTS-MODULES.md) | Модули входящих/исходящих сигналов (DESIGN-06): разработка, регистрация, версионирование, тесты | Любая работа в `signal-modules/**`, `matrix-io/**`, добавление/изменение кодировщиков и декодировщиков |
| [AGENTS-RESEARCH.md](AGENTS-RESEARCH.md) | Исследовательский контур: гипотезы, эксперименты, фиксация результатов, научные статьи | Любая работа в `docs/research/**`, запуск экспериментов, подготовка papers/ |

## Правила размещения

1. Новая зона ответственности → новый файл `AGENTS-<ZONE>.md` здесь + строка в таблице выше + ссылка из корневого AGENTS.md.
2. Файл агентной спецификации отвечает на вопросы: что разрешено/запрещено, какие артефакты обязательны, как проверяется результат, куда писать выход.
3. Агентная спецификация не дублирует спеки: она ссылается на DESIGN/SPEC по URI (§-ссылки), а не пересказывает их.
