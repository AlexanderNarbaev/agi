# AGENTS-RESEARCH — протокол исследований, фиксации результатов и научных статей

**Статус: normative** · Область: `docs/research/**`, эксперименты, публикации. Прочитай после корневого AGENTS.md (правила 4–6) и CONSTITUTION.md (статьи VI–VII).

## Жизненный цикл исследования (обязателен полностью)

1. **Гипотеза.** Опровержимое утверждение с числовым порогом подтверждения и опровержения — строка в `docs/research/HYPOTHESES.md`, статус `proposed`. Формулировка до эксперимента, не после (защита от HARKing, CONSTITUTION VI.2).
2. **Пререгистрация.** Карточка EXP: задачи, метрики с формулами, базовые линии, бюджет, протокол (сид/версии/железо), риски. Метрики регистрируются в `docs/research/METRICS.md` до запуска.
3. **Эксперимент.** Код в `docs/research/` (Python допустим только здесь; R допустим наравне с Python — статистический анализ и воспроизведение процедур из первоисточников, напр. МГУА/АВО; Java-прототипы — `prototype-java/`). Детерминизм: фиксированные seed, фиксированные версии данных; прогон публикует сырые данные (json/csv).
4. **Фиксация.** Отчёт `docs/research/reports/EXP-NNN-report.md`: пререгистрированные метрики vs измеренные, отклонения от протокола (с причинами), отрицательные результаты — наравне с положительными. Статус гипотезы обновляется: `accepted | rejected | superseded`.
5. **Статья.** При значимости результата — генерация публикации по протоколу `docs/research/papers/README.md` из зафиксированных артефактов (не из памяти): структура PAPER-NN (заглавие, аннотация, метод, результаты с таблицами из отчёта, ограничения, воспроизводимость). Числа в статье обязаны сходиться с отчётом и json сырых данных — расхождение = брак.

## Жёсткие правила

- **Нет гипотезы — нет эксперимента.** Исследовательский код вне EXP-карточки не запускается на данных проекта.
- **Честные границы:** внешние числа помечаются «литература» со ссылкой; свои — «прототипные» со средой измерения. Подмена одного другим = нарушение статьи VI.
- **Отрицательный результат публикуется** (пример: RESULTS §4 потолок DNF, §5 несходимость наивной TM, §7 ограничения WNN-пилота).
- **Пост-хок подгонка запрещена:** перебор гиперпараметров, если он влияет на вывод, включается в пререгистрированный протокол (пример: tuple-size в EXP-010, RESULTS §7).
- **Авторство и роли:** статья фиксирует, что сделано человеком, что агентом; автогенерация помечается как автогенерация (papers/README.md).
