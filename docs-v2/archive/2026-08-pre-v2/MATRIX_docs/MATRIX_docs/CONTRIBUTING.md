# CONTRIBUTING — Участие в проекте MATRIX

Проект развивается одним владельцем + ИИ-агентами по spec-driven протоколу. Правила едины для людей и агентов.

## Перед первым PR

1. Прочитай `CONSTITUTION.md` (инварианты и запреты) и `AGENTS.md` (рабочий протокол).
2. Найди свою задачу в спеке (`docs/spec/`) или предложи новую через issue.

## Процесс

- **Фича** = полный spec-цикл: спека (или её раздел) → план → задачи → реализация → приёмка по критериям спеки. Спеки могут корректироваться на приёмке — с changelog в шапке документа.
- **Багфикс/мелочь** (≤ ~30 строк): PR с тестом и строкой в WAL.md.
- **Эксперимент** = карточка в `docs/research/HYPOTHESES.md` до запуска (preregistration), отчёт после — при любом исходе.

## Требования к коду

- Java (продакшн-путь); тесты: jqwik (свойства), JUnit (интеграция), Testcontainers (инфраструктура); coverage gate ≥ 82% не понижается.
- Детерминизм рантайма: никакой случайности без seed, wall-clock и LLM-вызовов в контуре решений.
- Каждый обучающий цикл объявляет монотонный функционал Φ (CONSTITUTION, Статья III).

## Требования к формулировкам

Запрещены: «AGI», «не лжёт», «не забывает», «не может быть использован во вред», числа без воспроизводимого бенчмарка (CONSTITUTION, Статья VI). Пишите проверяемое: механизм + измерение.

## Этика участия

Вклад принимается только при согласии с Четырьмя запретами (CONSTITUTION, Статья I) и лицензией (AGPLv3 + политика этического использования).
