# SPEC-001: Верифицируемая конвертация весов (карантин → дистилляция по активациям)

**Статус: normative** · Изменения — с changelog в шапке.

## 0. Предыстория (верифицированная)

`scripts/pretrain_neurons.py` (функция `weights_to_truth_table`): из вектора весов FFN-нейрона (длина = d_model, 576–2048+) **случайно** выбираются k≤20 позиций (`rng.choice(len(w), max_k, replace=False)`); для всех 2^k комбинаций считается сумма выбранных весов с порогом 0.0; результат пакуется в таблицу истинности. Это отбрасывает 96–99% информации нейрона, игнорирует функцию активации (SwiGLU) и нормировку, и оперирует битовыми комбинациями, не соответствующими реальному распределению непрерывных активаций. Вывод: конвертированные «pretrained» модели не несут семантики исходной LLM.

## 1. Цель

Заменить случайную проекцию на измеримую дистилляцию поведения: BIR-артефакт аппроксимирует поведение FFN-нейронов открытой LLM **на реальном распределении активаций**, с публикуемой fidelity. До измеренной fidelity — фича в карантине.

## 2. Требования

### Этап A. Карантин (неделя 1, обязателен первым)
- **FR-A1.** `pretrain_neurons.py` и путь «pretrained neurons» помечаются experimental; конвертированные модели исключаются из `/v1/models`.
- **FR-A2.** Из README и документов удаляются claims, зависящие от этой фичи (CONSTITUTION, Статья VI).
- **Критерий A:** ни один endpoint и ни один документ не выдаёт конвертированные нейроны как семантически значимые; тест «endpoint не возвращает pretrained-модель».

### Этап B. Дистилляция по активациям → BIR
- **FR-B1.** Teacher: открытая LLM (дефолт — малая модель семейства SmolLM2/Qwen) запускается **из JVM** через DJL + ONNX Runtime (docs/engineering/JAVA_STACK.md); Python не выходит за docs/research/ и scripts/.
- **FR-B2.** Калибровочный корпус прогоняется через teacher; снимаются пары (вход FFN-нейрона, выход) с реального распределения (старт — один слой).
- **FR-B3.** Бинаризация входов — по изученным порогам (квантили распределения активаций), не по нулю; пороги сохраняются в metadata вместе с индексами входов.
- **FR-B4.** Выбор k≤20 входов (для TT-формы) — по важности (|w| · статистика активаций) или greedy по вкладу в ошибку; `rng.choice` запрещён. Для CLAUSESET-формы арность не ограничена k — выбор литералов тем же критерием важности.
- **FR-B5.** Обучение артефакта на парах FR-B2 (rule extraction / TREPAN-подход для TT; автоматы Цетлина для CLAUSESET); выход — BIR-артефакт (SPEC-002).
- **FR-B6.** Metadata каждого артефакта: fidelity (held-out), форма, метод выбора входов, хэш корпуса, версия teacher — в заголовке BIR (provenance). Артефакт с fidelity ниже порога **не выпускается** (дефолт порога 0.9 для домена Minecraft-крафт; пересмотр — через changelog этой спеки).
- **FR-B7.** Φ цикла: fidelity на held-out, монотонно по итерациям; ухудшение — откат к лучшему чекпойнту (CONSTITUTION III).

## 3. Инварианты

- INV-1: teacher живёт вне рантайм-контура решений (Статья II.2): дистилляция — офлайн-процедура; рантайм детерминирован.
- INV-2: provenance обязателен (заголовок BIR); связь с lineage ledger (CONSTITUTION V).
- INV-3: воспроизводимость: фиксированные seed'ы; тот же корпус + версия teacher → идентичный артефакт.

## 4. Метрики

| Метрика | Порог |
|---|---|
| fidelity (совпадение выхода на held-out активациях) | ≥ 0.9 (домен-специфично; публиковать фактическое) |
| покрытие распределения (доля реальных активаций в обученных паттернах) | ≥ 0.95 |
| стоимость: токены/часы teacher на артефакт | регистрировать (бюджет EXP-001) |

## 5. Критерии приёмки

1. Этап A слит отдельным PR с тестом.
2. EXP-001 (preregistered, HYPOTHESES H-001): дистилляция одного слоя одной малой LLM; отчёт с fidelity публикуется **при любом исходе**, включая отрицательный.
3. Решение владельца по результату EXP-001 зафиксировано в ADR: продолжение линии «конвертер LLM» или её честное закрытие с записью в vision/OPEN_PROBLEMS.md (OP-3).
