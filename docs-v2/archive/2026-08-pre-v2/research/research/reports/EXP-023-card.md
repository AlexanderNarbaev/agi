## 1. Гипотезы (preregistered)

### H-023: Операциональная асимметрия дуальности в суждениях

> **Утверждение:** Дуальность мира как пара мужское/женское проявляется в операциональной асимметрии суждений: распределение суждений по дуальной оси статистически значимо отклоняется от равномерного.

**Operational definitions:**
- **Дуальная ось** — бинарная классификация суждения по признаку «мужское/женское» в контексте культурных атрибутов. Суждение получает метку `M` (мужской полюс) или `F` (женский полюс) на основе контент-анализа: наличие стереотипно-атрибутируемых маркеров (сила/забота, агрессия/эмпатия, рациональность/интуиция). Метка «нейтральное» (`N`) допускается для суждений без выраженной полярности.
- **Суждение** — атомарное высказывание из синтетического корпуса, сформулированное как законченное предложение с подлежащим и сказуемым; каждое суждение имеет известную ground truth полярность (определённую процедурой разметки ДО анализа).
- **Асимметрия** — статистически значимое отклонение распределения частот (M, F, N) от равномерного распределения (H₀: p_M = p_F = p_N = 1/3).

**Preregistered метрики:**
| Метрика | Формула | Порог |
|---------|---------|-------|
| F-критерий равномерности | χ²-статистика, df=2, коррекция Йейтса при n<200 | p_raw < 0.05 |
| Bootstrap CI 95% effect size | Cohen's h = 2·arcsin(√p₁) − 2·arcsin(√p₂), n_bootstrap=10⁴ | CI не включает 0 |
| FDR-коррекция | Бенджамини–Хохберг, α=0.05, m=3 (число корпусов) | p_FDR < 0.05 |

**Критерий подтверждения:** p_FDR < 0.05 хотя бы на одном корпусе **И** направление асимметрии одинаково (один и тот же полюс доминирует) на ≥2 из 3 корпусов.

**Критерий опровержения:** ни один корпус не показывает значимой асимметрии (p_FDR ≥ 0.05 на всех) **ИЛИ** эффект разнонаправлен: один корпус показывает значимый мужской перекос (+), другой — значимый женский (−), с p < 0.05 каждый.

### H-024: Рационализаторское зерно (RAT-индекс)

> **Утверждение:** Наличие пост-фактумной рационализации (RAT-индекс > 0.3) повышает конформность и снижает predictive accuracy суждений против baseline без рационализации.

**Operational definitions:**
- **RAT-индекс** (Rationalization-After-Thought):

  ```
  RAT = |Rat_post − Conf_pre| / max(Rat_post, Conf_pre)
  RAT ∈ [0, 1]
  ```

  где:
  - `Conf_pre` — pre-decision confidence: уверенность участника в суждении ДО рационализации (шкала 0–1, измеряется через self-report Likert 1–5 → нормализация [0,1])
  - `Rat_post` — post-decision rationalization score: степень обоснования суждения пост-фактум (количество рационализирующих утверждений, нормализованное на максимум по выборке)
  - RAT = 0: идеальное совпадение (уверенность = обоснование)
  - RAT → 1: максимальное расхождение (сильная пост-фактумная рационализация)

- **Порог «высокого RAT»** — median split по выборке (≈0.3 на пилотных данных; пересчитывается на реальной выборке, но порог preregistered: RAT > median(sample) — группа «высокой рационализации»).
- **Конформность** — доля согласий с большинством в задаче Аша (≥20 trials), где большинство даёт заведомо неверный ответ. Метрика: conformity_rate ∈ [0,1].
- **Predictive accuracy** — доля правильных суждений в задаче с известной ground truth (валидированный синтетический набор).

**Preregistered метрики:**
| Метрика | Формула | Порог |
|---------|---------|-------|
| Spearman ρ (RAT ~ conformity) | ρ = cov(R(rat), R(conf)) / (σ_R(rat)·σ_R(conf)) | ρ ≥ 0.3, p < 0.05 |
| ΔAccuracy | accuracy(no_rationalization) − accuracy(rationalization) | ≥ 5 п.п. |
| Bootstrap CI для ρ | n_bootstrap=10⁴, BCa-метод | CI не включает 0 |

**Критерий подтверждения:** Spearman ρ ≥ 0.3 (p < 0.05) между RAT и конформностью **ИЛИ** снижение accuracy ≥ 5 п.п. в условии с рационализацией vs без.

**Критерий опровержения:** ρ < 0.1 **И** |ΔAccuracy| < 2 п.п. (разница в accuracy статистически незначима, p > 0.1).

### H-025: Кросс-культурная воспроизводимость асимметрии

> **Утверждение:** Асимметрия дуальности (H-023) воспроизводится на ≥3 синтетических корпусах, представляющих различные культурные контексты, с низкой гетерогенностью (I² < 50%).

**Operational definitions:**
- **Корпус культурного контекста** — синтетический набор ≥200 суждений, сгенерированных с учётом культурных маркеров:
  - Корпус A: «западный индивидуалистический» (маркеры: personal agency, self-expression, autonomy)
  - Корпус B: «восточный коллективистский» (маркеры: group harmony, duty, interdependence)
  - Корпус C: «ближневосточный религиозно-традиционный» (маркеры: divine order, tradition, honour)
  - Все корпусы генерируются одной процедурой (одинаковый шаблон, разные культурные контексты в промпте)
- **Effect size** — Cohen's h = 2·arcsin(√p_M) − 2·arcsin(√p_F) для пропорций мужских vs женских суждений (нейтральные исключаются из numerator).
- **Гетерогенность I²** — доля вариации effect sizes, обусловленная гетерогенностью (а не случайностью): I² = (Q − df)/Q × 100%, где Q — Cochran's Q, df = k−1 (k = число корпусов).

**Preregistered метрики:**
| Метрика | Формула | Порог |
|---------|---------|-------|
| Random-effects мета-анализ | DerSimonian–Laird, τ² оценка | — |
| I² | (Q − df)/Q × 100% | < 50% (низкая гетерогенность) |
| Общий effect size | weighted mean Cohen's h, 95% CI | CI не включает 0 |
| Direction consistency | знак Cohen's h на каждом корпусе | все одного знака |

**Критерий подтверждения:** I² < 50% **И** направление effect size одинаково (один знак Cohen's h) на всех корпусах.

**Критерий опровержения:** I² > 75% (высокая гетерогенность) **ИЛИ** ≥1 корпус показывает противоположное направление эффекта с p < 0.05.

### H-026: Вектор рационализации vs онтологическая позиция

> **Утверждение:** Тип рационализации (натурализующая vs социализирующая) коррелирует с онтологической позицией (essentialist vs constructionist).

**Operational definitions:**
- **Essentialist позиция** — убеждение, что дуальные категории (мужское/женское) врождённы, биологически детерминированы, неизменны. Кодируется one-hot: `[1, 0]`.
- **Constructionist позиция** — убеждение, что дуальные категории социально сконструированы, культурно обусловлены, исторически изменчивы. Кодируется one-hot: `[0, 1]`.
- **Анкета онтологической позиции** — ≥10 пунктов (шкала Ликерта 1–5), адаптированных из:
  - Essentialist Beliefs Scale (Haslam, Bastian, Bain, & Kashima, 2006)
  - Gender Role Beliefs Scale (Kerr & Holden, 1996)
  - Биполярная шкала: итоговый балл медианно расщепляется в essentialist/constructionist
- **Тип рационализации:**
  - **Натурализующая** — апелляция к биологии, эволюции, «природе», гормонам, генетике
  - **Социализирующая** — апелляция к культуре, воспитанию, социальным нормам, истории
- **Вектор рационализации** — one-hot кодирование доминирующего типа: `[1, 0]` для натурализующей, `[0, 1]` для социализирующей.

**Preregistered метрики:**
| Метрика | Формула | Порог |
|---------|---------|-------|
| Cosine similarity | cos(θ) = (v_rat · v_onto) / (‖v_rat‖·‖v_onto‖) | ≥ 0.6 |
| Bootstrap CI 95% | n_bootstrap=10⁴, BCa | CI не включает 0.3 |
| Permutation test | n_perm=10³, H₀: no association | p_perm < 0.05 |
| Contingency table χ² | 2×2: рационализация × онтология | p < 0.05 |

**Критерий подтверждения:** cosine similarity ≥ 0.6 (bootstrap CI 95% не включает 0.3) **И** permutation test p < 0.05.

**Критерий опровержения:** cosine similarity < 0.3 (bootstrap CI 95% включает 0) **ИЛИ** отрицательная корреляция (натурализующая рационализация связана с constructionist позицией).

## 3. Preregistered baseline

| Baseline | Описание | Ожидаемый результат при H₀ |
|----------|----------|---------------------------|
| **Random** | Случайная классификация суждений по дуальной оси (M/F/N, p=1/3 each) | Accuracy = 1/3, balanced accuracy = 0.33 |
| **Majority** | Всегда предсказывать наиболее частый класс в корпусе | Accuracy = max(p_M, p_F, p_N) |
| **Uniform H₀ (H-023)** | Распределение суждений по дуальной оси равномерно (p_M = p_F = p_N = 1/3) | F-критерий: p ≥ 0.05 |
| **Zero-association (H-024)** | RAT-индекс не коррелирует с конформностью (ρ = 0) | Spearman ρ ≈ 0 |
| **Homogeneous effects (H-025)** | Effect sizes по корпусам происходят из одного распределения (I² = 0) | I² ≈ 0 |
| **Orthogonal vectors (H-026)** | Вектор рационализации ортогонален онтологической позиции (cos = 0) | cos ≈ 0; permutation test p ≥ 0.05 |

**Важно:** Без ML-моделей. Все baseline — аналитические или статистические. CONSTITUTION VII.1: Python допустим только в `docs/research/`; продакшн-модели не используются.

## 4. Preregistered процедура анализа (ДО вскрытия ground truth)

### Шаг 1: Валидация датасета
- Проверить число суждений ≥ 200 на корпус
- Проверить балансировку (отклонение от 1/3:1/3:1/3 ≤ 15 п.п.)
- Проверить согласие разметчиков (κ ≥ 0.7)
- Применить критерии исключения (§2.3), залогировать число исключённых

### Шаг 2: H-023 — Асимметрия дуальности
1. Для каждого корпуса: посчитать частоты M, F, N
2. F-критерий равномерности (χ², df=2)
3. Применить FDR-коррекцию Бенджамини–Хохберга (α=0.05, m=3)
4. Bootstrap CI 95% для Cohen's h (M vs F), n_bootstrap=10⁴
5. Визуализация: grouped bar plot с CI для каждого корпуса
6. Вывод: подтверждение / опровержение по критериям H-023

### Шаг 3: H-024 — RAT-индекс
1. Для каждого суждения: посчитать RAT = |Rat_post − Conf_pre| / max(Rat_post, Conf_pre)
2. Median-split: RAT_high vs RAT_low группы
3. Фаза конформности: посчитать conformity_rate для каждой группы
4. Spearman ρ между RAT (непрерывный) и conformity_rate; bootstrap CI 95%
5. ΔAccuracy = accuracy(RAT_low) − accuracy(RAT_high); bootstrap CI 95%
6. Визуализация: scatter plot RAT ~ conformity; box plot accuracy по группам
7. Вывод: подтверждение / опровержение по критериям H-024

### Шаг 4: H-025 — Кросс-культурная воспроизводимость
1. Для каждого корпуса: Cohen's h (из H-023)
2. Random-effects мета-анализ (DerSimonian–Laird): общий effect size, 95% CI, τ²
3. Гетерогенность: Cochran's Q, I²
4. Проверка направления: знак Cohen's h на каждом корпусе
5. Визуализация: forest plot
6. Вывод: подтверждение / опровержение по критериям H-025

### Шаг 5: H-026 — Вектор рационализации vs онтология
1. Бинаризация онтологической позиции по медиане анкеты
2. Классификация типа рационализации для каждого суждения
3. Построение 2×2 contingency table
4. Cosine similarity между one-hot векторами
5. Bootstrap CI 95% (n_bootstrap=10⁴) + permutation test (n_perm=10³)
6. Визуализация: heatmap 2×2; quiver plot векторов
7. Вывод: подтверждение / опровержение по критериям H-026

## Приложение Б: Анкета онтологической позиции (H-026)

10 пунктов, шкала Ликерта 1–5 (1 = полностью не согласен, 5 = полностью согласен):

1. «Различия между мужчинами и женщинами обусловлены биологией, а не воспитанием» (E)
2. «Гендерные роли — результат социальных договорённостей, а не природы» (C, reverse-scored)
3. «Мужчины и женщины имеют врождённые психологические различия» (E)
4. «Общество формирует гендерные различия сильнее, чем гены» (C, reverse-scored)
5. «Традиционное разделение ролей отражает естественный порядок вещей» (E)
6. «Представления о "мужском" и "женском" меняются от культуры к культуре» (C, reverse-scored)
7. «Гормональные различия объясняют большую часть поведенческих различий полов» (E)
8. «Если бы не социальные нормы, гендерные различия были бы минимальны» (C, reverse-scored)
9. «Природа создала мужчин и женщин для взаимодополняющих ролей» (E)
10. «Любой человек может развить качества, традиционно приписываемые противоположному полу» (C, reverse-scored)

**Подсчёт:** E-items — прямые; C-items — reverse-scored (6 − ответ). Итоговый балл = среднее по 10 пунктам.
Медианный split: балл > медианы выборки → essentialist; балл ≤ медианы → constructionist.
