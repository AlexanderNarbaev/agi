# Публикации MATRIX — протокол автогенерации

**Статус: normative** · Эта папка — единственное место научных публикаций проекта. Публикация формируется **автоматически из артефактов**, а не пишется от руки.

## Правила

1. **Источник — только артефакты.** Каждая цифра в публикации обязана быть воспроизводима: из `prototype/results.json` (команда в шапке RESULTS.md), из JMH-отчёта, из EXP-отчёта (`research/reports/EXP-NNN-report.md`). Цифра без команды воспроизведения удаляется (CONSTITUTION VI.2).
2. **Триггер генерации.** Новая публикация создаётся при: (а) закрытии EXP с любым исходом (включая отрицательный — CONSTITUTION VI.2); (б) появлении нового класса измерений (как PAPER-01 — по итогам прототипа и аналитического расчёта).
3. **Структура обязательная:** Аннотация → Введение → Метод (со ссылками на DESIGN/SPEC) → Теоретические результаты (с выводами) → Экспериментальные результаты (таблицы из артефактов) → Отрицательные результаты и ограничения (обязательный раздел) → Связанные работы → Воспроизводимость (команды) → Статус гипотез (что подтверждено/опровергнуто/открыто).
4. **Честные формулировки.** Запрещены claims статьи VI. Внешние числа (литература) помечаются «внешний ориентир», свои — «измерено/выведено».
5. **Журнал изменений** в шапке каждой публикации. Версия публикации = версия экспериментального артефакта.
