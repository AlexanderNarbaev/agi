конкретизации параметризованных действий по классам доменов как строка
бюджета бюджетера, кандидат на сравнение по корпусам (FR-15); аудит
эквивалентности при свопе (§82) — доля свопов PROMOTED, подтверждённых
BDD-эквивалентностью на валидированном классе, против свопов по
выборочной эквивалентности: процедурный кандидат (запрет второго класса
свопов проверяется компилятором журнала); аудит комплектности тождеств новых форм (§83) — каждая форма, вводимая в DSL композиции L2, сопровождается комплектом тождеств и аудитом Падоа: процедурный кандидат в AGENTS-RESEARCH (проверка: реестр форм без неполных комплектов); аудит CM-нормы рядов (§85) — доля кандидатов рядов Cauldron с неизменным отображением (стабильное отображение стимул→реакция на валидированном классе) против кандидатов с вариативным: процедурный кандидат (VM-кандидаты не продвигаются — проверяется компилятором журнала); калибровка доли захватов (§85) — частота ложных срабатываний PROMOTED-навыков по сходству стимула при невыполненном предусловии как телеметрия качества предусловий, кандидат на калибровку в H-022); аудит специализации при свопе (§86) — всякий своп DESIGN-13 сопровождается сертификатом эквивалентности остаточного артефакта на validatedClass, верифицируемым независимо от специализатора: процедурный кандидат (компилятор не является верификатором — проверяется компилятором журнала); суперкомпиляция трассы как кандидат-генератор (§87) — отдельный аудируемый проход над журналом M4, поставляющий кандидатов с явной ссылкой на поддерживающие трассы и воспроизводимой гонкой: процедурный кандидат в AGENTS-RESEARCH (проверка: кандидат без ссылки на трассу не принимается); аудит допустимости эвристик планировщика (§88) — периодическая проверка h ≤ h* на контрольных задачах с известным оптимумом: процедурный кандидат (недопустимые эвристики понижаются до равномерного поиска по бюджету — проверяется компилятором журнала); библиотека скриптов как источник кандидатов (§89) — скрипт-кандидат принимается только с доказанными предусловиями Хоара на валидированных эпизодах журнала: процедурный кандидат (скрипт без ссылки на поддерживающие эпизоды не принимается — проверяется компилятором журнала); аудит концепт-маршрутизации (§90) — маршрут запроса через концепт-адрес обязан сопровождаться свидетелем класса разрешимости: процедурный кандидат (маршрут по невалидированной статистике ≡ SHADOW, не PROMOTED — проверяется гейтами FNL); аудит таблицы различий планировщика (§91) — версионируемая таблица «оператор ↔ классы различий» пересобирается из журнала применений с проверкой допустимости эвристики различий на контрольных задачах: процедурный кандидат на калибровку в H-022)); квоты impulse-goal в бюджетере (§92) — доля бюджета рядов на самостоятельно поставленные цели из импульса дефицита, калибруемая по принятым/отклонённым impulse-goal в журнале M4: кандидат на калибровку в H-021/H-022; аудит библиотеки приёмов переформулировки (§93) — приёмы ТРИЗ как версионируемые операторы трансформации формулировки со статистикой применений M4: процедурный кандидат (приём без статистики ≡ SHADOW, не PROMOTED — проверяется гейтами FNL); аудит медиа-схем RENDERING и внешней оценки произведений (§94) — генерация длинных композиций и медиа-артефактов по скелету с предусловиями связности, оценка только внешними критериями: процедурный кандидат); калибровка гистерезиса смены фокуса (§95) — пороги установки/вытеснения доминантной цели как параметры коридора (слишком высокий гистерезис ≡ монополизация, слишком низкий ≡ дребезг): кандидат на калибровку в H-022; мера ЗБР куррикулума (§97) — распределение доли этюдов, решённых с k подсказками, по классам задач как версионируемая метрика зоны: кандидат на уточнение EXP-005 и AT-FNL-тестов; аудит сдвигов уровней деятельности (§96) — каждый сдвиг мотива на цель и каждое развёртывание операции в действие журналируется с классом причины: процедурный кандидат (сдвиг без журнального события ≡ нарушение аудита — проверяется компилятором журнала); аудит аффорданс-фильтра (§98) — доля предлагаемых операторов, чьи предусловия подтвердились при исполнении, против доли ложных аффордансов (срывов предусловия): кандидат на калибровку в H-022 (телеметрия качества ситуационной модели); калибровка перцептивной готовности (§99) — покрытие классов сигналов версионируемой схемой предфильтра против зарегистрированных классов событий M4: процедурный кандидат (слепота к зарегистрированному классу без документированного решения ≡ нарушение); аудит фазы «оглянуться» (§100) — доля BRC-актов с журналируемым разбором трассы, породившим кандидата или зафиксированным отсутствием кандидата: процедурный кандидат (акт без разбора — сырьё для компилятора журнала, не норма); вторая ось типологии отказов (HARNESS-PRACTICE-scan, источник × механизм: транзиентный/восстановимый/пользовательский/неожиданный × reject-by-budget/reject-by-proof/deadlock/divergence) — расширение схемы записи журнала отказов: процедурный кандидат; Pareto-функционал бюджетера (Meta-Harness, arXiv:2603.28052) — цель рядов как фронт «качество × расход» вместо скаляра, с полной сырой трассой как входом кандидат-генератора (эмпирически: 56.7 против 41.3 best accuracy полного доступа к трассам против скоров): кандидат на калибровку в H-021; goldens-калибровка классов кандидатов («reproduce your own work», Hashimoto) — воспроизведение эталонных трасс владельца продюсером вслепую до допуска класса в ряды: кандидат на уточнение AT-FNL-тестов. калибровка префильтра согласованности (§101) — доля отказов класса «несогласованность», снятых до BRC, против стоимости префильта по классам доменов: кандидат на EXP по энергетике размышления (вместе с кандидатом Ботвинника §61); аудит каскадной инвалидации (§102) — каждая DEMOTED-инвалидация несёт ссылку на опровергнутое основание и журнальное событие: процедурный кандидат (инвалидация без ссылки ≡ нарушение аудита — проверяется компилятором журнала); аудит операционального класса EBL-кандидатов (§103) — кандидат из трассы обязан нести объявленный до обобщения операциональный класс: процедурный кандидат (обобщение без класса не принимается — проверяется гейтами FNL). калибровка ранней остановки самопорождения эвристик (§104) — доля χ-актов над библиотекой приёмов, не выигрывающих у стабильной библиотеки по внешнему критерию на контрольных эпизодах, как сигнал остановки ряда мета-уровня: кандидат на калибровку в H-021 (вместе с «инцухтом» §49 и границей §63); аудит реестра HTN-методов (§105) — каждый метод декомпозиции несёт предусловие Хоара, критерий сборки и статистику применений M4: процедурный кандидат (метод без контракта не принимается — проверяется гейтами FNL); аудит критериев сборки (§105) — план-рецепт проверяется композицией триплетов до исполнения: процедурный кандидат (декомпозиция без доказанной сборки не исполняется — проверяется компилятором планов); калибровка systematicity-скоринга (§106) — доля переносов по структурной аналогии, подтверждённых на целевом домене, против доли отклонённых: кандидат на калибровку порога скоринга глубины структуры (в H-021/H-022); аудит трасс аналогии (§106) — отображение фиксируется с базовым/целевым классом, сохранёнными и утерянными отношениями: процедурный кандидат (перенос без трассы отображения не принимается).

## 5. Честные границы системы (сводные)

1. **Квант:** никаких экспоненциальных ускорений для поиска/вывода; потолок
   OR — Θ(√n), симметричные функции — ~n/2 (AA §3). QuantumBackend — опция,
   не обещание.
2. **Неполнота:** ядро сознательно ограничено разрешимыми фрагментами; всё,
   что за пределом — внешняя верификация и объяснимый отказ, а не попытка
   «дожать» (AA §6, §8, §20; исторический источник — опровержение программы
   Гильберта, AA §33). Это не баг, а конституционное решение (Статья VI). Разрешимость — свойство класса, не артефакта (прецедент Янова, AA §84): эквивалентность и вывод проверяются только внутри объявленного класса с решающей процедурой; выход за класс ≡ UNDECIDED, не аппроксимация. Специализация (прецедент Ершова, AA §86) — член того же класса: остаточный артефакт эквивалентен исходному только на зафиксированном классе входов; динамический вход вне validatedClass ≡ UNDECIDED и повторный проход mix, не аппроксимация специализированным артефактом.
3. **Противоречия:** не взрывают систему (изоляция, AA §11), но и не
   «разрешаются» молча — два сорта знания разведены структурно; импредикативные
   расширения выразительности — только с доказанной непротиворечивостью
   (уроки Фреге и ITT-1971, AA §33–§35).
4. **Fuzzy:** никаких градаций истины в ядре; мягкость — только в интерфейсе
   читаемости (AA §22). Задокументированный отказ, а не пробел.
5. **Резервуар и декодер** — эмпирические ставки (H-015/H-016): при провале
   фиксируется отрицательный результат и fork-альтернатива, а не подгонка.
6. **Энергия:** числа 10⁴×–10⁶× — из прототипной энергометрии ops×нДж
   (H-009 accepted в своих границах); перенос на другие домены — только через
   новые пререгистрированные эксперименты (NFR-06).
7. **Управление:** принцип максимума — необходимое, не достаточное условие;
   гомеостат — инженерный контур с версионируемыми коридорами, а не
   «саморегулирующийся разум» (AA §36; H-021/H-022 — ставки, не теоремы).
8. **Комбинаторика:** точные экстремальные оценки (Спернер, Семереди) экспоненциальны
   или башенны — они задают потолки и запреты (k≤20; никакой регулярности в
   рантайме), а не практические алгоритмы (AA §38).
9. **Верификация:** сквозная интерактивная верификация стоит ~2× разработки и
   десятки строк доказательств на строку кода (seL4, AA §40) — наша линия:
   малые локальные сертификаты, CI-проверки и автоматизированные фрагменты,
   а не монолитные доказательства в рантайме.
10. **Когнитивные архитектуры:** ACT-R/Soar/теории внимания — источники
    дисциплины композиции (буферы, импассы, фильтры, вещание), а не модели
    сознания или истины: их подсимвольные величины (активация, полезность)
    у нас только ранжируют поиск и извлечение, факт же устанавливается
    исключительно доказательством (закон 1; AA §42–§43). «Полезность —
    не истина» — прямое отличие от рационального анализа Андерсона. Эвристика —
    не истина (прецедент Нильссона, AA §88): допустимость эвристики есть
    проверяемое свойство (h ≤ h*), а не мера доверия; калибровка эвристик —
    журналируемый процедурный акт, переоценка ≡ типизированный отказ
    (heuristic-inadmissible), а не «неточность оценки». Скрипт ранжирует, не
    выводит (прецедент Шенка–Абельсона, AA §89): заполнение умолчаний —
    помеченная проекция, отклонение от сценария — новая трасса-кандидат,
    а не ошибка. Различие состояний — структурный счётчик, не истина
    (прецедент Ньюэлла–Саймона, AA §91): таблица «оператор ↔ различия»
    версионируется, её допустимость проверяется на контрольных задачах. Приём ранжирует и порождает
    кандидатов, решение доказывается (прецедент Альтшуллера, AA §93):
    оператор трансформации формулировки задачи не есть её решение;
    ИКР — направление поиска, не гарантия результата. Согласованность — фильтр,
    не истина (прецедент Уолтца–Макуорта–Фройдера, AA §101): согласованный срез
    говорит о возможности, не о факте; статус по обоснованиям (прецедент Дойла–
    де Клера, AA §102) не есть верификация — статус артефакта устанавливается
    гейтами со свидетельством, а не пересчётом веры; EBL-обобщение (прецедент
    Митчелла–де Джонга, AA §103) — кандидат из доказательства, не принятие. «Интересность»
    задания (прецедент Лената, AA §104) — скоринг ранжирования рядов, не любопытство
    и не истина; метод HTN (прецедент Сачердоти–Нау, AA §105) — рецепт, не
    истина: декомпозиция доказуется на домене; systematicity (прецедент Гентнер,
    AA §106) — скоринг глубины общей структуры, аналогия ранжирует, не выводит.
11. **Кредит и время:** сила правила (bucket brigade) и оценка позиции
    (scoring polynomial Сэмюэла) — гипотезы для планирования, не знание
    (AA §46); логические часы — координатная система аудита, а не физическое
    время мира (граница FITO, AA §45): энергометрия и дедлайны идут по
    отдельному физическому каналу счётчиков и таймеров.
12. **Ожидания и прецеденты:** значение слота по умолчанию во фрейме —
    ожидание, маркированное UNDECIDED, а не свидетель (AA §47); наследование
    с отменой в базовой логике не используется — отмена только через явное
    новое свидетельство; эмерджентность («возникло из взаимодействия») не
    принимается как объяснение — BRC-акт обязателен (AA §47); исторические
    прецеденты (FGCS, AA §48) и внешние критерии самоорганизации (МГУА,
    AA §49) — эвристики отбора и уроки границ, а не источники истины:
    отобранная по внешнему критерию модель остаётся гипотезой SHADOW до
    свидетельствованного продвижения.
13. **Взаимодействие и поведение:** CSP-событие фиксирует факт передачи, а не
    истинность переданного (статус знания наследуется от происхождения);
    недетерминизм процесс-алгебры — только уровень спецификации, исполнение
    детерминировано (NFR-04); подавление/ингибиция выхода слоя (subsumption)
    допустимо только с журналированием — немотивированное подавление =
    нарушение аудита (AA §51); add/delete-дельта действия — декларируемое
    допущение фрейма: всё недекларированное считается неизменным, и это
    допущение проверяется телеметрией, а не принимается молча (AA §52).
14. **Суждения и сигналы — не истина, и никакой феноменологии:** ситуационная
    модель — рабочее описание для решения, наследующее статус источников и
    умирающее с актом решения (AA §53); мета-суждения (EOL/JOL/FOK/RC) и
    мониторинг гомеостата измеряют и ранжируют, но не порождают знание —
    продвижение только через гейты с внешним критерием (AA §54); термины
    «мотивация», «прерывание», «нетерпение» — технические имена сигналов,
    таймеров и механизмов: переносится только функциональная роль (Саймон),
    система не «испытывает» эмоций и не моделирует феноменальные состояния
    (AA §55; Статья VI); satisficing — критерий остановки поиска, а не
    критерий истины: «достаточно хорошее» решение принимается к исполнению,
    но его свидетель остаётся обязательным и аудируемым. Подкрепление — частота,
    не верность (прецедент Чернявского, AA §90): вес связи концепт-
    маршрутизации — производная валидированной статистики журнала M4,
    перестройка сети — офлайн-χ-акт с собственным свидетелем; «привычный»
    маршрут не становится «верным» от повторения. Импульс — сигнал, не
    истина (прецедент Симонова, AA §92): дефицит информации измеряется и
    порождает кандидата-цель, но не удостоверяет её ценность; самооценка
    творчества запрещена — произведение оценивается только внешними
    критериями (AA §94). Доминанта и мотив — состояние контура и
    драйвер, не переживание (прецеденты Ухтомского, AA §95, и Леонтьева, AA §96):
    фокус удерживается зафиксированным актом и сменяется только журналируемым
    событием с причиной; зона ближайшего развития — критерий отбора задач,
    вычисляемый из журнала (уровень PROMOTED, потолок оракула), а не мера
    «понимания» (прецедент Выготского, AA §97). Аффорданс и перцептивная
    готовность — фильтры и схемы, не знание о среде (прецеденты Гибсона, AA §98,
    и Найссера, AA §99): доказанное предусловие говорит о применимости оператора
    к модели, не о фактах мира; слепота схемы фильтра — документируемое решение,
    не дефект; правдоподобие Пойи (AA §100) — скоринг ранжирования кандидатов,
    не вероятность истины.
15. **Записи и изменчивость:** эпизодическая запись — истина о событии в
    системе («был акт X со свидетелем Y»), а не о мире: истинность Y
    определяется его верификацией, не фактом записи (AA §57); журнал M4 —
    append-only: извлечение не перезаписывает запись (инверсия
    реконструктивности человеческой памяти в инвариант), «реконструкция»
    по K-line — производная структура со своим provenance (AA §56–§57);
    самоизменение (χ-правила) — только декларированными меню через
    свидетельствованные акты M4/Φ-гейтов; FROZEN-слой неизменяем;
    привязка знака к референту версионируется схемой и не дрейфует
    неявно (AA §58); refresh контекста (репетиция) продлевает TTL, но не
    меняет статус элемента (AA §56); трансформация трассы в программу
    (суперкомпиляция, AA §87) не есть истина: обобщение конфигураций
    допустимо только с доказуемым сохранением семантики на объявленном
    классе, результирующий кандидат проходит полный пайплайн гейтов как
    любой χ-акт — происхождение из журнала не даёт статуса. Трансформационная
    смена класса или постановки (прецедент Боден, AA §94) не есть истина:
    χ-акт смены схемы порождает кандидата с tombstone и provenance, его
    приёмка — только внешним критерием через полный пайплайн гейтов;
    «новизна» произведения не удостоверяет его ценность.
16. **Полнота архитектуры и экспертиза:** чек-лист полноты (13 ограничений
    UTC) — инструмент аудита покрытия, а не доказательство «общего разума»:
    выполнение списка не создаёт претензии на когницию (Статья VI), а
    исключённые пункты (моторика, нейронность, эволюция) задокументированы
    как исключения по классу системы, а не как пробелы (AA §59); экспертная
    интуиция (слитное восприятие-действие без делиберации и объяснимости,
    Дрейфусы) **не переносится**: любое действие аудируемо, «поступить
    необъяснимо, но верно» — не режим работы; наивысшая стадия навыка —
    PROMOTED с журналируемым применением и мониторингом коридоров, монополия
    интуиции заменена монополией гейтов (AA §60); телесность и вовлечённость
    стадий — за границей, переносится только функциональная роль.
17. **Методы неточных задач — эвристики, не истина:** горизонт по цели, зона,
    обобщённый размен и «конъюнктурные стоимости» (Ботвинник, AA §61) —
    эвристики сужения и оценки поиска: скоринг трассы ранжирует планы,
    решение принимается со свидетелем; исторический исход «Пионера»
    (победа масштабируемого перебора над ручной формализацией экспертизы)
    зафиксирован как симметричный урок FGCS — мы не переносим доменную
    онтологию и не претендуем на «человеческий метод»; табличная
    достижимость применима только к малым пространствам (потолок k≤20,
    граница №8).
18. **Статистические гарантии — о сходимости и ёмкости, не об истинности:**
    равномерная сходимость (VC), MDL-оптимальность и PAC-обучаемость
    гарантируют поведение оценок на выборках (при условиях регулярности и
    стационарности распределения), но не истинность правил: «вероятно
    приблизительно корректный» и «наикратчайший» кандидат остаётся SHADOW
    до свидетельствованного продвижения (AA §62–§64); равномерные оценки
    заведомо пессимистичны — это гарантии худшего случая, рабочие пороги
    устанавливаются экспериментом (NFR-06); стационарность потока не
    предполагается — дрейф отслеживается гомеостатом (§36), а не
    статистической рамкой; длина описания сравнивает гипотезы внутри
    фиксированного языка (BIR) и не ранжирует языки (смена языка — акт
    миграции, §58); класс кандидатов расширяется только внутри доказанно
    обучаемых фрагментов — отрицательные результаты обучаемости читаются
    как карта запретов, симметричная карте разрешимости (§8–§9).
19. **Подкрепление, подтверждение и машинные животные — скоринги и роли,
    не истина и не поведение:** эмпирическое подкрепление (бусины MENACE,
    статистика BOXES) обновляет скоринги, а не гарантии: «хорошо играет»
    ≠ «доказуемо не проигрывает», продвижение — только через гейт со
    свидетелем (AA §65); степень подтверждения (Карнап) — функция языка и
    меры, не свойство мира; универсальная индуктивная логика исторически
    не состоялась, обоснование методов у нас только прагматическое
    (пререгистрация) и теоремное (VC/PAC/MDL) (AA §67); эмерджентная
    интерпретация машинных животных («любопытство», «самосознание») не
    переносится — богатство наблюдаемого поведения не есть наличие
    соответствующего состояния (граница №12); телесности и актуаторов у
    системы нет — фототаксис и движение переносятся только как
    функциональные роли (следование сигналу / отход от нарушения коридора)
    (AA §66); поведенческая рамка «наказание/поощрение» — метафора, у нас
    только счётчики исходов по классам (граница №14).
20. **Уровни, микромиры и обучение сетей — дисциплина построения, не источник
    истины:** уровни с контрактами (Дейкстра, AA §68) — норма организации:
    корректность слоя доказывает соответствие спецификации, а не истинность
    утверждений о мире; «умственная экономия» — эпистемическая норма
    читаемости артефактов, не свидетельство; микромир (SHRDLU, AA §69)
    переносится как дисциплина явной границы домена — его закрытость никогда
    не забывается и не экстраполируется на открытый мир (урок
    Винограда–Флореса: thrownness и разорванность фиксируют, чего у системы
    нет и что она не имитирует); свободный естественный язык остаётся за
    границей (ADR-006) — «язык» в контуре исчерпывается типизированными
    схемами; тьюринговские неорганизованные машины (AA §70) дают исторический
    первоисточник обучения булевых сетей в однородном базисе, но случайная
    инициализация, поведенческая рамка «боль/удовольствие» и эволюционный
    поиск не переносятся: «genetical search» задокументирован как отклонённый
    прецедент (ADR-003, граница №13) — отбор по выживанию не даёт
    свидетельства; разведка допускается только бюджетированной,
    журналируемой и никогда не продвигающей артефакт выше UNVERIFIED без
    свидетельства; триплеты Хоара (AA §80) доказывают соответствие
    исполнения контракту, а не истинность контракта: истинность
    устанавливается верификацией контракта на домене (та же граница,
    что у корректности слоя); PDDL-план (AA §81) — гипотеза исполнения:
    каждый шаг проверяется контрактом до акта, мониторинг исполнения
    (PLANEX §52) обязателен; бисимуляция (AA §82) не вводит новых
    обещаний о мире: эквивалентность на конечной выборке трасс —
    скоринг, своп производится только по проверяемой эквивалентности
    на объявленном классе (граница №10).

21. **Информация, сходимость и адаптация — не знание:** битовая мера
    (Шеннон, AA §73) измеряет передачу и неопределённость, но не даёт
    статуса знания: энтропия и ёмкость ранжируют каналы и бюджеты,
    свидетельство же обязательно отдельно; теоремы пределов теории
    информации неконструктивны (существование кода ≠ артефакт кода) —
    каждая конфигурация обязана быть явной и версионируемой; сходимость
    перцептрона (AA §71) гарантирует остановку только при условии
    (линейная разделимость) и ничего не говорит о скорости и обобщении —
    условие применимости объявляется в SPEC до использования гарантии;
    ультрастабильность (Ашби, AA §72) — след адаптации, не знание:
    стабилизировавшаяся конфигурация униматоров не продвигается выше
    UNVERIFIED без свидетельства; слепой перебор униматоров — антиобразец:
    меню коррекций типизировано «класс нарушения → класс коррекции»,
    requisite variety — потолок разнообразия меню, не лицензия на
    перебор; стационарность сред не предполагается — устойчивость
    требуется на всех режимах домена (селективная устойчивость к полям),
    дрейф отслеживается гомеостатом (§36), а не статистической рамкой.

22. **Надёжность организации и представимость — не истина:** кворумная
    избыточность (мультиплексирование, AA §74) снижает частоту отказов
    проверки, но не продвигает артефакт по статусу: согласие N реплик —
    инженерная гарантия с условием применимости (ε<ε₀) и ценой N, а не
    свидетельство истинности; выше критического порога ε₀ избыточность
    бессильна — надёжность покупается качеством компонента, не числом
    реплик; регулярность (Клини, AA §75) — честный потолок класса
    поведения, не цель: REFLEX-ветка регулярна по замыслу, претензия
    регулярной ветки на общее рассуждение — нарушение класса; definite
    event — сознательная граница окна контекста, а не «забывчивость»;
    инвариант по группе преобразований (AA §76) — не универсальное
    распознавание: предикат валиден только на объявленной орбите,
    смена группы — миграция схемы с пересмотром артефактов.

23. **Автоматизация и ёмкость — режимы исполнения, не знание:**
    автоматизм (теория инстансов, AA §78) ≡ ускорение извлечения, не
    статус: победа извлечения в гонке с алгоритмом не продвигает
    артефакт выше PROMOTED и не заменяет свидетель применимости
    (предусловие + коридоры); срыв захвата (AA §77) — не «человеческая
    ошибка», а типизированный отказ: ложное срабатывание навыка
    журналируется как событие отказа с классом, супервизия (SAS)
    переносится только как функциональная роль редкой эскалации по
    триггерам — сознательная супервизия как феномен за границей
    (Статья VI); «7±2» (AA §79) — не константа архитектуры: бюджеты
    контекста — явные версионируемые параметры по классам элементов,
    калибруемые экспериментом; чанк без контракта и свидетельства не
    расширяет ёмкость — «имя» не есть знание (граница №12). Дуальная обработка (AA §85) — второе экспериментальное основание той же дисциплины: автоматизм по неизменному отображению (CM) ≡ режим исполнения на валидированном классе, не продвижение; вариативное отображение (VM) не даёт права на PROMOTED; «захват» ≡ типизированный отказ, закрываемый предусловием, а не свойство внимания.
