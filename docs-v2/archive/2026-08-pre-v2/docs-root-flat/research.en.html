Hypothesis format

Each hypothesis has four parts:

  • Claim. A precise statement of what the system should do.
  • Success criterion. A numeric threshold for confirmation.
  • Falsification criterion. A numeric threshold for rejection.
  • Experiment. The procedure that produces the numbers.

CONSTITUTION Article VI requires that every claim in the project be verifiable. Hypotheses are the canonical place to state a claim before it is implemented.

Preregistration

Before running an experiment, the preregistration record is committed to docs/research/reports/EXP-NNN-report.md with:

  • Dataset / corpus (fixed before the run)
  • Random seed (fixed)
  • Success and falsification criteria (already in HYPOTHESES.md)
  • Hyperparameters
  • Number of trials

After the run, the report is updated with measurements. Comparison against pre-registered values is then a one-line check.

By cluster

Related hypotheses are grouped. Pick a cluster if your interest is in a specific area:

  • Compute (H-001, H-002, H-003, H-015): how BIR actually computes. Capacity, parity, deterministic equivalence.
  • Knowledge (H-004, H-007, H-011): retrieval, storage, graph. Where information lives.
  • Learning (H-005, H-009, H-010, H-016): how neurons learn. Distillation, Tsetlin, WiSARD, monotone specialization.

  • Lifecycle (H-012, H-017, H-022): TaskCell, LTL model checking, self-observation corridor.

  • Cauldron (H-018, H-019, H-020, H-021): candidate generation, GUHA, AQ/LAD, budget scheduling, Levin 2⁻ˡ.
  • Socio-cultural (H-023…H-034): duality axis, RAT-index, longitudinal cohorts, Dunbar layers, Hofstede, moral foundations. These are validation hypotheses run on synthetic corpora, not algorithm implementations.

Training data

MATRIX distills HuggingFace models into BIR neurons. Models used:

  • HuggingFaceTB/SmolLM2-135M, SmolLM2-360M
  • Qwen/Qwen2.5-0.5B, Qwen2.5-1.5B
  • Qwen/Qwen3-0.6B, Qwen3-1.7B
  • deepseek-ai/DeepSeek-R1-Distill-Qwen-1.5B

Scripts: scripts/pretrain_neurons.py (distillation), scripts/train_local.sh (orchestration), scripts/merge_pretrained_neurons.py (consolidation).

# Train one model
bash scripts/train_local.sh --model HuggingFaceTB/SmolLM2-135M

# Or all cached models
bash scripts/train_local.sh --all
