# Четыре закона: нерушимые правила MATRIX

> **Слой:** История | **Время чтения:** 4 минуты | **Обновлено:** 2026-09-20

---

## Зачем нужны законы?

Каждый мощный инструмент нуждается в ограничителях. У машины — тормоза. У ядерного реактора — защитная оболочка.

У MATRIX есть четыре закона, которые **никогда** не могут быть изменены, отключены или обойдены — даже разработчиками.

---

## Четыре закона

### Закон I: Никаких LLM за рулём

**Что это значит:** Ядро мозга MATRIX никогда не использует большую языковую модель (вроде ChatGPT) для принятия решений.

**Почему:** LLM мощные, но непредсказуемые. Они могут галлюцинировать, лгать или давать разные ответы на один и тот же вопрос. Для критических решений нужна детерминированность.

**Аналогия:** Это как разница между калькулятором и гадалкой. Калькулятор всегда даёт один и тот же ответ. Гадалка... варьируется.

**Как это работает:**
```
✅ РАЗРЕШЕНО: LLM помогает с офлайн-обработкой данных
✅ РАЗРЕШЕНО: LLM генерирует обучающие примеры
❌ ЗАПРЕЩЕНО: LLM принимает решения во время работы
❌ ЗАПРЕЩЕНО: LLM отвечает на запросы пользователей напрямую
```

### Закон II: Этика заморожена

**Что это значит:** Четыре модулятора безопасности никогда не могут быть удалены или ослаблены:

| Модулятор | Функция |
|-----------|---------|
| `ETHICAL_FILTER` | Блокирует неэтичный контент |
| `SAFETY_MONITOR` | Отслеживает нарушения безопасности |
| `LIE_DETECTOR` | Обнаруживает обман |
| `CONSISTENCY_CHECKER` | Предотвращает противоречия |

**Почему:** Если бы этику можно было «выключить» в экстренной ситуации, это была бы не настоящая этика. Безопасность должна быть безусловной.

**Аналогия:** Как законы физики — нельзя проголосовать за отмену гравитации.

**Как это работает:**
```java
// Эти ID захардкожены как ЗАМОРОЖЕННЫЕ
public static final Set<String> FROZEN_IDS = Set.of(
    "ETHICAL_FILTER",
    "SAFETY_MONITOR",
    "LIE_DETECTOR",
    "CONSISTENCY_CHECKER"
);

// Любая попытка удалить их вызывает исключение
if (FROZEN_IDS.contains(id)) {
    throw new IllegalArgumentException("Невозможно удалить ЗАМОРОЖЕННЫЙ модулятор: " + id);
}
```

### Закон III: Никаких заявлений о сознании

**Что это значит:** Мы никогда не утверждаем, что MATRIX «осознаёт», «живой», «сознательный» или имеет «чувства».

**Почему:** Это научно непроверяемые утверждения. Делать их было бы нечестно и потенциально вредно.

**Аналогия:** Термостат «реагирует» на температуру, но он не «чувствует» холод. MATRIX «реагирует» на входные данные, но ничего не «чувствует».

**Что мы говорим вместо этого:**
- ❌ «MATRIX чувствует стресс» → ✅ «Уровень кортизола повышен»
- ❌ «MATRIX счастлив» → ✅ «Уровень дофамина высок»
- ❌ «MATRIX хочет исследовать» → ✅ «Исследовательское поведение активно»

### Закон IV: Детерминированные сиды

**Что это значит:** При одинаковом входе MATRIX всегда выдаёт одинаковый выход.

**Почему:** Воспроизводимость необходима для отладки, тестирования и доверия. Если вы не можете воспроизвести результат, вы не можете ему доверять.

**Аналогия:** Это как рецепт — те же ингредиенты, те же шаги, один и тот же торт каждый раз.

**Как это работает:**
```java
// Все экземпляры Random используют сидированные конструкторы
Random rng = new Random(42); // Тот же сид = та же последовательность

// CONSTITUTION I: нет wall-clock, нет несидированного Random в runtime
```

## Почему четыре закона, а не три или пять?

Эти четыре закона решают четыре фундаментальных риска ИИ:

| Риск | Закон |
|------|-------|
| Непредсказуемость | Закон I (Никаких LLM) |
| Небезопасное поведение | Закон II (Замороженная этика) |
| Ложные утверждения | Закон III (Никаких заявлений о сознании) |
| Невоспроизводимость | Закон IV (Детерминизм) |

Уберите любой — и критический риск останется без внимания.

---

## Что, если кто-то попытается нарушить законы?

Законы защищены на нескольких уровнях:

1. **Уровень кода:** Набор `FROZEN_IDS` захардкожен
2. **Уровень тестов:** Каждый тест проверяет существование ЗАМОРОЖЕННЫХ модуляторов
3. **Уровень архитектуры:** `DynamicModulatorRegistry` отклоняет попытки удаления
4. **Уровень документации:** Эта страница существует как контракт

Если кто-то попытается удалить ЗАМОРОЖЕННЫЙ модулятор, система выбрасывает исключение и логирует попытку.

## Философия

Эти законы вдохновлены Тремя законами роботехники Айзека Азимова, но адаптированы для современного ИИ:

| Законы Азимова | Законы MATRIX |
|----------------|---------------|
| Не навреди человеку | Этика заморожена |
| Повинуйся приказам (если...) | Никаких LLM в runtime |
| Защити себя | Детерминированные сиды |
| (нет) | Никаких заявлений о сознании |

Мы добавили четвёртый, потому что современные риски ИИ включают *обман* — заявления о возможностях, которых нет.

Запустите набор тестов CONSTITUTION, чтобы увидеть законы в действии:

```bash
./gradlew :matrix-core:test --tests "io.matrix.federation.registry.DynamicModulatorRegistryTest"
```

Ожидается: все тесты проходят. ЗАМОРОЖЕННЫЕ модуляторы не могут быть удалены.
