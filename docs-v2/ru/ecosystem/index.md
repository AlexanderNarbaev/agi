# Экосистема MATRIX

Этот раздел описывает то, что действительно можно **собрать на этом репозитории и запустить
из него** — два обслуживающих приложения, их интерфейсы, их предположения о развёртывании
и пределы, о которых должен знать вызывающий.

Всё здесь сказано против работающей системы. Там, где страницу этого раздела нельзя
подтвердить кодом или каноническим документом, она говорит об этом, а не утверждает.

## Что экосистема собой представляет сегодня

MATRIX — это **не** размещённый сервис. Здесь нет `api.matrix.ai`, нет API-ключа, нет
тарифов на лимиты и нет ценовых планов — ничего из этого не существует, а страницы, которые
их описывали, исправлены, а не сохранены. Продукт — это **репозиторий**: два приложения,
которые вы запускаете из исходников, реестр возможностей, который говорит, что каждое из них
действительно делает, и исследовательская запись, лежащая за утверждениями.

| | **цепочка A** — эпистемическое приложение | **цепочка B** — мозговой рантайм |
|---|---|---|
| процесс | Quarkus, `io.matrix.MatrixApplication` | JDK `HttpServer`, `io.matrix.api.MinimalHttpServer` |
| модуль | `matrix-core` | `matrix-api-gateway` |
| порт | **9091** (HTTP, по умолчанию `127.0.0.1`) | **8765** (`127.0.0.1`, если режим безопасности не говорит иного) |
| маршруты | **210** | **28** |
| основные поверхности | `/v1/workbench` (57), `/v1/cognitive` (11), `/v1` chat (6) и ещё 36 ресурсов | `/v1/analyze`, `/v1/explain`, `/v1/learn`, `/v1/teach`, `/v1/sleep`, `/v1/goals`, `/v1/federate`, `/v1/audit*`, `/v1/gpu`, `/v1/distill`, `/v1/bir`, `/v1/conflicts`, `/v1/generalize`, `/v1/status`, `/v1/transcode/*`, `/v1/inbox/scan`, `/v1/auth/login`, а также health- и OpenAPI-маршруты |
| ответ по умолчанию | настоящее приложение | **`stub`** — 87-строчный `StubBrainCycle`, если не задан `MATRIX_MODE=production` |

Цепочки **не встречаются**: B не достигает ни одного класса эпистемического и когнитивного
хранилищ, а изоляцию доказывает гейт, который падает при их встрече. Каноническое описание —
[`docs-v2/architecture/RUNTIME-TOPOLOGY.md`](../../architecture/RUNTIME-TOPOLOGY.md).

## Заявленный статус и его источник

Зрелость любой возможности описывается на **четырёх независимых осях** — есть ли исходный
код, включён ли он в производственный путь, что исполнялось и что это делает сейчас, — и
хранится в реестре
[`docs-v2/architecture/CAPABILITY-REGISTRY.yml`](../../architecture/CAPABILITY-REGISTRY.yml).
Три правила делают его честным:

1. возможность не может быть помечена `SERVED` без **названного обслуживающего пути**;
2. возможность не может быть помечена `MEASURED` без **воспроизводимого бенчмарка**;
3. возможность не может быть помечена `FORMALLY_VERIFIED` из-за одного факта существования
   файла спецификации — нужны доказательства model-checking.

## Предположения о развёртывании — ровно такие, какие есть

- **Развёртывания нет.** Продукт — репозиторий; версии релиза нет, а существующие теги
  старше нескольких волн работы.
- **Контейнерный стек** в `docker-compose.yml` реален и такой, каким объявлен: PostgreSQL,
  Redis и Kafka, приложение Quarkus на `8080` внутри контейнера (опубликован на loopback
  хоста) и профиль native-image. Стек **не стартует** без `MATRIX_SECURITY_TOKEN`, и
  приложение не обслуживает открытые записи без него.
- Профиль **native-image заблокирован**: инструментарий GraalVM на машине разработчика
  отсутствует, native-scope отказывается запускаться, а не сообщает о проходе, и
  возможность остаётся `BLOCKED`, пока сборка не состоится.
- **GPU — необязательный ускоритель** (решение владельца OD-047 от 2026-11-06), а не
  требование пути обслуживания. Измеренный коэффициент на пути обслуживания — **12.06×**
  (12.06 / 11.68 / 11.47 за три прогона), а на одиночном вызове ONNX — **0.24×**, то есть
  GPU там примерно в четыре раза медленнее. Измерение —
  [`docs-v2/engineering/W48-GPU-BENCHMARK.md`](../../engineering/W48-GPU-BENCHMARK.md).

## Пределы, о которых должен знать вызывающий

| предел | что это значит для вас |
|---|---|
| шлюз **по умолчанию обслуживает заглушку** | `/v1/analyze` отвечает из 87-строчной заглушки, если не задан `MATRIX_MODE=production`. Активный режим виден в `GET /health/live` |
| цепочка A открывает **два незаявленных порта** | 9093 (multicast) и 9094 (TCP) открываются, не появляясь ни в одной записи обслуживания — открытый вопрос владельца F-02 |
| **проба готовности всегда отвечает 503** | её включает реактивный источник PostgreSQL, и производственный код её не читает; пользуйтесь пробой живости |
| **нет резервной копии всей базы** | SQLite backup API не встречается в репозитории; drill восстановления работает на копии |
| **гейты качества не блокируют** | они живут в CI job с именем «Quality gates (can fail)» |
| **свойства на корпусе владельца пропускаются в CI** | два класса, которым нужен этот корпус, пропускаются на чистом раннере, потому что корпуса нет в git. Пропуск — не проход |

Полный список и владелец, которого ждёт каждый пункт, — в
[`docs-v2/governance/PROJECT-STATE.md`](../../governance/PROJECT-STATE.md) §4.
