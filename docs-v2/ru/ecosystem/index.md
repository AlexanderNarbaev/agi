## Почему MATRIX существует

Большие языковые модели мощные, но непрозрачные. Они галлюцинируют, не могут
объяснить себя и стоят дорого для запуска. MATRIX использует другой подход:
**гибридный мозг**, который сочетает:

- **BIR** (Boolean Inference Rules) — явная, аудируемая логика
- **HDC** (Hyperdimensional Computing) — векторно-символьная память
- **MCTS** (Monte Carlo Tree Search) — принципиальное планирование
- **FROZEN модуляторы** — Этика, Безопасность, Согласованность, Детектор лжи

Всё работает на **seeded Random** — каждое решение воспроизводимо. **Никаких LLM
в runtime-пути.** Весь inference происходит на сервере MATRIX.
