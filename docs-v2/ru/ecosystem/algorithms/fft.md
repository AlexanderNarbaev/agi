# FFT — Быстрое преобразование Фурье

> **EN-документация является канонической.** Перевод добавляется в T-03.5.
> См. полную документацию: [FFT (EN)](/ecosystem/algorithms/fft/)

FFT разлагает сигнал на частотные компоненты. Для аудио это позволяет MATRIX
распознавать тоны, высоты и фонемы без вызова нейронной сети.
