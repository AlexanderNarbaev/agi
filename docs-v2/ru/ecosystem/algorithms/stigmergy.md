# Стегимергия — непрямая координация

> **EN-документация является канонической.** Перевод добавляется в T-03.5.
> См. полную документацию: [Stigmergy (EN)](/ecosystem/algorithms/stigmergy/)

**Стегимергия** — механизм непрямой координации между агентами: агенты
модифицируют общую среду, и другие агенты реагируют на эти модификации,
а не на прямые сообщения. Известен в муравейниках — каждый муравей оставляет
феромоны, за которыми следуют другие.
