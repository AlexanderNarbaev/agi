# Sobel — детекция границ

> **EN-документация является канонической.** Перевод добавляется в T-03.5.
> См. полную документацию: [Sobel (EN)](/ecosystem/algorithms/sobel/)

Оператор Sobel — классический фильтр детекции границ, использующий два
свёрточных ядра 3×3 — одно для горизонтальных градиентов, другое для вертикальных.
