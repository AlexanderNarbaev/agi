# MCTS — Monte Carlo Tree Search

> См. полную документацию: [MCTS (EN)](/ecosystem/algorithms/mcts/)

MCTS — алгоритм планирования, который ищет в дереве решений через моделирование
случайных playout-ов. Известен благодаря победе над людьми в Go (AlphaGo, 2016).
