# Биохимическая сеть модуляторов

> **EN-документация является канонической.** Перевод добавляется в T-03.5.
> См. полную документацию: [Biochemical Network (EN)](/ecosystem/algorithms/biochemical/)

**Биохимическая сеть модуляторов** — это система связанных обычных
дифференциальных уравнений (ОДУ), моделирующая регуляторную сеть — подобно
генным регуляторным сетям в биологии. MATRIX использует её для моделирования
4 FROZEN модуляторов (Этика, Безопасность, Согласованность, Детектор лжи).
