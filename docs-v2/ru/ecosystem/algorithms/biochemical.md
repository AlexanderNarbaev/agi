# Биохимическая сеть модуляторов

> **EN-документация является канонической.** Перевод добавляется постепенно.
> См. полную документацию: [Biochemical Network (EN)](/ecosystem/algorithms/biochemical/)

**Биохимическая сеть модуляторов** — система связанных обычных дифференциальных
уравнений (ОДУ), моделирующая регуляторную сеть — подобно генным регуляторным сетям в
биологии.

**Её статус — остров.** В реестре возможностей строка `W44-BIOCHEM` читается:
`IMPLEMENTED` / **`ISLAND`** / `TESTED` / **`DORMANT`** — «подсистема без обслуживающего
пути». То есть сегодня она реализована и покрыта тестами, но **не входит ни в один
обслуживаемый путь**: мост `CognitiveModulationBridge` переносит её в когнитивный путь,
но сам мост остаётся островом. Ранее эта страница утверждала, что MATRIX использует сеть
для моделирования четырёх FROZEN-модуляторов; **это не так** — те модуляторы идут
отдельным путём, а биохимические коэффициенты никуда не подключены.

Каноническая страница: [Biochemical Network (EN)](/ecosystem/algorithms/biochemical/) ·
реестр: `docs-v2/architecture/CAPABILITY-REGISTRY.yml`, строка `W44-BIOCHEM`.
