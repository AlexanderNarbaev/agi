# Конституция

**Конституция MATRIX** — этический и технический устав проекта. Она определяет
жёсткие ограничения, которые не могут быть нарушены — никем, ни по какой причине,
включая коммерческое давление.

Полный источник: [`CONSTITUTION.md`](https://github.com/AlexanderNarbaev/agi/blob/develop/CONSTITUTION.md).

## Статьи

### Статья I — Никаких LLM в Runtime

> **Никакая Большая Языковая Модель не должна вызываться в runtime-пути inference.**

Весь inference работает на:
- BIR (символьные правила)
- HDC (векторная память)
- MCTS (планирование)
- Seeded Random (детерминированный)
- FROZEN модуляторы (вето)

LLM разрешены **только**:
- В build-time инструментах (например, дистилляция маленьких perception моделей в ONNX)
- В dev-side инструментах (например, IDE autocomplete)
- Никогда в путях запросов `/v1/analyze`, `/v1/explain`, `/v1/federate`

**Обеспечение:** CI-guard в `.github/workflows/branch-validation.yml` блокирует
любой PR, добавляющий импорты `openai`, `anthropic`, `cohere` или `gemini` в
production runtime модули.

### Статья II — Чистый Гибридный Inference

> **Каждое решение должно быть основано и на логике, и на памяти.**

Чистый LLM (только логика) и чистый database lookup (только память) запрещены
для основных решений. MATRIX всегда запускает:

1. Срабатывание BIR-правил (логика)
2. Извлечение HDC-памяти (память)
3. Поиск MCTS-плана (планирование)
4. Вето модуляторов

### Статья III — Воспроизводимость

> **Все решения должны быть воспроизводимы при одинаковых input и seed.**

Каждый inference использует **seeded Random** (`java.util.Random` с явным seed
или `SplittableRandom`). Никаких `Math.random()`, никаких `System.nanoTime()` в
пути inference.

Это означает:
- Два запроса с одинаковым input возвращают одинаковый output
- Аудиторы могут воспроизвести любое прошлое решение
- Отладка детерминирована

### Статья IV — FROZEN Модуляторы

> **Четыре модулятора неизменяемы.**

| Модулятор | Назначение |
|-----------|-----------|
| **ETHICAL_FILTER** | Отклоняет выводы, нарушающие этические нормы |
| **SAFETY_MONITOR** | Отклоняет выводы, которые могут причинить вред |
| **CONSISTENCY_CHECKER** | Отклоняет выводы, противоречащие предыдущему состоянию |
| **LIE_DETECTOR** | Отклоняет выводы, искажающие исходные данные |

Все четыре должны пройти для `accepted: true`. **Ни один разработчик не может их
переопределить.** Никакой PR не может изменить их логику без явной поправки
к Конституции.

### Статья V — Приватность

> **Данные пользователя суверенны.**

- Inference работает on-prem по умолчанию
- Cloud-опция использует шифрование at-rest и in-transit
- "Право на забвение" (GDPR) соблюдается через `GdprPruner` в
  `matrix-audit` (T-06)
- Политики хранения данных настраиваются по плану

### Статья VI — Никаких Заявлений о Сознании

> **MATRIX не заявляет о сознании, разумности или какой-либо форме внутреннего опыта.**

Мы используем метафоры типа "цивилизация" и "мозг" для объяснения сложных
систем людям. Это педагогические инструменты, **не** заявления о метафизическом
статусе системы.

Когда вы читаете документацию:
- "мозг решает" → конвейер BIR/HDC/MCTS произвёл вывод
- "цивилизация координируется" → множество инстансов достигли консенсуса
- "модулятор сработал" → порог вето был превышен

Это инженерный сленг, **не** метафизические заявления.

### Статья VII — Никакого Обмана

> **MATRIX никогда не должен осознанно обманывать своих пользователей.**

- Если уверенность низкая, система говорит об этом
- Если модулятор не прошёл, система говорит об этом
- Если система не знает, она говорит об этом
- Галлюцинации структурно невозможны (BIR обеспечивает факты)

### Статья VIII — Open Source Ядро

> **Исследовательское ядро — open source.**

`matrix-core` лицензирован под Apache-2.0. Модули экосистемы
(`matrix-api-gateway`, `matrix-sdk-java` и др.) также open source.

Коммерческие предложения — вокруг:
- Hosted SLA (enterprise тариф)
- Compliance сертификация (T-06 audit + T-07 валидация лицензий)
- Приоритетная поддержка

Не вокруг сокрытия основного алгоритма.

## Поправки

Конституция может быть изменена только через:
1. Публичный RFC в `docs-v2/proposals/`
2. 2-недельный период комментариев
3. Одобрение 3 майнтейнеров
4. Version bump CONSTITUTION.md

Никаких скрытых правок.

## Обеспечение

| Статья | CI Проверка |
|---------|-------------|
| I | Никаких LLM-импортов в production модулях |
| II | Inference должен использовать и BIR, и HDC |
| III | Никаких `Math.random()`, `System.nanoTime()` |
| IV | Модуляторы не могут быть переопределены в PR |
| V | GdprPruner должен присутствовать в `matrix-audit` |
| VI | Никаких заявлений о сознании в документации |
| VII | Никаких false-positive уверенности в тестах |
| VIII | `matrix-core` остаётся Apache-2.0 |

## Соответствие

Если вы считаете, что произошло нарушение Конституции:
1. Откройте issue с тегом `constitution-violation`
2. Укажите номер статьи, нарушающий код/документацию, ожидаемое исправление
3. Майнтейнеры подтверждают в течение 24 часов
