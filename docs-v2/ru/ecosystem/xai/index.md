# Глубокое погружение в XAI

> См. полную документацию: [XAI Deep Dive (EN)](/ecosystem/xai/)

## Краткий обзор

Каждый ответ MATRIX включает `explain_id` — дескриптор для полной 5-шаговой трассы:

1. **INPUT_NORMALIZED** — нормализация входа
2. **BIR_RULES_FIRED** — сработавшие правила
3. **HDC_MEMORY_RETRIEVED** — извлечённые воспоминания
4. **MCTS_PLAN_SELECTED** — выбранный план
5. **MODULATORS_APPLIED** — 4 модулятора проголосовали
