# Что такое MATRIX?

## Аналогия с цивилизацией

MATRIX — это **гибридная нейро-символическая цивилизация**. Каждый запрос
пользователя порождает координированную последовательность когнитивных
процессов — восприятие, извлечение памяти, логический вывод, планирование,
действие — подобно цивилизации специализированных агентов.

Но в отличие от чёрного ящика LLM, каждый шаг **аудируем**:
1. **BIR** запускает явные правила
2. **HDC** извлекает воспоминания как векторы
3. **MCTS** ищет в дереве решений
4. **Модуляторы** (Этика, Безопасность, Согласованность, Детектор лжи) контролируют каждый вывод
5. **XAI трассы** записывают каждый шаг

## Почему нейро-символика?

| Чистый LLM | Чистый символьный | **MATRIX (Гибрид)** |
|------------|-------------------|---------------------|
| ❌ Галлюцинирует | ❌ Хрупкий | ✅ Основан на правилах |
| ❌ Не может объяснить | ✅ Полностью объясним | ✅ Оба |
| ❌ $0.01/запрос в облаке | ✅ Бесплатно локально | ✅ Дёшево (BIR O(1)) |
| ❌ Стохастический | ✅ Детерминированный | ✅ Seeded Random |
| ❌ Риск приватности | ✅ On-prem | ✅ On-prem |
| ✅ Сильный язык | ❌ Слабый язык | ✅ Дистиллированный ONNX для языка |
| ❌ Нет фактической памяти | ❌ Нет обобщения | ✅ HDC-память |

## Три движка

### BIR — Boolean Inference Rules

Логика, которая запускается **первой**, до любого нейронного вычисления.
Кодирует знания предметной области как правила if-then над символьными
атомами. Полностью детерминирован. Аудируем.

```java
rule: IF temperature(sensor-1) > 90 THEN alarm()
```

### HDC — Hyperdimensional Computing

Память как 10,000-битные векторы. Кодирование — это binding (XOR + majority),
извлечение — similarity (cosine). Обобщает на нескольких примерах. **Никаких
нейронных сетей** — чистая векторная арифметика над бинарными векторами.

```java
vec(cat) XOR vec(sits_on) XOR vec(mat) = memory_record
```

### MCTS — Monte Carlo Tree Search

Планирование как поиск по дереву игры. Rollouts моделируются, лучший ход
побеждает. Использовался в AlphaZero. Здесь планирует **последовательности
действий** над базой правил.

## Четыре FROZEN модулятора

Эти **неизменяемы** (Конституция, Статья IV):
- **ETHICAL_FILTER** — отклоняет выводы, нарушающие этику
- **SAFETY_MONITOR** — отклоняет выводы, которые могут причинить вред
- **CONSISTENCY_CHECKER** — отклоняет выводы, противоречащие предыдущему состоянию
- **LIE_DETECTOR** — отклоняет выводы, искажающие исходные данные

Все четыре должны согласиться, прежде чем любой ответ будет принят.
**Ни один разработчик не может их обойти.** Это обеспечивается на уровне
matrix-core, а не API gateway.

## Как течёт запрос

```
Input
  ↓
[Sensory] транскодеры (FFT для аудио, Sobel для видео)
  ↓
[BIR] срабатывание правил
  ↓
[HDC] извлечение памяти
  ↓
[MCTS] поиск плана
  ↓
[MODULATORS] 4-стороннее вето
  ↓
Output + Explain трасса
```

Каждый шаг записывается. Каждый шаг воспроизводим. **Каждый шаг аудируем.**

## Чем MATRIX отличается от LLM?

Самое важное отличие: **LLM отсутствует в пути запроса.**

Запрос пользователя никогда не достигает LLM. Он достигает гибридного
механизма рассуждений, который сочетает:
- Маленькую **дистиллированную** ONNX-модель для восприятия (текст, аудио, изображение)
- Чисто символьные алгоритмы для логики и памяти
- Детерминированное планирование

Это означает:
- ✅ Никаких галлюцинаций (BIR обеспечивает факты)
- ✅ Объяснимость (каждый шаг прослеживаем)
- ✅ Воспроизводимость (seeded Random)
- ✅ Дёшево в запуске (не нужен GPU-кластер для inference)
- ✅ On-prem (ваши данные никогда не покидают ваш сервер)

## Когда использовать MATRIX

✅ **Используйте MATRIX, когда:**
- Вам нужна объяснимость (регулируемые отрасли: финансы, здравоохранение, юриспруденция)
- Вам нужна воспроизводимость (CI/CD, научные вычисления)
- Вам нужно запускать on-prem (суверенитет данных)
- Вам нужно интегрировать символьные знания (правила, онтологии)
- Вы строите критичные к соответствию приложения

❌ **Не используйте MATRIX, когда:**
- Вам нужен свободный творческий текст (используйте LLM)
- Вам нужен веб-поиск в реальном времени (используйте search API)
- Вы быстро прототипируете без требований к объяснимости
