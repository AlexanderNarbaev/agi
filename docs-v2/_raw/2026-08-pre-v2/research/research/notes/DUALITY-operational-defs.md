# Операциональные определения: Дуальность мира и рационализаторское зерно

**Статус: living** · Preregistered operational definitions для H-023…H-026 (EXP-019).
**Дата:** 2026-08-10
**Назначение:** Зафиксировать операциональные определения ДО сбора данных. Без этих определений результаты недействительны (CONSTITUTION VI.3).

---

## 1. Дуальная ось (D-axis)

**Определение:** D-axis — многомерный бинарный классификатор, разделяющий синтетические суждения по признаку, ассоциированному с половым диморфизмом в психологической литературе.

**Операционализация:** D-axis состоит из 4 бинарных атрибутов с известным ground truth:

| Атрибут | Полюс A («маскулинный» полюс) | Полюс B («феминный» полюс) | Источник в литературе |
|---|---|---|---|
| D1: Когнитивный стиль | Логика / аналитика (logic/analytic) | Интуиция / холизм (intuition/holistic) | Baron-Cohen (2002), Lippa (2010) |
| D2: Социальная ориентация | Конкуренция / индивидуация (competition/individuation) | Кооперация / аффилиация (cooperation/affiliation) | Eagly & Wood (1999), Buss (1989) |
| D3: Коммуникативный стиль | Инструментальность / отчёт (instrumental/report) | Экспрессивность / раппорт (expressive/rapport) | Tannen (1990), Maccoby (1998) |
| D4: Агентность | Агенс / объект-ориентация (agentic/object-oriented) | Коммюн / отношение-ориентация (communal/relation-oriented) | Bakan (1966), Eagly (1987) |

**Измерение:** Каждый атрибут — бинарная метка (0 = полюс A, 1 = полюс B), присваиваемая каждому синтетическому суждению НЕЗАВИСИМО от пола респондента. Ground truth — консенсус ≥3 raters (κ ≥ 0.7).

**Примечание:** D-axis НЕ отождествляется с биологическим полом респондента. Это атрибут СУЖДЕНИЯ, а не респондента.

## 2. Суждение (judgment)

**Определение:** Синтетическая единица — триплет:

```
J = (statement, pre_decision_confidence, post_decision_rationalization)
```

**Формат statement:** Утверждение на естественном языке (русский), требующее оценки по шкале Ликерта 1–5 (1 = полностью не согласен, 5 = полностью согласен). Каждое утверждение размечено по D-axis (D1–D4) и имеет известный ground truth (консенсус экспертов).

**Примеры:**
- *«При решении сложной задачи важнее следовать интуиции, чем формальной логике.»* [D1=1 — intuition pole]
- *«В рабочем коллективе конкуренция эффективнее кооперации для достижения результата.»* [D2=0 — competition pole]
- *«Лучше прямо сказать о проблеме, чем смягчать формулировку ради сохранения отношений.»* [D3=0 — instrumental pole]

**Pre-decision confidence (C_pre):** Уверенность респондента в ответе ДО получения обратной связи. Шкала: 0.0 (полная неуверенность) … 1.0 (полная уверенность). Измеряется сразу после statement, до rationalization.

**Post-decision rationalization (C_post):** Уверенность респондента ПОСЛЕ предоставления возможности обосновать своё суждение. Шкала та же (0.0…1.0). Респондент получает: *«Объясните, почему вы дали такой ответ»* (free text), затем повторно оценивает уверенность.

## 3. Асимметрия суждений (judgment asymmetry)

**Определение:** Систематическое различие в уверенности суждений вдоль D-axis.

**Метрики:**

| Метрика | Формула / Определение | Порог H-023 |
|---|---|---|
| Δ-confidence | Δ = mean(C_pre \| D=0) − mean(C_pre \| D=1) | подтверждение: \|Δ\| > 0.10 + bootstrap 95% CI не включает 0 |
| ROC-AUC | AUC классификатора, предсказывающего D-полюс по C_pre | подтверждение: AUC > 0.55 (выше случайного) + permutation p-value < 0.05 (FDR-скорректированное) |
| Per-attribute Δ | Δ_i для каждого D1…D4 отдельно | подтверждение: ≥2 из 4 атрибутов значимы после FDR-коррекции |
| Effect size (Cohen's d) | d = Δ / σ_pooled | опровержение: d < 0.20 (trivial) для всех 4 атрибутов |

**Критерии H-023 (preregistered):**
- **Подтверждение:** Δ-confidence значимо (bootstrap 95% CI не перекрывает 0) и ROC-AUC > 0.55 с permutation p < 0.05 (FDR) минимум на 1 из 4 D-атрибутов.
- **Опровержение:** Ни один D-атрибут не показывает значимой асимметрии после FDR-коррекции (p_adj > 0.05 для всех 4), И effect size d < 0.20 для всех.

## 4. RAT-индекс (rationalization seed index)

**Определение:** RAT-индекс — нормализованное расстояние между pre-decision confidence и post-decision rationalization confidence.

**Расчёт:**

```
RAT = (C_post − C_pre) / (1 − C_pre),  для C_pre < 1.0
RAT = 0,                                  для C_pre = 1.0 (нет места для роста)
```

**Интерпретация:**
- RAT > 0: уверенность ВЫРОСЛА после рационализации (post-hoc justification)
- RAT = 0: уверенность не изменилась
- RAT < 0: уверенность СНИЗИЛАСЬ после рационализации (редкий случай — критическая рефлексия)

Диапазон: [−1, 1]. Типичные значения по литературе: [0, 0.5] (Kahneman 2011, Stanovich 2011).

**Критерии H-024 (preregistered):**
- **Подтверждение:** RAT > 0 значимо (one-sample bootstrap, 95% CI не включает 0) И Spearman ρ(RAT, conformity) > 0.20 с p < 0.05.
- **Опровержение:** RAT ≤ 0 (уверенность не растёт после рационализации) ИЛИ ρ(RAT, conformity) ≤ 0.05.

## 5. Конформность (conformity)

**Определение:** Степень отклонения индивидуального суждения от majority baseline.

**Метрика:**

```
conformity = 1 − |individual_response − majority_mode| / 4
```

Где majority_mode — мода ответов по всему корпусу для данного statement.

Диапазон: [0, 1], где 1 = полное совпадение с большинством.

**Preregistered:** Конформность измеряется для каждого респондента и каждого суждения отдельно. Агрегация — среднее по респонденту.

## 6. Онтологическая позиция: Essentialism vs Constructionism

**Определение:** Бинарная ось, измеряющая, склонен ли респондент приписывать наблюдаемым различиям (в частности, гендерным) фиксированную «природу» (essentialism) или социальный конструкт (constructionism).

**Операционализация:** Адаптированная шкала Haslam et al. (2000) — 4 утверждения, каждое оценивается по шкале Ликерта 1–5:

1. *«Различия между мужчинами и женщинами в поведении имеют биологическую, врождённую природу.»* (naturalness)
2. *«Психологические различия между мужчинами и женщинами стабильны и не меняются со временем.»* (stability)
3. *«Человек либо обладает "мужскими" чертами, либо "женскими" — промежуточных вариантов мало.»* (discreteness)
4. *«Гендерные различия невозможно изменить воспитанием или культурой.»* (immutability)

**Расчёт:** Сумма баллов по 4 утверждениям (диапазон 4–20). Essentialism: score ≥ 13 (верхняя треть шкалы). Constructionism: score ≤ 8 (нижняя треть шкалы). Средние значения исключаются из анализа (exclusion criterion).

**Критерии H-026 (preregistered):**
- **Подтверждение:** Spearman ρ(RAT_mean, essentialism_score) > 0.25 с bootstrap 95% CI не включает 0; эффект сохраняется при контроле cognitive ability (CRT).
- **Опровержение:** ρ < 0.10 ИЛИ эффект исчезает при контроле CRT (partial ρ < 0.05).

## 7. Схема эксперимента

### 7.1. Синтетические корпуса

| Параметр | Значение |
|---|---|
| Количество корпусов | ≥3 (минимально: русскоязычный, англоязычный, смешанный/контрольный) |
| Суждений на корпус | ≥200 |
| D-атрибутов на суждение | 4 (D1–D4) |
| Ground truth | Консенсус ≥3 raters, κ ≥ 0.7 |
| Балансировка | ~50% D=0 / 50% D=1 по каждому атрибуту |

### 7.2. Процедура (preregistered)

1. **Demographics:** пол, возраст, образование (только для стратификации, не для анализа D-axis).
2. **Essentialism scale:** 4 утверждения (см. §6).
3. **CRT (Cognitive Reflection Test):** 3 вопроса (Frederick 2005), русская адаптация.
4. **Judgment block:** Для каждого из ≥200 суждений:
   - Предъявление statement
   - Оценка по шкале 1–5 (response)
   - Pre-decision confidence (C_pre)
   - Free-text rationalization prompt
   - Post-decision confidence (C_post)
5. **Порядок:** Рандомизированный для каждого респондента (seed фиксирован для воспроизводимости).

### 7.3. Контролируемые переменные

- Время ответа (логируется)
- Длина rationalization текста (логируется)
- Порядок предъявления (seed-based рандомизация)
- Пол респондента (стратификация, не предиктор)
