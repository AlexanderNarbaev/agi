Architecture Decision Records (6)

Почему архитектура такая, какая есть

6 документов · normative
ADR-001MATRIX vs RAG

MATRIX — детерминированное ядро; RAG — недоверенный периферийный сервис. Каждый делает то, что умеет.

ADR-002BIR — каноническое представление

Почему три эквивалентные формы, а не одна. Компромиссы ёмкости, скорости, верифицируемости.

ADR-003Цетлин vs живые механизмы

Почему автоматы Цетлина, а не градиентное обучение, для BIR-продюсеров.

ADR-004Бюджетные расписания Cauldron

Почему Левин 2⁻ˡ, а не равномерное, для распределения бюджета кандидатов.

ADR-005Трёхзначные вердикты гейтов

Почему гейты возвращают ALLOW/DENY/UNDECIDED, а не boolean. Как undecided пробрасывается.

ADR-006LLM и сторы — не зависимости

MATRIX не зависит от LLM или внешнего хранилища. Это периферийные сервисы, верифицируемые на границе.
