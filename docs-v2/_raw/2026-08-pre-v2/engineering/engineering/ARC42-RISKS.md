# ARC42, раздел 11. Риски и технический долг

**Статус: living** · Реестр рисков архитектуры в формате arc42 §11. Остальные разделы arc42 покрыты существующими документами: цели — GOALS-REQUIREMENTS (раздел 1), ограничения — CONSTITUTION + NFR (раздел 2), контекст — C4 L1 (раздел 3), стратегия — SYSTEM-SYNTHESIS (раздел 4), строительные блоки — C4 L2/L3 + DESIGN (раздел 5), сценарии — BRC-контур DESIGN-03 (раздел 6), развёртывание — C4 deployment (раздел 7), сквозные концепции — ADR-002…006 (раздел 8), решения — ADR (раздел 9), качество — METRICS + HYPOTHESES (раздел 10). Этот файл — только риски/долг.

## 3. Правила реестра

- Новый риск — только с митигацией и трассировкой; риск без митигации = открытая проблема (vision/OPEN_PROBLEMS), не риск.
- Риски R-xx с гипотезами закрываются экспериментами; статус риска меняется в том же коммите, что и результат EXP.
- Отрицательные результаты экспериментов переводят риск в «материализован» и открывают fork-альтернативу (граница №5 SYSTEM-SYNTHESIS).
