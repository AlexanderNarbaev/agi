# ADR-004. Планировщик бюджетов рядов Cauldron: расписание Левина как базовое, сопряжённый DP как ставка; гомеостат коридоров

- **Статус:** proposed (базовое расписание принято к реализации; сопряжённый бюджетер и гомеостат — пререгистрированные ставки H-021/H-022)
- **Дата:** волна 6 документации
- **Связи:** DESIGN-07 §2/§5, HYPOTHESES H-019/H-021/H-022, EXP-019/021/022, C4 (компоненты Cauldron), FR-07, NFR-01/04/07/10

## Контекст

Cauldron порождает кандидатов рядами нарастающей сложности под жёстким энергетическим конвертом (G-A, NFR-01). Нужна дисциплина распределения бюджета между рядами и внутри рядов. Варианты: (а) равномерное расписание; (б) жадный per-row выбор (максимум немедленного покрытия на джоуль); (в) расписание Левина 2^−l с Kt-скорингом; (г) составной планировщик (backward value iteration + теневые цены). Отдельный вопрос: кто следит, что сам планировщик не уводит систему из коридоров (энергия, UNDECIDED, отказы гейтов).

Требования: детерминизм (NFR-04), обрезание бюджета (NFR-07 — никакой ряд не блокирует остальные), онлайн-контур не блокируется (NFR-10), фактическое распределение бюджета аудируемо (witness запуска).

## Решение

1. **Базовое расписание — Левин**: ряд с длиной описания l получает долю бюджета ∝ 2^−l; очередь внутри ряда — по Kt-скорингу (длина описания + log стоимости проверки). Проверяется против равномерного в EXP-019 (H-019).
2. **Сопряжённый бюджетер — ставка поверх базового**: backward value iteration по состояниям рядов (принцип оптимальности Беллмана) с теневыми ценами ψ (сопряжённая система Понтрягина) и обрезанием ветвей тем же расписанием Левина (approximate DP — ответ на проклятие размерности). Внедряется только при подтверждении H-021 против жадного контроля в EXP-021.
3. **Гомеостат коридоров**: контур отрицательной обратной связи с версионируемыми коридорами метрик (энергия/тик, покрытие, доля UNDECIDED, отказы гейтов); отклонение → минимальная коррекция из версионируемого меню (перебалансировка бюджетов, понижение фрагмента); каждая коррекция — событие с witness. Ставка H-022, проверка EXP-022.
4. **Режимы предельных нагрузок — bang-bang дисциплина**: при линейной стоимости оптимум на границе конверта; переключения режимов редки и каждое логируется как аудируемое событие.

## Основания (атлас)

- Расписание Левина 2^−l и Kt — московская школа (§27); универсальный поиск оптимален для инверсии с точностью до константы — у нас эвристика, не теорема.
- Принцип максимума и сопряжённая система — Понтрягин (§36); необходимое, не достаточное условие → ставка, не закон.
- Принцип оптимальности и проклятие размерности — Беллман (§36); составное DP — прямой ответ.
- Отрицательная обратная связь и гомеостаз — Винер (§36); «дисфункция = шум в канале» → дисциплина телеметрии: прежде чем корректировать механизм, проверь целостность сигнала.

## Последствия

**Положительные:**
- Бюджетирование становится вычислимым и аудируемым: плановое против фактического распределения — в witness каждого запуска (EXP-019/021).
- Длинные ряды не голодают, короткие не доминируют — свойство расписания Левина; жадные и равномерные политики задокументированы как контроли, а не кандидаты.
- Гомеостат заменяет аварийные остановки коррекциями; коридоры версионируются → воспроизводимость поведения контура (NFR-04).

**Отрицательные / цена:**
- Сопряжённый бюджетер требует модели ценности состояний; при её отсутствии/нестабильности — откат к базовому расписанию Левина (фолбэк зафиксирован здесь).
- Гомеостат — инженерный контур, не «саморегулирующийся разум»: меню коррекций закрыто и версионируется; новые коррекции — только через ADR (Статья VI, граница №7 SYSTEM-SYNTHESIS).

## Отвергнутые альтернативы

- **Равномерное расписание как база:** контрпример Левина — равномерность экспоненциально расточительна на длинных описаниях; остаётся контролем EXP-019.
- **Жадный per-row как база:** игнорирует «сейчас против потом» (двухточечная краевая задача, §36); остаётся контролем EXP-021.
- **RL-планировщик:** модель переходов P(s'|s,a) в Котле неизвестна заранее; вынесено в исследовательскую ветку, не в ядро (граница §36).

## Проверяемость

- EXP-019 (H-019): покрытие на джоуль ≥ +15% против равномерного на ≥2 доменах.
- EXP-021 (H-021): ≥ +10% против жадного при равном конверте; регресс UNDECIDED > 2 п.п. — фальсификатор.
- EXP-022 (H-022): удержание в коридорах ≥ 95% при 2× вариативности нагрузки; рост энергии > 10% — фальсификатор.
- Фолбэк-матрица (базовое Левин ← сопряжённый ← RL-ветка) фиксируется в DESIGN-07 при реализации.
