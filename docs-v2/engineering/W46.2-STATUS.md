## 2. The repair — what was broken and what it cost

**The W46.0 audit found 51 broken links. The checker found 360 strict failures** — the wider
scope, the wider rule set, and the identifier analysis the directive asks for. **All 360 are
now zero.** The gate is green: `python3 scripts/docs-link-check.py --root . --strict` exits
**0**.

| the class | before | after | what the repair was |
|---|---|---|---|
| `BROKEN_LINK` | 75 | **0** | the renumbered series repaired by subject; the site routes recognised as routes; the nine references with no counterpart marked with an explicit reason |
| `MISSING_PATH` | 124 | **0** | the v1-tree references marked; the runtime artefacts and the placeholders marked; the scripts and the two canonical documents **written** |
| `DUPLICATE_IDENTIFIER` | 127 | **0** | the resolution rule rewritten: the register of a family defines, the reports reference |
| `UNDEFINED_IDENTIFIER` | 34 | **0** | the eleven genuine gaps recorded as **Q-W46-19** and marked; the patterns marked as patterns |

**The two renumbering repairs, with their evidence:** `DESIGN-13-brain-pipeline` →
`DESIGN-03-pipeline` (the request pipeline); `DESIGN-07-consolidation-cycle` →
`DESIGN-07-lifecycle` (the file that holds `lifecycle/ConsolidationCycle`);
`DESIGN-04-hades-burden` → `DESIGN-10-binary-reservoir` (the file that holds HADES);
`DESIGN-08-hierarchical-memory` → `DESIGN-05-memory` (M0…M4); `DESIGN-14-boolean-rag` →
`DESIGN-14-bir-migration`. The SPEC series the same way: `SPEC-005-deliberation` →
`SPEC-006-consciousness-deliberation`, `SPEC-006-action` → `SPEC-005-action`,
`SPEC-007-memory-hierarchy` → `SPEC-011-memory-hierarchy`.

**The rule the checker now applies, and it is the interesting part of this phase:**

> **A register defines; everything else references.** The register of a family is an explicit
> mapping, not a guess — because a heuristic cannot tell a register from a mirror:
> `docs-v2/vision/FINALSUMMARY.md` restates the hypothesis register faithfully, and it is a
> mirror, not a second register.

**And the two exemptions that make a repair honest:**

- `<!-- no-link: the reason -->` — a document that names a file **in order to say that the
  file does not exist** is not making a broken reference. 65 references carry one.
- `<!-- no-id: the reason -->` — the same for an identifier. 25 references carry one.

**Both are auditable: the reason is on the line.** A silent fix would have hidden exactly the
facts this wave exists to surface.

## 3. The history that was preserved, not erased

**No document was deleted. No historical record was rewritten.** The two documents this phase
rewrote are the two that had to change:

- **`docs-v2/architecture/RUNTIME-TOPOLOGY.md`** described a cluster that was designed and
  never built — PostgreSQL, Redis, Kafka, Loki, a Pekko actor cell. Its **text is preserved
  verbatim in §7** of the new document, under the heading *"the cluster pipeline that was
  designed and never built"*, with the warning that none of it is in the running topology.
- **`docs-v2/INDEX.md`** listed documents in backticked prose and had **zero** clickable
  links. It is now a link table: **81 links, all of them resolve**, and it names the canonical
  set first.

**The statuses that were applied** — the documents that record a past state now say so:
`INSTALL.md`, `SESSION.md`, `MIGRATION.md`, `docs-v2/TRANSFORMATION-PLAN.md`,
`docs-v2/engineering/RELEASE-NOTES.md`, `docs-v2/quality/RECON-W33.1-runbook-D3-D5.md`,
`docs-v2/research/summaries/INDEX-W20.md` → `HISTORICAL`; `docs-v2/archive/*` → `ARCHIVED`;
the hypothesis registers and the research reports → `RESEARCH`.

**The negative results are now discoverable.** `docs-v2/research/NEGATIVE-RESULTS-INDEX.md`
holds the **refuted** hypotheses (H-002, H-003, H-035 — every one `refuted-toy`), the
**rejected** capabilities (the connectome: 159 tests, 0 production callers; the biochemical
island; the measurement cluster; the gateway's JAX-RS facade), and the **corrected claims**
(33,000× never measured; 90 % retention never measured; 724 → 9,432 tests; 9 → 15 TLA+
specifications, 14 of them gated; 25 % → 30 % baseline; "the GPU is unavailable" is a
loader-path fact, not a hardware fact; `MinimalHttpServer` **is** served).

**And the dangerous finding the worker surfaced:** **twelve identifiers carry a different
claim under the same number** between the research register and `docs-v2/science-v2/`. The
register's **H-002 is `refuted-toy`**; science-v2's **H-002 is "HDC Shows Superior Sample
Efficiency ✅"** — a refutation and a confirmation under one number. That is recorded, not
silently fixed; the repair is the owner's (**Q-W46-19** covers the undefined ones, and the
science-v2 divergence is on the list for the owner).

**W46.2 is complete.** The repository now has a canonical set of **eighteen** documents, one
