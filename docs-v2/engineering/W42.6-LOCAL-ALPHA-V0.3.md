## 1. What this Alpha is

A **local** learning system that runs on one machine with **no mandatory
external service**: no PostgreSQL, no Redis, no Kafka, no OTLP collector, no
model API, no network. The store is an embedded SQLite file; the application
starts in **1.3 seconds**.

It does one thing end to end and shows its work: it **takes a concept out of
a real document, explains it from its own stored knowledge, answers about
it at four levels of abstraction, says what it does not know, refuses a
question whose premise its own knowledge contradicts, gives the learner the
next exercise, measures the learner on items it did not teach, writes its
own account of the imported concept, forgets the old records without
destroying them, and keeps every bit of it across a forced kill.

**What it is not:** a general intelligence, a model, or a system that learns
from a person. §3 says what was measured and §4 names what is not.

**The restart was a `SIGKILL` of the application's own JVM, with the SQLite
write-ahead log unclean** — 469 712 bytes pending at the moment of the
kill. The recovery read every one of them.

**One correction to the record:** an earlier run of this checklist showed
the imported knowledge *missing* after the restart. The cause was the
checklist itself — it called `POST /load`, which **replaces the workspace's
knowledge**, and the reload therefore wiped the imported concept. The
restart was not at fault; the order of the steps was. The checklist now
loads once, before the import, and never again.

## 3. What is measured, and what is not

**Measured, on the W42 benchmark (34 items, the same instrument since
W42.0):**

| | W42.0 | W42.1 | W42.3 | **W42.5** |
|---|---|---|---|---|
| the answer accuracy | 0.583 | 0.583 | 0.792 | **0.792** |
| the abstention quality | 0.400 | 0.700 | 0.700 | **0.900** |
| the BM25 overlap | 0.593 | 0.593 | 0.594 | **0.594** |
| the Russian items | 0/5 | 0/5 | 4/5 | **4/5** |
| the `FALSE_PREMISE` items | 0/2 | 0/2 | 0/2 | **2/2** |

**Measured, on the dialogue cases (168, RU + EN):** the class of the
utterance **168/168**; the answerability over the in-scope cases **0.934**;
the refusals that had to happen **2/4**.

**Measured, against the no-consolidation baseline:** the delayed retention's
evidence **2 → 3** and its stage **EXPLORATION → PRACTICE**.

**Seven things this Alpha does NOT show** — in the same order as the W41
Alpha, because they have not changed:

1. **168 cases and 34 benchmark items are a demonstration, not a
   generalisation.** The mission's §14 asks for ≥100 multilingual cases; the
   set has 168, and a number over a set of that size says what it says.
2. **Human learning was not measured.** The retention baseline compares two
   selection policies under ONE scripted learner — a rule, wrong the first
   time and right the second. The report of it says so, and no number from
   it is a statement about a person.
3. **The support score is not a probability and is not calibrated.** It is
   `SupportScore.UNCALIBRATED` and says so in the API.
4. **The delayed teach-back phase fails**, and is reported as failing.
5. **The paraphrase category is 0/2**: *"Explain how green plants make food
   using sunlight."* is refused. The workspace's vocabulary does not reach
   the paraphrase, and the system says it does not know rather than guessing.
6. **The consolidation does not yet change the knowledge.** It forgets the
   dialogue memory and reports the claims' support; it does not integrate
   the learner's errors into the knowledge, and the mission's §9's
   error-driven learning integration is not wired.
7. **The full repository test suite was not re-run.** The targeted packages
   were: 144 classes, 1341 tests, 0 failures.

## 4. Known limitations, named

1. **Two curated domains only** (`photosynthesis`, `logic`) plus whatever a
   document adds. There is no corpus.
2. **The entailment checker is bounded** — it enumerates ground
   propositional forms under a fixed atom budget.
3. **The answer is not translated.** A Russian question about English
   knowledge gets an English answer, and **the answer says so**.
4. **The conversation is in memory.** The durable record is the
   `asked_question` table; the context does not survive a restart.
5. **The `POST /load` replaces the workspace's knowledge.** It is the
   package loader, not an import.
6. **The consolidation's rules are simple.** Seven kinds of forgetting, each
   a rule over the dialogue memory; none of them touches a claim.
7. **`ConsciousBrain` and the nine shadow classes** of the W41 audit are
   undecided. The mission's §16.1 makes that the owner's decision.
8. **`PlanningStage` uses a constant reward** and `AgentLoop.checkConvergence`
   is weak, as the W41 audit found them. Both are recorded in
   `W42-RISK-REGISTER.md`.

## 5. How to run

```bash
export JAVA_HOME=$HOME/jdk25
export PATH="$JAVA_HOME/bin:$PATH"

# the application
./gradlew :matrix-core:quarkusRun
# → http://localhost:9091/workbench/

# the targeted suites (144 classes, 1341 tests)
./gradlew :matrix-core:test --tests "io.matrix.knowledge.*" \
                            --tests "io.matrix.memory.*" \
                            --tests "io.matrix.brain.*" \
                            --tests "io.matrix.api.*" \
                            --tests "io.matrix.rag.*"

# the formal gate
for cfg in formal/*.cfg; do
  java -cp tools/tla2tools.jar tlc2.TLC -config "$cfg" "$(basename "$cfg" .cfg).tla"
done
python3 scripts/mutation-harness.py --report docs-v2/engineering/MUTATION-REPORT.md
```

The full repository suite is not run by default; the standing rule requires
the owner's agreement because of the OOM risk.

## 6. The owner's checklist

The twelve steps above are the walkthrough. If you run them in this order,
on a fresh clone, you should see these outcomes:

| # | the step | the call | what you should see |
|---|---|---|---|
| 1 | create | `POST /workspaces/{id}/load` | the counts of the two packages |
| 2 | acquire | `POST /workspaces/{id}/documents` | the segments, the claims, the concepts, **the representations** |
| 3 | explain | `POST /workspaces/{id}/ask` | the **document's own sentence** as the first line |
| 4 | levels | the same question at four levels | four different accounts |
| 5 | limits | a question it cannot support | `answered: false` and a reason |
| 6 | premise | a question with a false premise | `answered: false`, the premise and the refuting claim named |
| 7 | practise | `GET …/exercises/next` | an item and **the reason it was chosen** |
| 8 | evaluate | `GET …/assessment` | the held-out items, which the teacher never saw |
| 9 | represent | `GET …/representations` | the account the import wrote |
| 10 | consolidate | `POST …/consolidate` | the marked records, **and the same number of claims** |
| 11 | baseline | `GET …/retention-experiment` | the two arms, and the limits beside them |
| 12 | restart | `kill -9`, then start again | **every count unchanged**, the imported account still the answer |

**Two things to watch.** The consolidation is destructive in one way only:
it **marks** records, and `GET …/dialogue` no longer returns the forgotten
ones. And `POST …/load` **replaces** the workspace — do not call it after
an import.
