## What each mutant attacks

- **`MemoryM4Causal-tombstone-guard-inverted`** — The Insert guard must reject an insert that a tombstone covers. Inverting it must make the tombstone properties fail.
- **`MemoryM4Causal-merge-stale-clock`** — The Merge filter must use the MERGED clock. Reverting it to the receiver's pre-merge clock is the defect RECON-W39 corrected - and it was invisible to F1-F4 until PresentImpliesUncovered and AbsentImpliesCovered were added.
- **`MemoryM4Causal-tombstone-deletes-newer`** — A tombstone at a stale epoch must not delete a strictly newer value. Making the removal unconditional is the defect RECON-W39 corrected.
- **`ConjugateBudgeterDP-step-uses-raw-unit-slope`** — The step must compute the slope over the REDUCED grid, as the Java does. The raw-unit slope is what the model computed before RECON-W39 and what the Java never computes. The shipped configuration has row costs with gcd 1, where the two slopes coincide, so the mutant is checked against a configuration whose costs share a divisor.
- **`ConjugateBudgeterDP-witness-union`** — The witness reconstruction must carry the remaining budget down, not union the skip and take witnesses. The union can cost more than the envelope - the defect RECON-W38.5 corrected.
- **`BrcStep-chain-fold-reversed`** — The chain must be applied left to right. Folding it in reverse must break ComposeEndpointPreserved.
- **`BrcStep-convergence-threshold-strict`** — The step must mark a step converged when the Hamming distance is AT MOST the threshold. Using a strict comparison must break ConvergenceIsComputed, which states the Java's own rule.
- **`HashChain-verified-always-true`** — A broken chain must never be reported as verified. Making the append report an unconditionally verified chain must break VerifiedImpliesIntact.
- **`BotEthicsPipeline-trigger-guard-dropped`** — The FNL verdict must gate the approve action: an action the FNL rejects may not be approved. Dropping the guard must break FnlVerdictIsFollowed.
- **`MctsLatsVisit-node-its-own-child`** — A node must never become its own child. Dropping the guard must break TreeAcyclic - the defect RECON-W38.5 corrected.
- **`MPDTNeuron-init-k-range-widened`** — The k bound must hold from the initial state. Widening the initial range must make KBounded fail.
- **`Consensus-evaluate-without-quorum`** — A proposal may only be decided once the quorum of votes has been cast. Dropping the quorum guard must break the decision properties.
- **`FrozenEthicalFNL-fires-a-non-triggering-axiom`** — Only the axioms whose trigger covers the feature set may fire. Firing all of them must break FiredSubsetOfTotal and NeuronsAreCanonical.
- **`HashChain-wrong-sequence-number`** — A link's sequence number must be its position in the chain - the contract RECON-W39 wrote into the Java (sequence(i) = i - 1). Recording a different number must break the integrity check.
- **`KnowledgeLifecycle-established-without-evidence`** — A refinement must not leave a claim established with nothing behind it. Dropping the evidence the refinement attaches must make EvidenceRequired fail.
- **`KnowledgeLifecycle-no-revision-recorded`** — Every change must leave a revision that says what changed. Dropping the revision must make RevisionRecorded fail.
- **`KnowledgeLifecycle-superseded-claim-rewritten`** — A correction must not rewrite what was believed. Letting the refinement change the text of the superseded claim must make SupersededKeepsProposition fail.
- **`KnowledgeLifecycle-draft-claim-can-be-superseded`** — A claim with no evidence cannot be superseded: the superseded status is itself an established one. Widening the guard to allow a DRAFT claim must make EvidenceRequired fail - the gap the model found in its own first version.
- **`KnowledgeStore-import-drops-the-claims`** — An import must land the claims and the evidence that backs them together. Dropping the claims must make TypeOK fail, because the evidence would then point at claims that are not there.
- **`KnowledgeStore-rollback-leaves-the-claims`** — A rolled-back import must leave nothing behind. Letting the rollback keep the claims must make ImportIsAtomic fail - the store would hold half a package.
- **`KnowledgeStore-import-drops-the-sources`** — A claim that is backed by evidence needs a source behind that evidence. Dropping the sources must make BackedHasSource fail.
- **`KnowledgeStore-migration-lowers-the-version`** — The schema version only ever goes up. A migration that lowers it must fail the version properties - a downgrade would read data written by a newer schema.
