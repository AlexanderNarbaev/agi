# L22 — University and Researcher Partnerships

**Status:** normative · **Layer:** 22 (academic collaboration) · **Date:** 2026-08-26
**Changelog:** 2026-08-26 — brain wave v4 levels; rewrite in measured/scientific tone; archive reference added.

## 1. Scope
L22 specifies how the project engages academic groups: partnership forms, open problem list, publication and IP terms, educational integration, grants, residencies, and the partnership registry. Operational coordination lives in L11; licensing in L12.

## 2. Engagement Principles
**Academic freedom** — the project does not predetermine outcomes. Confirming and refuting results are equally welcome. **Open access** — code under AGPLv3 + ethical; datasets under CC0/CC BY; papers at minimum as ArXiv preprints. Exceptions only for off-core commercial work under a separate agreement. **No dual-use** — no partnerships with military departments, weapons labs, mass-surveillance vendors. Partners undergo L7 ethical audit. **Attribution** — co-authorship per substantial intellectual contribution; alphabetical recommended for equal contribution; technical-only help in Acknowledgements.

## 3. Partnership Forms
1. **Research partnership** — joint work on an open problem. Matrix provides code, maintainer time, compute when available. Partner provides research time, students, lab.
2. **Educational partnership** — thesis topics, semester course, lab practicum. Matrix provides materials, guest lectures.
3. **Grant partnership** — joint proposal (Horizon Europe, ERC, NSF, DFG, ANR, RNF, etc.). Matrix acts as industry partner / work-package lead.
4. **Researcher residency** — 1–6 months, remote or on-site. Funded by grants, scholarships, or partner funds.
5. **Student internship** — 3–6 months, 20–40 h/week, on `good first issue` plus one mentored project; "Matrix Contributor" certificate per L15.

## 5. Project Initiation
Proposal as GitHub Discussion labelled `research-proposal` → partner matching (maintainer curator ↔ academic co-PI) → goals, deliverables, schedule, IP split agreed → signed MOU (1–2 pages; template in repo) → bi-weekly syncs, public progress dashboard → close-out: paper, code integration, blog post.

## 6. Intellectual Property
Code: AGPLv3 + ethical restrictions (L12). Patents: royalty-free grant-back within Matrix scope (L12 §3.1). Data: CC0/CC BY unless containing personal data. Commercial co-funding disclosed in paper and MOU; hidden funding not permitted.

## 7. Educational Integration
Course "Introduction to Discrete Cognitive Architectures" (L15) offered for CS / Cognitive Science / Philosophy-of-Mind tracks. Sample thesis topics: FPGA implementation of MPDT truth table; GA vs gradient comparison on navigation; interpretable FNL for text classification; formal verification of FROZEN axioms. Instructor support: free slides, guest lectures, instructor chat.

## 8. Grants and Residencies
Grant roles: consultant, co-performer, infrastructure provider. Priority programs: EU Horizon Europe, ERC, NSF, DFG, ANR, RNF. Process: researcher contacts coordinators → joint scoping → letter of support → on award, MOU + budget + start. Residency: 1–6 months, open call 1–2× per year, maintainer committee selects. Funding from grants or community fund.

## 9. Registry and Reporting
Public `PARTNERSHIPS.md` (in repo): institution, type, topic, contact, status, links to paper and code. Updated by community coordinators. Annual report "Matrix in Academia" lists completed projects, joint papers, and defended theses.

## 10. Phase-Aligned Targets
Phase 0 — first preprint "MPDT Neuron: Formal Model and Genetic Training". Phase 1 — first educational partnership in one university. Phase 2 — first research partnership (FROZEN verification). Phase 3 — Horizon Europe joint proposal, 3+ active partnerships. Phase 4+ — partners in 10+ countries, annual conference.
