# L18 — Testing, CI/CD, and Code Quality

**Status:** normative · **Layer:** 18 (engineering quality) · **Date:** 2026-08-26
**Changelog:** 2026-08-26 — brain wave v4 levels; rewrite in measured/scientific tone; archive reference added.

## 1. Scope
L18 specifies the engineering quality program: test strategy across four layers, CI triggers and gates, release publishing, code-quality tools, SemVer policy, and rollback. Layer 18 is normative for the public repository and enforced by GitHub Actions.

## 2. Test Layers
1. **Unit** — JUnit 5, AssertJ, Mockito. Every public method covered. Naming `should_expectedBehavior_when_condition`. No `Thread.sleep()`; Awaitility for async. Deterministic.
2. **Integration** — Testcontainers (Kafka, MinIO), Pekko TestKit. Avro round-trip, NeuronClusterActor↔broker, `.ldn` snapshot load/store, NBP two-actor transfer. Quarkus profile `integration-test`. CI on every PR; suite ≤ 5 min.
3. **Chaos** — Chaos Mesh / Litmus / custom. Scenarios: (a) random cluster kill → HADES isolation, accuracy ≥ 90%; (b) inter-pod partition → Circuit Breaker + quorum; (c) Kafka latency injection → buffer holds, no signal loss; (d) disk pressure → snapshot writer halts, alerts fire. Weekly, staging.
4. **Ethical** — fail-closed on every Three-Prohibition case; covers all six FROZEN axioms (L7 §5.2). Any failure is critical severity; PR merge blocked.

## 3. CI
Platform: GitHub Actions. Triggers: PR (full), push main (full + snapshot artifact), tag `v*` (full + release image), cron weekly (chaos in staging). PR jobs: `lint` (Checkstyle, SpotBugs); `unit-test` (matrix Java 25, JaCoCo); `integration-test`; `ethical-test` (critical gate); `build-native` depends on unit + integration + ethical. Coverage: JaCoCo, floor 80% line on new code (warning in early phases; hard gate planned). Secrets: Gitleaks, TruffleHog — blocks PR on hit.

## 4. CD
Artifacts: Docker → ghcr.io/matrix-ai/matrix; libs → Maven Central (or GitHub Packages early); reference `.ldn` snapshots → public MinIO bucket. Tag pipeline `v*`: native build → all tests incl. chaos → publish image with version + `latest` → auto-changelog → GitHub Release with binaries + reference snapshots. Staging: ArgoCD/Flux on success; chaos + pilots (L13) auto-run.

## 5. Code Quality
Checkstyle: Google Java Style; config in repo. SpotBugs: bytecode static analysis. SonarQube: long-term aggregation (optional). Cyclomatic complexity ≤ 10/method (warning). Class ≤ 500 lines (recommendation).
**Forbidden**: `float`/`double` in MPDT core (Ax-1); raw `System.currentTimeMillis` without abstraction; FROZEN-neuron mutation in production; `Thread.sleep()` outside chaos tests.

## 6. Versioning
SemVer 2.0.0. PATCH: bug fix, no API/protocol change. MINOR: backward-compatible feature; Avro field add with `default`. MAJOR: breaking — protocol change, field removal. Avro: deprecated one MINOR, removed in MAJOR. Kafka topics: new versioned topic on format change (`neuron-batch.v2.{clusterId}`). gRPC: add methods MINOR; remove/change MAJOR. FNL manifest `version` field per L3; PATCH auto, MINOR manual.

## 7. Rollback and Hotfix
Rollback: ArgoCD auto on health-check fail; manual `kubectl rollout undo`. State rollback: last stable `.ldn` snapshot, replay events after snapshot timestamp. Hotfix: branch `hotfix/<desc>` from last stable tag, minimal fix + reproducer test, fast CI (lint + unit + ethical), maintainer approval, PATCH tag, out-of-band release. Postmortem: blameless within 48 h of every SEV1/SEV2 (L10 §5.2); regression test added.

## 8. Acceptance Gates
- Unit coverage ≥ 82% line on matrix-core (CONSTITUTION V).
- Integration suite ≤ 5 min on standard runner.
- Ethical suite: 100% of FROZEN axiom scenarios pass.
- Chaos suite: weekly green; HADES accuracy invariant holds.
- PR merge blocked on any critical gate failure.
