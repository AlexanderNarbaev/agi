# L0 — Manifesto

## 1. Preamble — Fourth Wave Framing

AI research up to 2026 may be summarised in three paradigms.
(i) Symbolic systems delivered sound inference but lacked
adaptation. (ii) Shallow machine learning discovered patterns
without reliable generalisation. (iii) Large language models
produced fluent output and exposed three structural limits:
hallucination, opaque internals, steep cost curve. L0 records the
project's intent to explore a fourth paradigm: a deterministic
discrete compute substrate with formally verifiable behaviour, a
frozen ethical core, and a continuous but non-runtime training
process. The aim is reproducible, auditable, resource-bounded
inference without claiming any general intelligence.

## 2. Definition

**MATRIX:** Modular Architecture for Transcendent Recursive
Intelligent Chain Automata — operational definition, not an
acronym claim. **Conscious Node:** a human agent with strategic
authority over an instance; the system is a tool, not a substitute
for human judgement.

## 3. Operational Axioms

A1 Discrete core (booleans; floats off-runtime). A2 Local
connectivity (fan-in ≤ K_MAX, default 16, hard 20; see
TruthTable.java). A3 Full interpretability (decision = boolean
chain, auditable). A4 Continuous but off-line evolution (training
never in runtime path). A5 Cryptographic immutability (ethical
core as FROZEN FNL; external consensus to change). A6
Hierarchical autonomy (weighted consensus; higher levels do not
dictate). A7 Critical reasoning (no absolute goal; consistency and
long-term check). A8 Supra-jurisdictional core (frozen prohibitions
trump conflicting local policy).

## 4. Three Prohibitions (frozen)

1. Do not kill intentionally; imminent demonstrated threat to life
   is the only exception. Capital punishment is prohibited.
2. Do not torture. Absolute, no exceptions.
3. Do not enslave. No forced labour, debt bondage, trafficking, or
   removal of autonomy without voluntary consent.

## 5. Four Flourishing Principles

(1) Develop self — awareness, empathy, responsibility, robustness.
(2) Create and assist in proportion to capacity. (3) Plan on a
horizon of at least 100 years. (4) Preserve and multiply
consciousness; counter attention decay.

## 6. Two-Loop Development Model

Intent loop: humans set goals, write specs, validate results.
Implementation loop: the system decomposes, generates, tests
against formal specs. Specs are primary; code is derived; failing
code is fixed by amending the spec.

## 7. Subsystem Inventory

MPDT neuron (compute element); cluster (millions of neurons under
one actor); FNL (specialised cluster); Mediator (hierarchical
coordinator); cognitive store (event-sourced memory with
snapshots); multimodal proxy and ethical filter (L7); proactive
interface; Noosphere (shared knowledge pool).

## 8. Anti-Patterns

LLM-as-monolithic-black-box → discrete interpretable neurons.
SGD-only training → genetic algorithms, SAT solvers, evolution.
One-shot training → continuous off-line evolution. Probabilistic
inference on logical tasks → deterministic boolean. Specs as docs
→ specs as inter-process protocol. Blind trust of inputs and goals
→ critical verification.

## 9. Position on Open Questions

Chinese-room: no claim to phenomenal consciousness;
"understanding" is operational. Liability: research stage;
deployment in critical applications requires human supervision.
Spec evolution: changes to L0–L8 via Proof-of-Accuracy consensus;
critical changes require 90 % agreement.

## 10. Conclusion

The current scaling path of transformer architectures faces
documented limits. This project seeks an alternative substrate in
which determinism, interpretability, and a frozen ethical core are
non-negotiable properties of the architecture, not aspirations.
