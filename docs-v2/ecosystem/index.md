## Why MATRIX Exists

Large Language Models are powerful but opaque. They hallucinate, they cannot
explain themselves, and they cost a fortune to run. MATRIX takes a different
approach: **a hybrid brain** that combines:

- **BIR** (Boolean Inference Rules) — explicit, auditable logic
- **HDC** (Hyperdimensional Computing) — vector-symbolic memory
- **MCTS** (Monte Carlo Tree Search) — principled planning
- **FROZEN Modulators** — Ethics, Safety, Consistency, Lie Detection

All running on **seeded Random** — every decision is reproducible. **No LLM in
the runtime path.** All inference happens server-side on the MATRIX server.
