# SPEC-002-quantum — BIR → MPS

**Статус: normative** · пересмотр 2026-08-26 (v2 rebuild) · часть SPEC-002.

## Что

Квантовая аппроксимация BIR: TT → Tensor Product → MPS-разложение (последовательные SVD-сжатия, порог ε), bond-dimension χ. Карта тавтологически реализуема на компиляции TT в MPS через стандартный алгоритм (`χ ≤ 2^N` для точного представления; оценка через ренки β^n на [K=20, шум-канал]).

## BLOCKED-EXT: код запуска

- Субстрат: quantum hardware отсутствует.
- Решение: оставить спецификацию, реализация отложена до появления.
- Протокол верификации: reference implementation в research-only Python под guard `matrix.research.enabled`; числа сверяются на k≤10.

## Цели

- Реалистичный протокол MPS-композиции для большого TT с контролируемым χ.
- Метрики: χ, ε (порог реконструкции), gate-count при компиляции в схему.
