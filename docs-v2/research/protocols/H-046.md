# EXP-046 preregistration

## Hypothesis (H-046)
Subconscious impulse → conscious gate filter accuracy ≥ 0.9 on synthetic
impulse corpus (synthetic-scope).

## Setup
- `ImpulseScheduler` with `ConjugateBudgeter` + `EthicalFilter` (FROZEN-FNL)
- 1000 synthetic impulses drawn from the 4-way `AutonomyImpulse` enum,
  with a noise rate of 10% — 10% of impulses are randomly relabelled
  to a "forbidden" name that violates the ethical filter.
- "Ground truth" gate decision: `allowed = ethics.allows(impulse.name)`
  with the original (un-relabelled) impulse name.
- Accuracy = correct gate decisions / total decisions

## Measurements
- Total impulses fired: N
- Allowed by gate: ALLOWED
- Blocked by gate: BLOCKED
- Match with ground truth: MATCH
- Accuracy: MATCH / N

## Gate
- Accuracy ≥ 0.9
