# EXP-039 preregistration

## Hypothesis (H-039)
Curiosity-impulse fires when prediction-error > θ_c in offline replay.
Precision@top-K ≥ 0.7 at recall ≥ 0.5 (synthetic-scope).

## Setup
- Synthetic replay corpus: 200 episodes, half "surprising" (prediction-error > θ) and half "boring" (≤ θ)
- Threshold sweep: θ_c ∈ {1, 2, 3, 4}
- For each θ, run an impulse-scheduler that fires curiosity when |predError| > θ_c
- Top-K = half the corpus size = 100; measure precision = true-positive / K

## Gate
- Precision@top-K ≥ 0.7 at recall ≥ 0.5
- Single seed; median over thresholds
