# EXP-043 preregistration

## Hypothesis (H-043)
Decentralized digest synthesis (k-anonymous + DP-noise) preserves downstream task utility ≥0.7 × baseline at k=100, ε=1.0 (synthetic-scope).

## Setup
- `Anonymizer(k=100)`
- `DecentralizedDigestPipeline(epsilon=1.0, sensitivity=1)`
- 1000 synthetic content hashes, each with known true count drawn from `Pareto(α=2.0)` distribution
- "Downstream task" = a synthetic classifier that returns 1 if the noisy count meets the threshold, 0 otherwise; the baseline classifier returns 1 if the true count meets the threshold.
- Utility = F1 against ground truth (positive = truly above threshold)

## Measurements
- Total digests emitted: |D|
- Shared digests: |{d ∈ D : d.shared}|
- Downstream utility: F1 vs ground truth
- Relative utility: utility / baseline_utility
- Multiple epsilon values: 0.1, 0.5, 1.0, 5.0

## Gate
- Relative utility ≥0.7 at ε=1.0, k=100
- 5 seed replications, median reported
