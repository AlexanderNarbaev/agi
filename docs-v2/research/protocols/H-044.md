# EXP-044 preregistration

## Hypothesis (H-044)
Saliency weights calibrate from prediction-error stream online.
Calibration error (ECE) ≤ 0.1 after 1000 cycles (synthetic-scope).

## Setup
- Saliency weigher: returns fixed weight = current PE normalised
- Track predicted-vs-actual saliency over N cycles
- ECE = sum over bins of |predicted - actual| × bin_weight

## Gate
- ECE ≤ 0.1 after 1000 cycles
