## 1. Дельта относительно W25

- Атлас расширен §98-§106 (волны 26-28): новые разделы переноса в L0-L9.
- Стек механизмов L0-L10 стабилен; добавлены ссылки на новые разделы атласа в колонке «Основание».
- Без изменений: 4 класса отказа, конституционный минимум, лестница субстратов, контрактная дисциплина DSL.

## 3. Сквозной отказ (L3/L6)

Без изменений относительно W25: 4 класса с witness — reject-by-budget (трёхзначный вердикт, UNDECIDED заразителен), reject-by-proof (Заславский), deadlock (нет готовых событий), divergence (расход без коммуникации; детектор — счётчик повторений).

## 4. Прозрачность границ (без изменений)

- k≤20 — потолок (Sperner §38).
- Закон 1: сила правила — гипотеза для ранжирования.
- Неполнота — конституционное основание.
- Эмерджентная интерпретация поведения не переносится.
- Конституционные триггеры проходят любой фильтр (аттенюация Бродбента).
