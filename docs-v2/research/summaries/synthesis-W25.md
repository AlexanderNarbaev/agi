## 2. Сквозной отказ (L3/L6)

Четыре класса с witness:
- **reject-by-budget** — трёхзначный вердикт, UNDECIDED заразителен по Клини.
- **reject-by-proof** — сильное отрицание Заславского с хранимым контрпримером.
- **deadlock** — нет готовых событий (AA §50).
- **divergence** — расход бюджета без коммуникации; детектор — счётчик повторений состояния (AA §66, антиневротическая схема Шеннона).

## 3. Прозрачность границ

- k≤20 — потолок из Sperner §38.
- Закон 1: сила правила — гипотеза для ранжирования, не истина.
- Неполнота — конституционное основание: внешнее доверие вне формальной системы.
- Запреты и frozen-компоненты — конституционный минимум; изменение через RFC + консенсус.
- Эмерджентная интерпретация поведения (граница №12) — не переносится; каждый акт аудируем по журналу.
