# The accepted decision-path findings — explicit, narrow, owned and time-bounded.
#
# RECON-W43.0. One accepted finding GROUP per line:
#   <root>:<file>:<symbol> = <count> | <the reason it is permitted>
#
# The count is the number of accepted findings of that symbol in that file.
# The LINE NUMBER is deliberately not part of the key: a key that moves when
# unrelated code is inserted above it makes the baseline a maintenance trap,
# and a baseline that is a trap is a baseline nobody maintains. The count
# changes only when a finding is added or removed, which is exactly the
# change the gate must catch.
#
# Every line is an EXCEPTION, not a pass. The gate fails when a group
# appears that is not here, when a count does not match, AND when a group
# here no longer holds — so the baseline cannot silently become a blanket.
#
# WHAT IS IN HERE
# The wall-clock reads are timestamps: the time a goal was set, a row was
# written, an episode was logged, a file was observed. They RECORD when
# something happened and they decide nothing, which is what CONSTITUTION
# Article I allows: it forbids wall-clock in a DECISION PATH, not the
# recording of time.
#
# They were previously invisible because the determinism audit scanned
# neither matrix-brain-runtime nor the knowledge core. The W43 audit found
# them by widening the coverage, and they are listed here one by one, each
# with its reason, rather than being waved through by a package-level
# exemption.
#
# ONE EXCEPTION IS OF A DIFFERENT KIND
# TrueDistillationFactory imports an ONNX activation teacher. That is a
# TRAINING component: it teaches a distilled model and does not run on the
# decision path. It is listed separately below rather than swept in with
# the timestamps.
#
# owner: repo-owner
