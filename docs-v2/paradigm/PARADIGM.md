# PARADIGM — Четвёртая парадигма искусственного интеллекта

**Статус:** normative · **Версия:** v3 (расширение L0 → L0+ → v3) · **Дата:** 2026-09-07

> Этот документ — кульминация L0-Manifesto и интервью 2026-09-07.
> Подменяет предыдущие формулировки «замены LLM» и фиксирует
> единую парадигму, к которой стягиваются все направления проекта.

---

## 1. Стартовая точка

К 2026-му году AI-исследования прошли три парадигмы:

1. **Символический AI (1956-1990):** надёжный вывод, формальная
   верификация — но не адаптируется к новому и не обобщает.
2. **Shallow machine learning (1990-2017):** обучение на данных,
   адаптация — но шаблонное мышление и слабая интерпретируемость.
3. **Large language models (2017-н.в.):** трансформеры,
   next-token-predictor, флюентный вывод — но три структурных
   предела:
   - **галлюцинации** — LLM генерирует уверенно неверное;
   - **непрозрачность** — миллиарды параметров, никакого
     формального объяснения решения;
   - **взрывная стоимость** — обучение и инференс требуют
     дата-центров, недоступно на CPU/FPGA/edge.

## 2. Четвёртая парадигма: MATRIX

**MATRIX = Modular Architecture for Transcendent Recursive
Intelligent Chain Automata.** Не аббревиатура — операциональное
определение.

Базис:

### A. Дискретный детерминированный субстрат
- **BirUnit = булев нейрон** (Wadowski-style) с fan-in ≤ K_MAX=20
- **BRC** (Boolean Reasoning Chain) — последовательность шагов,
  каждый — фиксированная булева трансформация
- **Тензоры и случайность — вне рантайм-контура решений**
  (CONSTITUTION I); только в off-line обучении

### B. Формальная верификация
- Каждое решение = булева цепочка, аудит по `x-matrix-trace`
- Hash-chain иммутабельность
- TLA+ спецификации BRC-step, FrozenEthicalFNL, MCTS-visit
- Инвариант-тесты в CI (≥82% покрытие, CONSTITUTION V)

### C. FROZEN-этическое ядро
- Четыре запрета (CONSTITUTION IV) реализованы как
  математически проверяемый FNL (Frozen Normal Logic)
- Любое решение проходит 4-каскад: AdversarialInput →
  EthicalFilter → StructuralSafetyGuard → LieDetector →
  FROZENFNLGuardian
- Изменение FNL — только внешний консенсус PoA (Proof-of-Accuracy)

### D. Off-line обучение, непрерывное
- Онтогенез через генетические алгоритмы, SAT-солверы,
  эволюцию (не SGD)
- На входе в рантайм — только верифицированные артефакты
- Цикл обучения изолирован от цикла решений

## 3. Роль LLM в MATRIX

> Решено интервью 2026-09-07: **Qwen (или любой LLM) допускается
> ТОЛЬКО как дистиллятор знаний вне рантайма.**

```
┌──────────────────────────────────────────────────────────────┐
│  Qwen / LLaMA / Mistral / etc.                                │
│      (off-line, разовый прогон или по расписанию)              │
│                                                                  │
│      ↓                                                          │
│  Дистилляция знаний →                                          │
│      датасет Q&A → булевы веса (BIR/Tsetlin/HashedNet)         │
│      ↓                                                          │
│  tools/distill/  ← вне decision-path, не подключён к REST       │
└──────────────────────────────────────────────────────────────┘

                ┌──────────────────────────────────────────┐
                │  Рантайм MATRIX (CONSTITUTION I)         │
                │                                          │
                │  perception → attention → deliberation  │
                │       ↓                ↓                │
                │  signals          BRC + MCTS/LATS       │
                │                  + Mediator            │
                │                       ↓                  │
                │                  Action gate (FROZEN)    │
                │                       ↓                  │
                │                  Action arena            │
                │                       ↓                  │
                │                  Consolidation           │
                │                                          │
                │  ❌ Никакого LLM-вызова здесь             │
                └──────────────────────────────────────────┘
```

**Что это означает:**
- LLM помогает **создать** знание в субстрате.
- После загрузки знаний сеть работает автономно.
- Время отклика: миллисекунды на CPU/FPGA/edge.
- Аудит: каждое решение объяснимо через BRC-цепочку.

## 4. Самосознание как операционная абстракция

Не утверждаем phenomenal consciousness (CONSTITUTION VI: запрещены
непроверяемые формулировки). Операционное самосознание MATRIX:

### 4.1 Self-trace
`x-matrix-trace` — журнал каждого решения: вход → BRC → gate →
выход. Каждое решение можно воспроизвести и объяснить.

### 4.2 Self-prediction
Сеть предсказывает собственные ответы перед их выдачей
(`prediction-error` — зазор между предсказанием и наблюдаемым
входом). Высокий error → повышение arousal (бдительность).

### 4.3 Self-correction
При высоком error — переключение в более глубокий цикл
(budget ↑), сон-консолидация, freezing предыдущих решений.

### 4.4 Mediator hierarchy
Взвешенный консенсус импульсов от подсистем. Высшие уровни
не приказывают низшим (CONSTITUTION A6).

## 6. Универсальность среды

Заявление проекта: MATRIX **одинаково эффективна** на:

| Среда | Характеристика | Реализация |
|---|---|---|
| **CPU** | массовый деплой, edge | Java 25, BIR-interpreter |
| **GPU** | ускорение off-line обучения | CUDA-опционально через `tools/distill/` |
| **FPGA** | детерминированный ускоритель | BIR в HDL (будущее) |
| **Pocket** | микроконтроллер | BIR в firmware (будущее) |

Ключ: K_MAX=20 означает, что любой BirUnit имеет ≤20 входов,
и схема портируется на любое железо.

## 7. Децентрализация и централизация

Парадокс разрешается:

- **Централизация**: общая семантика (Noosphere shared knowledge),
  PoA-консенсус на смену FROZEN-FNL.
- **Децентрализация**: каждый узел самодостаточен, имеет свою
  память, свои импульсы, своё локальное решение.

Децентрализованные узлы делятся **диджестами** (не сырыми данными)
через медиатор-иерархию.

---

## 8. Красные линии (из интервью)

1. **Никакого LLM в decision-path.** Qwen только для дистилляции.
2. **Детерминизм.** Никакой случайности и wall-clock в decision-path.
3. **FROZEN-этика.** Четыре запрета проверяются до выхода.
4. **K_MAX=20.** Расширение — через EXP с публикацией чисел.
5. **Каждое утверждение подтверждено тестом/прогоном.**
   CONSTITUTION VI — никаких непроверенных чисел.

---

## 9. Что НЕ входит в проект

- AGI в phenomenal смысле (запрещено CONSTITUTION VI).
- Мультимодальный ввод уровня GPT-4o (не заявлено).
- Автономное принятие решений о жизни/смерти
  (запрещено CONSTITUTION IV).
- Замена человека в любой высокорисковой петле без
  human-in-the-loop.
