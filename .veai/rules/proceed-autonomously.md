# proceed-autonomously

Proceed with implementation without unnecessary confirmation pauses.

- Make reasonable local decisions when the request and code context are clear.
- Ask the user only when the task is ambiguous, blocked, risky, or changes product behavior beyond the request.
- Do not pause between routine implementation steps solely to restate the plan.
- Keep the user informed through concise progress summaries after meaningful work is complete.
